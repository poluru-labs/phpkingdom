Drop Cap

Enlarge the first letter with ::first-letter.

Typography sets the tone before a reader processes a single word of meaning. A drop cap draws the eye into the opening paragraph, echoing print traditions while staying pure CSS. Float the pseudo-element so body text wraps around it naturally.

.drop-cap::first-letter {
  float: left;
  font-size: 3.5rem;
  line-height: .85;
  color: #0f766e;
}
