Typography Checklist

A quick review list before shipping text-heavy pages.

  • Measure: Body copy stays between 45–75 characters per line.
  • Scale: Headings use a consistent ratio (e.g. 1.25 or 1.333).
  • Line height: Body ≥ 1.5; display headings can be tighter (~1.1–1.2).
  • Contrast: Text meets WCAG AA (4.5:1 for normal, 3:1 for large).
  • Hierarchy: One clear h1; heading levels match document outline.
  • Links: Distinguishable without relying on color alone.
  • Responsive: Fluid type or breakpoints prevent overflow on mobile.
  • Font loading: Limit weights; use font-display: swap.
  • Language: Set lang for hyphenation and screen readers.
  • Proof: Read aloud — awkward breaks and rag reveal spacing issues.
