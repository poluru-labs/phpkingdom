White Space

nowrap, pre-wrap, and pre control line breaks and spacing.

white-space: nowrap
This line stays on one row extra spaces collapse scroll if needed
white-space: pre-wrap
Preserves spaces and line breaks while still wrapping long lines.
white-space: pre
function greet(name) { return "Hello, " + name; }

Use pre-wrap for user-generated text; use pre for code blocks with horizontal scroll.
