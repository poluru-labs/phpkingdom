Idempotent Producer

Section: Producer Reliability

Focus: Manual Commit

Scenario: CDC bridge

Study the KafkaJS pattern and adapt it to your event-driven service.

KafkaJS (Node.js)

// Idempotent Producer — Example 07
// Focus: manual commit | Scenario: CDC bridge

import { Kafka } from "kafkajs";
const kafka = new Kafka({ clientId: "orders", brokers: ["localhost:9092"] });
export async function sendOnce(topic, messages) {
  const producer = kafka.producer({
    idempotent: true,
    maxInFlightRequests: 5,
    transactionalId: undefined, // EOS needs transactions
  });
  await producer.connect();
  await producer.send({ topic, messages, acks: -1 });
  await producer.disconnect();
}

export const TOPIC_ID = "idempotent-producer";

Practice Notes

Checklist for Idempotent Producer
- Practice: manual commit
- Scenario: CDC bridge
- Prefer idempotent producers and explicit keys for ordering
- Commit offsets after successful processing (at-least-once)
- Use DLQ/retry topics for poison messages
- Never log secrets; include correlation IDs in headers
