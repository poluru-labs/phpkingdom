# phpkingdom.com Tutorials

Tutorial packs for [phpkingdom.com](https://phpkingdom.com) — practical HTML examples, exercises, and starter templates for web and Node.js topics.

**Author:** Subrahmanyam Poluru · **Email:** mail.polurus@gmail.com · **Site:** [polurus.com](https://polurus.com)

## Features

- Topic-aware HTML examples with metadata (site, author, course, section, topic)
- Practice packs: Problem → Solution exercises per course
- Starter templates for common app and tooling workflows
- Covers frontend, backend, testing, cloud, and design-system tracks
- Consistent folder layout: sections → topics → examples / exercises / templates
- Ready for phpkingdom.com publishing and local browsing
