Git Commands

# Bare Repositories — Exercise 23
# Focus: lfs track | Scenario: open source fork

# Bare repository (bare-repository)
git init --bare /tmp/bare-repository.git
git clone /tmp/bare-repository.git /tmp/bare-repository-work
cd /tmp/bare-repository-work
echo '# bare-repository' > README.md
git add README.md && git commit -m "chore(bare-repository): init"
git push origin main

Practice Notes

Checklist for Bare Repositories
- Practice: lfs track
- Scenario: open source fork
- Prefer small commits with clear messages
- Never rewrite shared history without coordination
- Use git status often before commit/push
- Prefer pull --rebase on feature branches; protect main

Useful companions:
  git status -sb
  git log --oneline --graph --decorate
  git reflog
  git restore --staged <file>
  git push --force-with-lease

Notes

This exercise shows one way to apply Bare Repositories in a open source fork context.

Commit often, review diffs before push, and keep main/master protected with reviews.
