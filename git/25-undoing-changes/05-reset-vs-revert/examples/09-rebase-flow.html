Git Commands

# git reset vs git revert — Example 09
# Focus: rebase flow | Scenario: mobile app

# reset vs revert (reset-vs-revert)
git reset --soft HEAD~1
git revert HEAD --no-edit
git log --oneline -n 5
# Prefer revert on main; reset only on unpublished commits

Practice Notes

Checklist for git reset vs git revert
- Practice: rebase flow
- Scenario: mobile app
- Prefer small commits with clear messages
- Never rewrite shared history without coordination
- Use git status often before commit/push
- Prefer pull --rebase on feature branches; protect main

Useful companions:
  git status -sb
  git log --oneline --graph --decorate
  git reflog
  git restore --staged <file>
  git push --force-with-lease
