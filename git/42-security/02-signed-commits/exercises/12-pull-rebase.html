Git Commands

# Signed Commits — Exercise 12
# Focus: pull rebase | Scenario: team feature

# Signed commits (signed-commits)
git config --global gpg.format ssh
git config --global user.signingkey ~/.ssh/id_ed25519.pub
git config --global commit.gpgsign true
git commit -S -m "feat(signed-commits): signed change"
git log --show-signature -n 1

Practice Notes

Checklist for Signed Commits
- Practice: pull rebase
- Scenario: team feature
- Prefer small commits with clear messages
- Never rewrite shared history without coordination
- Use git status often before commit/push
- Prefer pull --rebase on feature branches; protect main

Useful companions:
  git status -sb
  git log --oneline --graph --decorate
  git reflog
  git restore --staged <file>
  git push --force-with-lease

Notes

This exercise shows one way to apply Signed Commits in a team feature context.

Commit often, review diffs before push, and keep main/master protected with reviews.
