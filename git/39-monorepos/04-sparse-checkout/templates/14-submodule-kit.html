# Sparse Checkout — Template 14
# Focus: submodule kit | Scenario: hotfix release

# Sparse checkout cone mode (sparse-checkout)
git clone --filter=blob:none --sparse git@github.com:phpkingdom/mono.git
cd mono
git sparse-checkout set apps/sparse-checkout packages/ui
git status

Practice Notes

Checklist for Sparse Checkout
- Practice: submodule kit

- Prefer pull --rebase on feature branches; protect main
