Git Commands

# Sparse Checkout — Exercise 11
# Focus: push set-upstream | Scenario: solo project

# Sparse checkout cone mode (sparse-checkout)
git clone --filter=blob:none --sparse git@github.com:phpkingdom/mono.git
cd mono
git sparse-checkout set apps/sparse-checkout packages/ui
git status

Practice Notes

Checklist for Sparse Checkout
- Practice: push set-upstream
- Scenario: solo project
- Prefer small commits with clear messages
- Never rewrite shared history without coordination
- Use git status often before commit/push
- Prefer pull --rebase on feature branches; protect main

Useful companions:
  git status -sb
  git log --oneline --graph --decorate
  git reflog
  git restore --staged <file>
  git push --force-with-lease

Notes

This exercise shows one way to apply Sparse Checkout in a solo project context.

Commit often, review diffs before push, and keep main/master protected with reviews.
