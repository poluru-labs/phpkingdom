# Pre-Commit Linting — Template 11
# Focus: codeowners | Scenario: solo project

# Pre-commit linting via husky + lint-staged (pre-commit-linting)
npx husky init
npm i -D lint-staged eslint prettier
echo "npx lint-staged" > .husky/pre-commit
chmod +x .husky/pre-commit
git add -A && git commit -m "chore(pre-commit-linting): wire pre-commit lint"

Practice Notes

Checklist for Pre-Commit Linting
- Practice: codeowners
- Scenario: solo project
- Prefer small commits with clear messages
- Never rewrite shared history without coordination
- Use git status often before commit/push
- Prefer pull --rebase on feature branches; protect main

Useful companions:
  git status -sb
  git log --oneline --graph --decorate
  git reflog
  git restore --staged <file>
  git push --force-with-lease
