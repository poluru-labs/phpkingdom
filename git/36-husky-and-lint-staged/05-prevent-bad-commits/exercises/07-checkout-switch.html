Git Commands

# Prevent Invalid Commits — Exercise 07
# Focus: checkout switch | Scenario: CI pipeline

# Block bad commits locally (prevent-bad-commits)
cat > .husky/commit-msg <<'EOF'
#!/usr/bin/env sh
npx --no -- commitlint --edit "$1"
EOF
chmod +x .husky/commit-msg

Practice Notes

Checklist for Prevent Invalid Commits
- Practice: checkout switch
- Scenario: CI pipeline
- Prefer small commits with clear messages
- Never rewrite shared history without coordination
- Use git status often before commit/push
- Prefer pull --rebase on feature branches; protect main

Useful companions:
  git status -sb
  git log --oneline --graph --decorate
  git reflog
  git restore --staged <file>
  git push --force-with-lease

Notes

This exercise shows one way to apply Prevent Invalid Commits in a ci pipeline context.

Commit often, review diffs before push, and keep main/master protected with reviews.
