Git Commands

# CODEOWNERS — Example 11
# Focus: fetch pull | Scenario: solo project

# CODEOWNERS (code-owners)
mkdir -p .github
cat > .github/CODEOWNERS <<'EOF'
*       @phpkingdom/core
/docs/  @phpkingdom/docs
EOF
git add .github/CODEOWNERS
git commit -m "chore(code-owners): add CODEOWNERS"

Practice Notes

Checklist for CODEOWNERS
- Practice: fetch pull
- Scenario: solo project
- Prefer small commits with clear messages
- Never rewrite shared history without coordination
- Use git status often before commit/push
- Prefer pull --rebase on feature branches; protect main

Useful companions:
  git status -sb
  git log --oneline --graph --decorate
  git reflog
  git restore --staged <file>
  git push --force-with-lease

Notes

This example shows one way to apply CODEOWNERS in a solo project context.

Commit often, review diffs before push, and keep main/master protected with reviews.
