Git Commands

# Three-Way Merge — Exercise 07
# Focus: checkout switch | Scenario: CI pipeline

# Three-way merge when histories diverged (three-way-merge)
git switch main
git merge --no-ff feature/three-way-merge -m "merge: feature/three-way-merge into main"
git log --oneline --graph -n 12

Practice Notes

Checklist for Three-Way Merge
- Practice: checkout switch
- Scenario: CI pipeline
- Prefer small commits with clear messages
- Never rewrite shared history without coordination
- Use git status often before commit/push
- Prefer pull --rebase on feature branches; protect main

Useful companions:
  git status -sb
  git log --oneline --graph --decorate
  git reflog
  git restore --staged <file>
  git push --force-with-lease

Notes

This exercise shows one way to apply Three-Way Merge in a ci pipeline context.

Commit often, review diffs before push, and keep main/master protected with reviews.
