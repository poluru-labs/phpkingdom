# Fast-Forward Merge — Example 03
# Focus: stage files | Scenario: open source fork

# Fast-forward merge (fast-forward-merge)
git switch main
git merge --ff-only feature/fast-forward-merge
git log --oneline --graph -n 8

Practice Notes

Checklist for Fast-Forward Merge
- Practice: stage files
- Scenario: open source fork
- Prefer small commits with clear messages
- Never rewrite shared history without coordination
- Use git status often before commit/push
- Prefer pull --rebase on feature branches; protect main

Useful companions:
  git status -sb
  git log --oneline --graph --decorate
  git reflog
  git restore --staged <file>
  git push --force-with-lease

Notes

This example shows one way to apply Fast-Forward Merge in a open source fork context.

Commit often, review diffs before push, and keep main/master protected with reviews.
