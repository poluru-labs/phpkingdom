# Default Branch — Example 23
# Focus: hook setup | Scenario: open source fork


# Default branch naming (default-branch)
git remote show origin | sed -n '/HEAD branch/s/.*: //p'
git branch -m master main
git push -u origin main

Practice Notes

Checklist for Default Branch
- Practice: hook setup
- Scenario: open source fork
- Prefer small commits with clear messages
- Never rewrite shared history without coordination
- Use git status often before commit/push
- Prefer pull --rebase on feature branches; protect main

Useful companions:
  git status -sb
  git log --oneline --graph --decorate
  git reflog
  git restore --staged <file>
  git push --force-with-lease

Notes

This example shows one way to apply Default Branch in a open source fork context.

Commit often, review diffs before push, and keep main/master protected with reviews.
