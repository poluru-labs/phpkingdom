# Tracking Branches — Example 15
# Focus: log graph | Scenario: monorepo app

# Tracking branches (tracking-branches)
git branch -vv
git switch -c feature/tracking-branches --track origin/main
git branch -u origin/feature/tracking-branches
git status -sb

Practice Notes

Checklist for Tracking Branches
- Practice: log graph
- Scenario: monorepo app
- Prefer small commits with clear messages
- Never rewrite shared history without coordination
- Use git status often before commit/push
- Prefer pull --rebase on feature branches; protect main

Useful companions:
  git status -sb
  git log --oneline --graph --decorate
  git reflog
  git restore --staged <file>
  git push --force-with-lease

Notes

This example shows one way to apply Tracking Branches in a monorepo app context.

Commit often, review diffs before push, and keep main/master protected with reviews.
