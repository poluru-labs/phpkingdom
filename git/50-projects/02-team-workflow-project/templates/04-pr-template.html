# Focus: pr template | Scenario: hotfix release

# Project: team workflow (team-workflow-project)
git switch main && git pull --ff-only
git switch -c feature/team-workflow-project
git commit --allow-empty -m "feat(team-workflow-project): team task"
git push -u origin HEAD
gh pr create --fill

Practice Notes

Checklist for Team Collaboration Workflow
- Practice: pr template
- Scenario: hotfix release
- Prefer small commits with clear messages
- Never rewrite shared history without coordination
- Use git status often before commit/push
- Prefer pull --rebase on feature branches; protect main

Useful companions:
  git status -sb
  git log --oneline --graph --decorate
  git reflog
  git restore --staged <file>
  git push --force-with-lease
