Git Commands

# Git CI/CD Workflow — Example 14
# Focus: diff staged | Scenario: hotfix release

# Project: CI/CD with Git (ci-cd-project)
mkdir -p .github/workflows
cat > .github/workflows/ci.yml <<'EOF'
name: ci
on: [push, pull_request]
jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: echo CI
EOF
git add -A && git commit -m "ci(ci-cd-project): project workflow"

Practice Notes

Checklist for Git CI/CD Workflow
- Practice: diff staged
- Scenario: hotfix release
- Prefer small commits with clear messages
- Never rewrite shared history without coordination
- Use git status often before commit/push
- Prefer pull --rebase on feature branches; protect main

Useful companions:
  git status -sb
  git log --oneline --graph --decorate
  git reflog
  git restore --staged <file>
  git push --force-with-lease
