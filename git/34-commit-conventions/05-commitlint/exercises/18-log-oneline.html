# commitlint setup (commitlint)
npm i -D @commitlint/cli @commitlint/config-conventional
echo "module.exports={{extends:['@commitlint/config-conventional']}}" > commitlint.config.js
npx commitlint --from HEAD~1 --to HEAD --verbose

Practice Notes

Checklist for Commitlint
- Practice: log oneline
- Scenario: design system
- Prefer small commits with clear messages
- Never rewrite shared history without coordination
- Use git status often before commit/push
- Prefer pull --rebase on feature branches; protect main

Useful companions:
  git status -sb
  git log --oneline --graph --decorate
  git reflog
  git restore --staged <file>
  git push --force-with-lease

Notes

This exercise shows one way to apply Commitlint in a design system context.
