Git Commands

# Commit Message Templates — Example 16
# Focus: gitignore rule | Scenario: docs site

# Commit message template (commit-message-template)
git config commit.template ~/.gitmessage-commit-message-template.txt
cat > ~/.gitmessage-commit-message-template.txt <<'EOF'
# <type>(<scope>): <subject>
#
# Why this change:
EOF
git commit

Practice Notes

Checklist for Commit Message Templates
- Practice: gitignore rule
- Scenario: docs site
- Prefer small commits with clear messages
- Never rewrite shared history without coordination
- Use git status often before commit/push
- Prefer pull --rebase on feature branches; protect main

Useful companions:
  git status -sb
  git log --oneline --graph --decorate
  git reflog
  git restore --staged <file>
  git push --force-with-lease

Notes
