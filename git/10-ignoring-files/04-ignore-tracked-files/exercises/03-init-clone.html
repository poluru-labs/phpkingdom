Exercise 03

Ignore Previously Tracked Files

Section: Ignoring Files

Focus: Init Clone

Scenario: open source fork

Run the commands in a practice repo and verify with git status / git log.

Git Commands

# Ignore Previously Tracked Files — Exercise 03
# Focus: init clone | Scenario: open source fork

# Stop tracking a file that is already committed (ignore-tracked-files)
git rm --cached path/to/secret.env
echo 'path/to/secret.env' >> .gitignore
git commit -m "chore(ignore-tracked-files): untrack secret.env"

Practice Notes

Checklist for Ignore Previously Tracked Files
- Practice: init clone
- Scenario: open source fork
- Prefer small commits with clear messages
- Never rewrite shared history without coordination
- Use git status often before commit/push
- Prefer pull --rebase on feature branches; protect main

Useful companions:
  git status -sb
  git log --oneline --graph --decorate
  git reflog
  git restore --staged <file>
  git push --force-with-lease

Notes

This exercise shows one way to apply Ignore Previously Tracked Files in a open source fork context.
