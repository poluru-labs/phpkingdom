# Git Ignore Patterns — Template 09
# Focus: gh workflow | Scenario: mobile app

# .gitignore patterns (ignore-patterns)
cat >> .gitignore <<'EOF'
*.log
*.tmp
dist/
.env*
!.env.example
EOF
git status --ignored

Practice Notes

Checklist for Git Ignore Patterns
- Practice: gh workflow
- Scenario: mobile app
- Prefer small commits with clear messages
- Never rewrite shared history without coordination
- Use git status often before commit/push
- Prefer pull --rebase on feature branches; protect main

Useful companions:
  git status -sb
  git log --oneline --graph --decorate
  git reflog
  git restore --staged <file>
  git push --force-with-lease
