# Forking Workflow — Template 19
# Focus: reflog kit | Scenario: mobile app

# Forking workflow (forking-workflow)
gh repo fork phpkingdom/upstream --clone=false
git remote add upstream git@github.com:phpkingdom/upstream.git
git fetch upstream
git rebase upstream/main
git push origin HEAD
gh pr create --repo phpkingdom/upstream

Practice Notes

Checklist for Forking Workflow
- Practice: reflog kit
- Scenario: mobile app
- Prefer small commits with clear messages
- Never rewrite shared history without coordination
- Use git status often before commit/push
- Prefer pull --rebase on feature branches; protect main

Useful companions:
  git status -sb
  git log --oneline --graph --decorate
  git reflog
  git restore --staged <file>
  git push --force-with-lease

Notes
