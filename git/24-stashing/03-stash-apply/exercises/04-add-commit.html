Git Commands

# Apply a Stash — Exercise 04
# Focus: add commit | Scenario: hotfix release

# Apply stash without removing it (stash-apply)
git stash push -m "wip-stash-apply"
git stash apply stash@{{0}}
git status

Practice Notes

Checklist for Apply a Stash
- Practice: add commit
- Scenario: hotfix release
- Prefer small commits with clear messages
- Never rewrite shared history without coordination
- Use git status often before commit/push
- Prefer pull --rebase on feature branches; protect main

Useful companions:
  git status -sb
  git log --oneline --graph --decorate
  git reflog
  git restore --staged <file>
  git push --force-with-lease

Notes

This exercise shows one way to apply Apply a Stash in a hotfix release context.

Commit often, review diffs before push, and keep main/master protected with reviews.
