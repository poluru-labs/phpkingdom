# Pop a Stash — Template 16
# Focus: conventional commits | Scenario: docs site

# Pop the latest stash (stash-pop)
git stash push -u -m "wip-stash-pop"
git switch main
git stash pop
git status

Practice Notes

Checklist for Pop a Stash
- Practice: conventional commits
- Scenario: docs site
- Prefer small commits with clear messages
- Never rewrite shared history without coordination
- Use git status often before commit/push
- Prefer pull --rebase on feature branches; protect main

Useful companions:
  git status -sb
  git log --oneline --graph --decorate
  git reflog
  git restore --staged <file>
  git push --force-with-lease
