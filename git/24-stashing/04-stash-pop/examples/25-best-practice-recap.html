# Pop a Stash — Example 25
# Focus: best practice recap | Scenario: monorepo app

# Pop the latest stash (stash-pop)
git stash push -u -m "wip-stash-pop"
git switch main
git stash pop
git status

Practice Notes

Checklist for Pop a Stash
- Practice: best practice recap
- Scenario: monorepo app
- Prefer small commits with clear messages
- Never rewrite shared history without coordination
- Use git status often before commit/push
- Prefer pull --rebase on feature branches; protect main
