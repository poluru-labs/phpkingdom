# Fork workflow (github-fork)
gh repo fork phpkingdom/github-fork --clone
cd github-fork
git remote add upstream git@github.com:phpkingdom/github-fork.git
git fetch upstream
git rebase upstream/main

Practice Notes

Checklist for Fork a GitHub Repository
- Practice: blame line
- Scenario: mobile app
- Prefer small commits with clear messages
- Never rewrite shared history without coordination
- Use git status often before commit/push
- Prefer pull --rebase on feature branches; protect main

Useful companions:
  git status -sb
  git log --oneline --graph --decorate
  git reflog
  git restore --staged <file>
  git push --force-with-lease

Notes

This exercise shows one way to apply Fork a GitHub Repository in a mobile app context.

Commit often, review diffs before push, and keep main/master protected with reviews.
