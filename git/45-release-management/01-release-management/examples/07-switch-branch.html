# Git Release Management — Example 07
# Focus: switch branch | Scenario: CI pipeline

# Release management (release-management)
git switch main
git pull --ff-only
git tag -a v1.0.0 -m "release release-management"
git push origin main --follow-tags

Practice Notes

Checklist for Git Release Management
- Practice: switch branch
- Scenario: CI pipeline
- Prefer small commits with clear messages
- Never rewrite shared history without coordination
- Use git status often before commit/push
- Prefer pull --rebase on feature branches; protect main

Useful companions:
  git status -sb
  git log --oneline --graph --decorate
  git reflog
  git restore --staged <file>
  git push --force-with-lease

Notes

This example shows one way to apply Git Release Management in a ci pipeline context.

Commit often, review diffs before push, and keep main/master protected with reviews.
