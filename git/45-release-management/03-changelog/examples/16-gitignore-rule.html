Git Commands

# Maintain a Changelog — Example 16
# Focus: gitignore rule | Scenario: docs site

# Changelog from Git history (changelog)
git log v1.0.0..HEAD --pretty=format:'- %s (%h)' > CHANGELOG-changelog.md
git add CHANGELOG-changelog.md
git commit -m "docs(changelog): update changelog"

Practice Notes

Checklist for Maintain a Changelog
- Practice: gitignore rule
- Scenario: docs site
- Prefer small commits with clear messages
- Never rewrite shared history without coordination
- Use git status often before commit/push
- Prefer pull --rebase on feature branches; protect main

Useful companions:
  git status -sb
  git log --oneline --graph --decorate
  git reflog
  git restore --staged <file>
  git push --force-with-lease

Notes

This example shows one way to apply Maintain a Changelog in a docs site context.
