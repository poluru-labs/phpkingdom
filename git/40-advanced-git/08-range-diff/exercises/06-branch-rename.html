Git Commands

# git range-diff — Exercise 06
# Focus: branch rename | Scenario: docs site

# git range-diff — compare rebased series (range-diff)
git range-diff main~3..main origin/feature/range-diff~3..origin/feature/range-diff
git range-diff -p main..feature/range-diff@{{1}} main..feature/range-diff

Practice Notes

Checklist for git range-diff
- Practice: branch rename
- Scenario: docs site
- Prefer small commits with clear messages
- Never rewrite shared history without coordination
- Use git status often before commit/push
- Prefer pull --rebase on feature branches; protect main

Useful companions:
  git status -sb
  git log --oneline --graph --decorate
  git reflog
  git restore --staged <file>
  git push --force-with-lease

Notes

This exercise shows one way to apply git range-diff in a docs site context.

Commit often, review diffs before push, and keep main/master protected with reviews.
