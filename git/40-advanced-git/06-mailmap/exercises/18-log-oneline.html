# .mailmap — normalize author identities (mailmap)
cat > .mailmap <<'EOF'
Subrahmanyam Poluru <mail.polurus@gmail.com> Subrah <old@example.com>
Subrahmanyam Poluru <mail.polurus@gmail.com> <dev@localhost>
EOF
git shortlog -sn
git log --use-mailmap --format='%an <%ae>' -n 10

Practice Notes

Checklist for Git Mailmap
- Practice: log oneline
- Scenario: design system
- Prefer small commits with clear messages
- Never rewrite shared history without coordination
- Use git status often before commit/push
- Prefer pull --rebase on feature branches; protect main

Useful companions:
  git status -sb
  git log --oneline --graph --decorate
  git reflog
  git restore --staged <file>
  git push --force-with-lease

Notes

This exercise shows one way to apply Git Mailmap in a design system context.

Commit often, review diffs before push, and keep main/master protected with reviews.
