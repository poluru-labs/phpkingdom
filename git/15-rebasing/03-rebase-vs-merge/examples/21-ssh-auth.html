# Rebase vs Merge — Example 21
# Focus: ssh auth | Scenario: solo project

# rebase vs merge (rebase-vs-merge)
git switch main && git merge --no-ff feature/rebase-vs-merge
git switch feature/rebase-vs-merge && git rebase main
# Prefer rebase on private feature branches; merge for shared main

Practice Notes

Checklist for Rebase vs Merge
- Practice: ssh auth
- Scenario: solo project
- Prefer small commits with clear messages
- Never rewrite shared history without coordination
- Use git status often before commit/push
- Prefer pull --rebase on feature branches; protect main

Useful companions:
