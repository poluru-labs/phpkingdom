Git Commands

# Hotfix Branches — Example 01
# Focus: starter command | Scenario: solo project

# Git Flow hotfix (hotfix-branches)
git switch main
git switch -c hotfix/hotfix-branches
git commit -m "fix(hotfix-branches): production patch"
git switch main && git merge --no-ff hotfix/hotfix-branches
git tag -a v1.2.1 -m "hotfix"

Practice Notes

Checklist for Hotfix Branches
- Practice: starter command
- Scenario: solo project
- Prefer small commits with clear messages
- Never rewrite shared history without coordination
- Use git status often before commit/push
- Prefer pull --rebase on feature branches; protect main

Useful companions:
  git status -sb
  git log --oneline --graph --decorate
  git reflog
  git restore --staged <file>
  git push --force-with-lease

Notes

This example shows one way to apply Hotfix Branches in a solo project context.

Commit often, review diffs before push, and keep main/master protected with reviews.
