# Git Flow feature branches (feature-branches)
git switch develop
git switch -c feature/feature-branches
git commit -m "feat(feature-branches): work"
git switch develop
git merge --no-ff feature/feature-branches

Practice Notes

Checklist for Feature Branches
- Practice: pre-commit hook
- Scenario: team feature
- Prefer small commits with clear messages
- Never rewrite shared history without coordination
- Use git status often before commit/push
- Prefer pull --rebase on feature branches; protect main

Useful companions:
  git status -sb
  git log --oneline --graph --decorate
  git reflog
  git restore --staged <file>
  git push --force-with-lease

Notes

This exercise shows one way to apply Feature Branches in a team feature context.

Commit often, review diffs before push, and keep main/master protected with reviews.
