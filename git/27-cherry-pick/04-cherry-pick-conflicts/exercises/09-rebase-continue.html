Section: Cherry-Pick

Run the commands in a practice repo and verify with git status / git log.

Git Commands

# Resolve Cherry-Pick Conflicts — Exercise 09
# Focus: rebase continue | Scenario: mobile app

# Cherry-pick with conflicts (cherry-pick-conflicts)
git cherry-pick <commit-sha>
git status
git add -A
git cherry-pick --continue
# git cherry-pick --abort
git show --stat HEAD

Practice Notes

Checklist for Resolve Cherry-Pick Conflicts
- Practice: rebase continue
- Scenario: mobile app
- Prefer small commits with clear messages
- Never rewrite shared history without coordination
- Use git status often before commit/push
- Prefer pull --rebase on feature branches; protect main

Useful companions:
  git status -sb
  git log --oneline --graph --decorate
  git reflog
  git restore --staged <file>
  git push --force-with-lease

Notes

This exercise shows one way to apply Resolve Cherry-Pick Conflicts in a mobile app context.

Commit often, review diffs before push, and keep main/master protected with reviews.
