Git Commands

# Cherry-Pick a Commit — Example 19
# Focus: resolve conflict | Scenario: mobile app

# Cherry-pick one commit (cherry-pick-commit)
git log --oneline origin/main -n 20
git cherry-pick <commit-sha>
git show --stat HEAD
git push -u origin HEAD

Practice Notes

Checklist for Cherry-Pick a Commit
- Practice: resolve conflict
- Scenario: mobile app
- Prefer small commits with clear messages
- Never rewrite shared history without coordination
- Use git status often before commit/push
- Prefer pull --rebase on feature branches; protect main

Useful companions:
  git status -sb
  git log --oneline --graph --decorate
  git reflog
  git restore --staged <file>
  git push --force-with-lease
