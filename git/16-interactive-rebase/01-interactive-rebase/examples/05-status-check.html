Git Commands

# Interactive Rebase — Example 05
# Focus: status check | Scenario: monorepo app

# Interactive rebase — reshape local commits (interactive-rebase)
git fetch origin
git rebase -i origin/main
# In the todo editor: pick / reword / edit / squash / fixup / drop / reorder
git add -A
git rebase --continue
# git rebase --abort
git log --oneline --graph -n 12
# Never rewrite commits already on a shared protected branch

Practice Notes

Checklist for Interactive Rebase
- Practice: status check
- Scenario: monorepo app
- Prefer small commits with clear messages
- Never rewrite shared history without coordination
- Use git status often before commit/push
- Prefer pull --rebase on feature branches; protect main

Useful companions:
  git status -sb
  git log --oneline --graph --decorate
  git reflog
  git restore --staged <file>
  git push --force-with-lease

Notes

This example shows one way to apply Interactive Rebase in a monorepo app context.
