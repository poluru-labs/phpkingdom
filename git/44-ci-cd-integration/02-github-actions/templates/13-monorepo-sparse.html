# GitHub Actions — Template 13
# Focus: monorepo sparse | Scenario: open source fork

# GitHub Actions CI (github-actions)
mkdir -p .github/workflows
cat > .github/workflows/github-actions.yml <<'EOF'
name: ci
on: [push, pull_request]
jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: echo ok
EOF
git add .github/workflows/github-actions.yml
git commit -m "ci(github-actions): add workflow"

Practice Notes

Checklist for GitHub Actions
- Practice: monorepo sparse
- Scenario: open source fork
- Prefer small commits with clear messages
- Never rewrite shared history without coordination
- Use git status often before commit/push
- Prefer pull --rebase on feature branches; protect main

Useful companions:
  git status -sb
  git log --oneline --graph --decorate
  git reflog
  git restore --staged <file>
  git push --force-with-lease
