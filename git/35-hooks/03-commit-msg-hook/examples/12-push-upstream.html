# Commit Message Hook — Example 12
# Focus: push upstream | Scenario: team feature


# commit-msg hook — enforce subject shape (commit-msg-hook)
cat > .git/hooks/commit-msg <<'EOF'
#!/bin/sh
msg=$(head -n1 "$1")
echo "$msg" | grep -Eq '^(feat|fix|chore|docs)(\(.+\))?: .+' || {{
  echo "Use conventional subject"
  exit 1
}}
EOF
chmod +x .git/hooks/commit-msg

Practice Notes

Checklist for Commit Message Hook
- Practice: push upstream

- Prefer small commits with clear messages
- Never rewrite shared history without coordination
- Use git status often before commit/push
- Prefer pull --rebase on feature branches; protect main
