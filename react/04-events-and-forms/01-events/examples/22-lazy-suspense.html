React

// React Events — Example 22
// Focus: lazy suspense | Scenario: SaaS dashboard

function SaveButton() {
  function onClick(e) {
    e.preventDefault();
    console.log("save", e.currentTarget);
  }
  return <button type="button" onClick={onClick}>Save</button>;
}
// Synthetic events; pass functions — onClick={onClick} not onClick={onClick()}

Practice Notes

Checklist for React Events
- Practice: lazy suspense
- Scenario: SaaS dashboard
- Prefer function components + Hooks over class components
- Keep state local; lift only when siblings need to share
- Keys must be stable and unique among siblings
- Effects: declare dependencies; clean up subscriptions/timers
- For shared UI state: Context / Zustand / Redux; for server state: React Query
