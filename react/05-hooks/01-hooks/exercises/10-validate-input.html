// React Hooks — Exercise 10
// Focus: validate input | Scenario: B2B portal

// Rules of Hooks:
// 1. Only call Hooks at the top level (not in loops/conditions)
// 2. Only call Hooks from React functions
import { useState, useEffect } from "react";

export default function Demo() {
  const [n, setN] = useState(0);
  useEffect(() => {
    console.log("n changed", n);
  }, [n]);
  return <button onClick={() => setN((x) => x + 1)}>{n}</button>;
}

Practice Notes

Checklist for React Hooks
- Practice: validate input
- Scenario: B2B portal
- Prefer function components + Hooks over class components
- Keep state local; lift only when siblings need to share
- Keys must be stable and unique among siblings
- Effects: declare dependencies; clean up subscriptions/timers
- For shared UI state: Context / Zustand / Redux; for server state: React Query
