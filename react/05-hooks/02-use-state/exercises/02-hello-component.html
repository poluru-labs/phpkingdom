React

// useState Hook — Exercise 02
// Focus: hello component | Scenario: SaaS dashboard

import { useState } from "react";

export default function Toggle() {
  const [open, setOpen] = useState(false);
  return (
    <button onClick={() => setOpen((v) => !v)}>
      {open ? "Open" : "Closed"}
    </button>
  );
}

Practice Notes

Checklist for useState Hook
- Practice: hello component
- Scenario: SaaS dashboard
- Prefer function components + Hooks over class components
- Keep state local; lift only when siblings need to share
- Keys must be stable and unique among siblings
- Effects: declare dependencies; clean up subscriptions/timers
- For shared UI state: Context / Zustand / Redux; for server state: React Query
