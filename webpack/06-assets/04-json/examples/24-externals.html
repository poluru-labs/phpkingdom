Practice Notes

Checklist for JSON Modules
- Practice: externals
- Scenario: micro-frontend host
- Share a webpack.common.js and merge dev/prod with webpack-merge
- Prefer asset modules over file-loader/url-loader
- Use contenthash + splitChunks for long-term caching
- Measure with webpack-bundle-analyzer before optimizing
- Webpack 5: use output.clean instead of clean-webpack-plugin when possible
