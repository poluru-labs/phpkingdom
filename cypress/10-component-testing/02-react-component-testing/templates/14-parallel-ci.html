// React Component Testing — Template 14
// Focus: parallel ci | Scenario: admin panel

import { Counter } from "./Counter";

describe("<Counter />", () => {
  it("increments on click", () => {
    cy.mount(<Counter initial={2} />);
    cy.contains("[data-cy=count]", "2");
    cy.get("[data-cy=inc]").click();
    cy.contains("[data-cy=count]", "3");
  });
});
// Framework: react + vite/webpack bundler in component.devServer

Practice Notes

Checklist for React Component Testing
- Practice: parallel ci
- Scenario: admin panel
- Prefer data-cy / role-based selectors over brittle CSS
- Lean on Cypress retry-ability; avoid cy.wait(ms)
- Isolate tests; use cy.session for auth speed
- Stub flaky network with cy.intercept; assert with cy.wait('@alias')
- Keep e2e for journeys; use component testing for UI units

Useful commands:
  npm install --save-dev cypress
  npx cypress open
  npx cypress run
  npx cypress run --record --parallel
  npx cypress run --browser chrome
