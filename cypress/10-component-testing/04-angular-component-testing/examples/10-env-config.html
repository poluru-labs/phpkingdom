// Angular Component Testing — Example 10
// Focus: env config | Scenario: booking app

import { ButtonComponent } from "./button.component";

describe("ButtonComponent", () => {
  it("projects content", () => {
    cy.mount(ButtonComponent, {
      componentProperties: { label: "Deploy" },
    });
    cy.contains("button", "Deploy").should("be.visible");
  });
});
// Use @cypress/angular mount helpers with the Angular builder

Practice Notes

Checklist for Angular Component Testing
- Practice: env config
- Scenario: booking app
- Prefer data-cy / role-based selectors over brittle CSS
- Lean on Cypress retry-ability; avoid cy.wait(ms)
- Isolate tests; use cy.session for auth speed
- Stub flaky network with cy.intercept; assert with cy.wait('@alias')
- Keep e2e for journeys; use component testing for UI units

Useful commands:
  npm install --save-dev cypress
  npx cypress open
  npx cypress run
  npx cypress run --record --parallel
  npx cypress run --browser chrome
