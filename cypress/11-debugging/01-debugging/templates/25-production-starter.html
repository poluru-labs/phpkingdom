// Cypress Debugging — Template 25
// Focus: production starter | Scenario: auth portal

describe("debugging", () => {
  it("uses debug and pause", () => {
    cy.visit("/cart");
    cy.get("[data-cy=line-item]").debug(); // DevTools breakpoint
    cy.get("[data-cy=checkout]").pause().click();
  });

  it("logs subjects", () => {
    cy.get("[data-cy=total]").then(($el) => {
      cy.log(`total text: ${$el.text()}`);
    });
  });
});
// Open Mode + time-travel is the primary debug loop

Practice Notes

Checklist for Cypress Debugging
- Practice: production starter
- Scenario: auth portal
- Prefer data-cy / role-based selectors over brittle CSS
- Lean on Cypress retry-ability; avoid cy.wait(ms)
- Isolate tests; use cy.session for auth speed
- Stub flaky network with cy.intercept; assert with cy.wait('@alias')
- Keep e2e for journeys; use component testing for UI units

Useful commands:
  npm install --save-dev cypress
  npx cypress open
  npx cypress run
  npx cypress run --record --parallel
  npx cypress run --browser chrome
