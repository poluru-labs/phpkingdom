Cypress

// Screenshots — Example 01
// Focus: starter visit | Scenario: SaaS dashboard

describe("screenshots", () => {
  it("captures on demand and on failure", () => {
    cy.visit("/dashboard");
    cy.screenshot("dashboard-top");
    cy.get("[data-cy=widget-revenue]").screenshot("revenue-widget");
  });
});
// config: screenshotOnRunFailure: true, screenshotsFolder: "cypress/screenshots"

Practice Notes

Checklist for Screenshots
- Practice: starter visit
- Scenario: SaaS dashboard
- Prefer data-cy / role-based selectors over brittle CSS
- Lean on Cypress retry-ability; avoid cy.wait(ms)
- Isolate tests; use cy.session for auth speed
- Stub flaky network with cy.intercept; assert with cy.wait('@alias')
- Keep e2e for journeys; use component testing for UI units
