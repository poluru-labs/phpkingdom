// Spies — Example 07
// Focus: should assertion | Scenario: API-backed SPA

describe("cy.spy", () => {
  it("spies on console.error during a flow", () => {
    cy.visit("/checkout", {
      onBeforeLoad(win) {
        cy.spy(win.console, "error").as("consoleError");
      },
    });
    cy.get("[data-cy=pay]").click();
    cy.get("@consoleError").should("not.have.been.called");
  });
});

Practice Notes

Checklist for Spies
- Practice: should assertion
- Scenario: API-backed SPA
- Prefer data-cy / role-based selectors over brittle CSS
- Lean on Cypress retry-ability; avoid cy.wait(ms)
- Isolate tests; use cy.session for auth speed
- Stub flaky network with cy.intercept; assert with cy.wait('@alias')
- Keep e2e for journeys; use component testing for UI units
