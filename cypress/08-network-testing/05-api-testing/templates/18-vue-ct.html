// API Testing — Template 18
// Focus: vue ct | Scenario: mobile web app

describe("API testing with cy.request", () => {
  it("creates then fetches a resource", () => {
    cy.request("POST", "/api/items", { name: "Book" }).then((res) => {
      expect(res.status).to.eq(201);
      expect(res.body).to.have.property("id");
      const id = res.body.id;
      cy.request(`/api/items/${id}`).its("body.name").should("eq", "Book");
    });
  });
});
// No browser UI required — great for setup and contract checks

Practice Notes

Checklist for API Testing
- Practice: vue ct
- Scenario: mobile web app
- Prefer data-cy / role-based selectors over brittle CSS
- Lean on Cypress retry-ability; avoid cy.wait(ms)
- Isolate tests; use cy.session for auth speed
- Stub flaky network with cy.intercept; assert with cy.wait('@alias')
- Keep e2e for journeys; use component testing for UI units

Useful commands:
  npm install --save-dev cypress
  npx cypress open
  npx cypress run
  npx cypress run --record --parallel
  npx cypress run --browser chrome
