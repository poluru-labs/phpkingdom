// Network Testing — Example 17
// Focus: screenshot on fail | Scenario: API-backed SPA

describe("network testing overview", () => {
  it("stubs, waits, and asserts on XHR/fetch", () => {
    cy.intercept("GET", "/api/metrics", { fixture: "metrics.json" }).as("metrics");
    cy.visit("/ops");
    cy.wait("@metrics");
    cy.get("[data-cy=uptime]").should("contain", "%");
  });
});

Practice Notes

Checklist for Network Testing
- Practice: screenshot on fail
- Scenario: API-backed SPA
- Prefer data-cy / role-based selectors over brittle CSS
- Lean on Cypress retry-ability; avoid cy.wait(ms)
- Isolate tests; use cy.session for auth speed
- Stub flaky network with cy.intercept; assert with cy.wait('@alias')
- Keep e2e for journeys; use component testing for UI units
