// First Cypress Test — Example 22
// Focus: visual snapshot | Scenario: marketing site

// cypress/e2e/home.cy.js — first green spec

describe("home page", () => {
  it("loads and greets visitors", () => {
    cy.visit("/");
    cy.contains("h1", "Welcome").should("be.visible");
    cy.get("[data-cy=email]").type("ada@phpkingdom.com");
    cy.get("[data-cy=submit]").click();
    cy.url().should("include", "/thanks");
  });
});

Practice Notes

Checklist for First Cypress Test
- Practice: visual snapshot
- Scenario: marketing site
- Prefer data-cy / role-based selectors over brittle CSS
- Lean on Cypress retry-ability; avoid cy.wait(ms)
- Isolate tests; use cy.session for auth speed
- Stub flaky network with cy.intercept; assert with cy.wait('@alias')
- Keep e2e for journeys; use component testing for UI units
