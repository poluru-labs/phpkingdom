cypress-axe

Inject and check a11y

Starter Spec

// npm i -D cypress-axe axe-core
// support: import "cypress-axe";

describe("a11y", () => {
  it("home has no serious violations", () => {
    cy.visit("/");
    cy.injectAxe();
    cy.checkA11y(null, { includedImpacts: ["critical", "serious"] });
  });
});

Run

npx cypress open
npx cypress run
