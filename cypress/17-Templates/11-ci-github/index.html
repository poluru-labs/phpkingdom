Build, start, wait-on

Starter Spec

# .github/workflows/cypress.yml
name: Cypress
on: [push]
jobs:
  cypress:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: cypress-io/github-action@v6
        with:
          build: npm run build
          start: npm start
          wait-on: 'http://localhost:3000'

Run

npx cypress open
npx cypress run
