cy.intercept

Stub and wait aliases

Starter Spec

describe("todos intercept", () => {
  it("stubs GET /api/todos", () => {
    cy.intercept("GET", "/api/todos", { fixture: "todos.json" }).as("todos");
    cy.visit("/todos");
    cy.wait("@todos").its("response.statusCode").should("eq", 200);
    cy.get("[data-cy=todo]").should("have.length.greaterThan", 0);
  });
});

Run

npx cypress open
npx cypress run
