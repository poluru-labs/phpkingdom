cypress/included

Containerized e2e

Starter Spec

# docker-compose.yml
services:
  web:
    build: .
    ports: ["3000:3000"]
  e2e:
    image: cypress/included:13.6.0
    working_dir: /e2e
    volumes: [".:/e2e"]
    depends_on: [web]
    environment:
      - CYPRESS_baseUrl=http://web:3000
    command: cypress run

Run

npx cypress open
npx cypress run
