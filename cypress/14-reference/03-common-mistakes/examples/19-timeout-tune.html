// Common Cypress Mistakes — Example 19
// Focus: timeout tune | Scenario: docs site

describe("common mistakes", () => {
  it("avoids assigning command results", () => {
    // WRONG: const el = cy.get("[data-cy=total]");
    cy.get("[data-cy=total]").invoke("text").then((text) => {
      expect(text.trim()).to.match(/^\$/);
    });
  });

  it("does not share mutable state across its()", () => {
    cy.visit("/counter");
    cy.get("[data-cy=inc]").click();
  });
});

Practice Notes

Checklist for Common Cypress Mistakes
- Practice: timeout tune
- Scenario: docs site
- Prefer data-cy / role-based selectors over brittle CSS
- Lean on Cypress retry-ability; avoid cy.wait(ms)
- Isolate tests; use cy.session for auth speed
- Stub flaky network with cy.intercept; assert with cy.wait('@alias')
- Keep e2e for journeys; use component testing for UI units
