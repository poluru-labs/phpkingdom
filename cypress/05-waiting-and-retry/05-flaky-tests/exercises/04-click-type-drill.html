// Flaky Tests — Exercise 04
// Focus: click type drill | Scenario: admin panel

describe("anti-flake patterns", () => {
  it("asserts readiness before clicking", () => {
    cy.visit("/menu");
    cy.get("[data-cy=menu-item-billing]")
      .should("be.visible")
      .and("not.be.disabled")
      .click();
    // Avoid { force: true } as a first resort
  });

  it("isolates state between tests", () => {
    cy.clearCookies();
    cy.clearLocalStorage();
    cy.visit("/login");
  });
});

Practice Notes

Checklist for Flaky Tests
- Practice: click type drill
- Scenario: admin panel
- Prefer data-cy / role-based selectors over brittle CSS
- Lean on Cypress retry-ability; avoid cy.wait(ms)
- Isolate tests; use cy.session for auth speed
- Stub flaky network with cy.intercept; assert with cy.wait('@alias')
- Keep e2e for journeys; use component testing for UI units

Useful commands:
  npm install --save-dev cypress
  npx cypress open
  npx cypress run
  npx cypress run --record --parallel
  npx cypress run --browser chrome
