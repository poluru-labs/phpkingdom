Cypress

// cy.wait() — Example 15
// Focus: api request | Scenario: auth portal

describe("cy.wait", () => {
  it("waits on an aliased network call", () => {
    cy.intercept("GET", "/api/orders*").as("orders");
    cy.visit("/orders");
    cy.wait("@orders").its("response.statusCode").should("eq", 200);
    cy.get("[data-cy=order-row]").should("have.length.greaterThan", 0);
  });
});
// Prefer cy.wait("@alias") over cy.wait(5000)

Practice Notes

Checklist for cy.wait()
- Practice: api request
- Scenario: auth portal
- Prefer data-cy / role-based selectors over brittle CSS
- Lean on Cypress retry-ability; avoid cy.wait(ms)
- Isolate tests; use cy.session for auth speed
- Stub flaky network with cy.intercept; assert with cy.wait('@alias')
- Keep e2e for journeys; use component testing for UI units
