// Best Selectors — Exercise 19
// Focus: component prop | Scenario: docs site

// Selector priority (Cypress best practices)
// 1. data-cy / data-testid  2. ARIA / role  3. text (contains)  4. CSS

describe("best selectors", () => {
  it("uses role + name when data-cy is missing", () => {
    cy.visit("/a11y-form");
    cy.findByRole?.("button", { name: /save/i }); // if cypress-testing-library
    cy.get("[data-cy=save]").should("be.enabled").click();
  });

  it("never selects by dynamic classes alone", () => {
    cy.get("[data-cy=user-row]").should("have.length", 3);
  });
});

Practice Notes

Checklist for Best Selectors
- Practice: component prop
- Scenario: docs site
- Prefer data-cy / role-based selectors over brittle CSS
- Lean on Cypress retry-ability; avoid cy.wait(ms)
- Isolate tests; use cy.session for auth speed
- Stub flaky network with cy.intercept; assert with cy.wait('@alias')
- Keep e2e for journeys; use component testing for UI units

  npx cypress run --record --parallel
