// click, type and submit — Example 05
// Focus: data attribute selectors | Scenario: auth portal

describe("click, type, submit", () => {
  it("fills and submits a newsletter form", () => {
    cy.visit("/");
    cy.get("[data-cy=newsletter-email]")
      .type("reader@phpkingdom.com{enter}");
    // or:
    cy.get("[data-cy=newsletter]").within(() => {
      cy.get("[data-cy=newsletter-email]").clear().type("reader@phpkingdom.com");
      cy.root().submit();
    });
    cy.contains("You are subscribed").should("be.visible");
  });
});

Practice Notes

Checklist for click, type and submit

- Scenario: auth portal
- Prefer data-cy / role-based selectors over brittle CSS
- Lean on Cypress retry-ability; avoid cy.wait(ms)
- Isolate tests; use cy.session for auth speed
- Stub flaky network with cy.intercept; assert with cy.wait('@alias')
- Keep e2e for journeys; use component testing for UI units
