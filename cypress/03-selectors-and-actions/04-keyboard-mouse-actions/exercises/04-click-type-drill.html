Cypress

// Keyboard and Mouse Actions — Exercise 04
// Focus: click type drill | Scenario: admin panel

describe("keyboard and mouse", () => {
  it("uses real-ish interactions", () => {
    cy.visit("/editor");
    cy.get("[data-cy=title]").type("Draft{selectall}{backspace}Final");
    cy.get("[data-cy=body]").type("Line one{enter}Line two");
    cy.get("[data-cy=toolbar]").trigger("mouseover");
    cy.get("[data-cy=bold]").click();
    cy.get("[data-cy=body]").type("{ctrl+b}bold");
  });
});
// Prefer .click / .type; use .trigger for hover/custom events

Practice Notes

Checklist for Keyboard and Mouse Actions
- Practice: click type drill
- Scenario: admin panel
- Prefer data-cy / role-based selectors over brittle CSS
- Lean on Cypress retry-ability; avoid cy.wait(ms)
- Isolate tests; use cy.session for auth speed
- Stub flaky network with cy.intercept; assert with cy.wait('@alias')
- Keep e2e for journeys; use component testing for UI units
