Complete the task in a local Cypress project and verify with cypress open/run.

Cypress

// get, find and contains — Exercise 07
// Focus: fixture usage | Scenario: API-backed SPA

describe("get, find, contains", () => {
  beforeEach(() => cy.visit("/blog"));

  it("scopes with get + find", () => {
    cy.get("[data-cy=post-list]")
      .find("[data-cy=post]")
      .first()
      .find("h2")
      .should("be.visible");
  });

  it("finds by text with contains", () => {
    cy.contains("[data-cy=post]", "Getting started").click();
    cy.contains("h1", "Getting started").should("exist");
  });
});

Practice Notes

Checklist for get, find and contains
- Practice: fixture usage
- Scenario: API-backed SPA
- Prefer data-cy / role-based selectors over brittle CSS
- Lean on Cypress retry-ability; avoid cy.wait(ms)
- Isolate tests; use cy.session for auth speed
- Stub flaky network with cy.intercept; assert with cy.wait('@alias')
- Keep e2e for journeys; use component testing for UI units
