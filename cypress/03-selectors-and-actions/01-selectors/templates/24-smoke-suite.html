// Cypress Selectors — Template 24
// Focus: smoke suite | Scenario: admin panel

describe("selectors", () => {
  it("prefers stable data-cy attributes", () => {
    cy.visit("/profile");
    cy.get("[data-cy=avatar]").should("be.visible");
    cy.get("[data-cy=display-name]").should("not.be.empty");
  });

  it("avoids brittle CSS tied to styling", () => {
    // Prefer: cy.get("[data-cy=save]")
    // Avoid:  cy.get(".btn.btn-primary.mt-2")
    cy.get("[data-cy=save]").click();
  });
});

Practice Notes

Checklist for Cypress Selectors
- Practice: smoke suite
- Scenario: admin panel
- Prefer data-cy / role-based selectors over brittle CSS
- Lean on Cypress retry-ability; avoid cy.wait(ms)
- Isolate tests; use cy.session for auth speed
- Stub flaky network with cy.intercept; assert with cy.wait('@alias')
- Keep e2e for journeys; use component testing for UI units

Useful commands:
  npm install --save-dev cypress
  npx cypress open
  npx cypress run
  npx cypress run --record --parallel
  npx cypress run --browser chrome
