Cypress

// URL Assertions — Exercise 11
// Focus: overwrite visit | Scenario: SaaS dashboard

describe("URL assertions", () => {
  it("asserts path, query, and hash", () => {
    cy.visit("/products?sort=price#featured");
    cy.location("pathname").should("eq", "/products");
    cy.location("search").should("include", "sort=price");
    cy.hash().should("eq", "#featured");
    cy.url().should("include", "/products");
  });
});

Practice Notes

Checklist for URL Assertions
- Practice: overwrite visit
- Scenario: SaaS dashboard
- Prefer data-cy / role-based selectors over brittle CSS
- Lean on Cypress retry-ability; avoid cy.wait(ms)
- Isolate tests; use cy.session for auth speed
- Stub flaky network with cy.intercept; assert with cy.wait('@alias')
- Keep e2e for journeys; use component testing for UI units
