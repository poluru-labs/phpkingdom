describe("should vs expect", () => {
  it("retries with should; expect does not retry", () => {
    cy.visit("/async-badge");
    // Retries until passes or timeout:
    cy.get("[data-cy=badge]").should("have.text", "Ready");

    cy.get("[data-cy=badge]").then(($el) => {
      // Runs once — wrap again if you need retries
      expect($el.text()).to.match(/Ready|OK/);
    });
  });
});

Practice Notes

Checklist for should and expect
- Practice: custom commands
- Scenario: docs site
- Prefer data-cy / role-based selectors over brittle CSS
- Lean on Cypress retry-ability; avoid cy.wait(ms)
- Isolate tests; use cy.session for auth speed
- Stub flaky network with cy.intercept; assert with cy.wait('@alias')
- Keep e2e for journeys; use component testing for UI units
