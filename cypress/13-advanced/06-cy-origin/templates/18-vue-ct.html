// cy.origin Cross-Origin — Template 18
// Focus: vue ct | Scenario: mobile web app

describe("cy.origin cross-origin", () => {
  it("logs in on the IdP then returns", () => {
    cy.visit("/login");
    cy.get("[data-cy=sso]").click();
    cy.origin("https://idp.example.com", () => {
      cy.get("#username").type("ada@phpkingdom.com");
      cy.get("#password").type("secret", { log: false });
      cy.contains("button", "Sign in").click();
    });
    cy.url().should("include", "/app");
    cy.get("[data-cy=user-menu]").should("contain", "Ada");
  });
});
// Requires Cypress 12+ experimental/stable origin support

Practice Notes

Checklist for cy.origin Cross-Origin
- Practice: vue ct
- Scenario: mobile web app
- Prefer data-cy / role-based selectors over brittle CSS
- Lean on Cypress retry-ability; avoid cy.wait(ms)
- Isolate tests; use cy.session for auth speed
- Stub flaky network with cy.intercept; assert with cy.wait('@alias')
- Keep e2e for journeys; use component testing for UI units
