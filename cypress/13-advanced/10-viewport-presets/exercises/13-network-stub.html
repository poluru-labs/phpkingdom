// Viewport Presets — Exercise 13
// Focus: network stub | Scenario: checkout flow

describe("viewport presets", () => {
  const presets = [
    ["iphone-6", "mobile"],
    ["ipad-2", "tablet"],
    ["macbook-15", "desktop"],
  ];

  presets.forEach(([preset, label]) => {
    it(`renders nav on ${label} (${preset})`, () => {
      cy.viewport(preset);
      cy.visit("/");
      cy.get("[data-cy=nav]").should("be.visible");
    });
  });

  it("custom dimensions", () => {
    cy.viewport(360, 800);
    cy.visit("/");
    cy.get("[data-cy=nav-toggle]").should("be.visible");
  });
});

Practice Notes

Checklist for Viewport Presets
- Practice: network stub
- Scenario: checkout flow
- Prefer data-cy / role-based selectors over brittle CSS
- Lean on Cypress retry-ability; avoid cy.wait(ms)
- Isolate tests; use cy.session for auth speed
- Stub flaky network with cy.intercept; assert with cy.wait('@alias')
- Keep e2e for journeys; use component testing for UI units
