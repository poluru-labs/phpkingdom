cy.clock and Timers

Section: Advanced

Complete the task in a local Cypress project and verify with cypress open/run.

Cypress

// cy.clock and Timers — Exercise 24
// Focus: flake fix | Scenario: admin panel

describe("cy.clock and timers", () => {
  it("advances fake timers for a countdown", () => {
    cy.clock();
    cy.visit("/sale");
    cy.get("[data-cy=countdown]").should("contain", "01:00");
    cy.tick(30_000);
    cy.get("[data-cy=countdown]").should("contain", "00:30");
    cy.tick(30_000);
    cy.contains("[data-cy=banner]", "Sale ended");
  });
});
// cy.clock stubs Date + timers; cy.tick moves time forward
