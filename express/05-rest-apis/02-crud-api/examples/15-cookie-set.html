CRUD API

Scenario: blog API

Study the Express route/middleware pattern and adapt it to your API.

Express

// CRUD API — Example 15
// Focus: cookie set | Scenario: blog API

const books = [];
let seq = 1;

app.get("/books", (req, res) => res.json(books));
app.post("/books", (req, res) => {
  const book = { id: seq++, ...req.body };
  books.push(book);
  res.status(201).json(book);
});
app.put("/books/:id", (req, res) => {
  const i = books.findIndex((b) => b.id === Number(req.params.id));
  if (i < 0) return res.sendStatus(404);
  books[i] = { id: books[i].id, ...req.body };
  res.json(books[i]);
});
app.delete("/books/:id", (req, res) => {
  const i = books.findIndex((b) => b.id === Number(req.params.id));
  if (i < 0) return res.sendStatus(404);
  books.splice(i, 1);
  res.sendStatus(204);
});

Checklist for CRUD API
