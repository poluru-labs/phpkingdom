// Express Middleware — Exercise 10
// Focus: status codes | Scenario: public docs API

// Middleware signature: (req, res, next) => {}
app.use((req, res, next) => {
  req.requestId = Date.now().toString(36);
  console.log(req.requestId, req.method, req.url);
  next();
});

app.get("/whoami", (req, res) => {
  res.json({ requestId: req.requestId });
});
// Call next() to continue; omit it to end the cycle (after sending)

Practice Notes

Checklist for Express Middleware
- Practice: status codes
- Scenario: public docs API
- Keep route handlers thin; push logic into controllers/services
- Always attach final 4-arg error middleware
- Validate input; load secrets from environment variables
- Export app separately from listen() for easier testing
