Express

// Application Middleware — Exercise 03
// Focus: res json | Scenario: auth service

const express = require("express");
const morgan = require("morgan");
const app = express();

// Runs for every request on this app
app.use(morgan("dev"));
app.use(express.json({ limit: "1mb" }));
app.use(express.urlencoded({ extended: true }));

app.get("/api/ping", (req, res) => res.json({ ok: true }));

app.listen(3000);
// Application-level: app.use(...) before routes

Practice Notes

Checklist for Application Middleware
- Practice: res json
- Scenario: auth service
- Keep route handlers thin; push logic into controllers/services
- Always attach final 4-arg error middleware
- Validate input; load secrets from environment variables
- Export app separately from listen() for easier testing
