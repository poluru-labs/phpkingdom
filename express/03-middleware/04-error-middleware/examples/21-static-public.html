Error Middleware

Section: Middleware

Focus: Static Public

Scenario: REST API

Study the Express route/middleware pattern and adapt it to your API.

Express

// Error Middleware — Example 21
// Focus: static public | Scenario: REST API

// Must be 4 args — Express detects error handlers by arity
app.use((err, req, res, next) => {
  console.error(err.stack);
  const status = err.status || 500;
  res.status(status).json({
    error: err.message || "Internal Server Error",
    requestId: req.requestId,
  });
});

// Trigger: next(err) or throw in async with wrapper
app.get("/boom", (req, res, next) => {
  next(Object.assign(new Error("Boom"), { status: 400 }));
});
