Express

// Router Middleware — Example 17
// Focus: jwt protect | Scenario: realtime chat

const express = require("express");
const api = express.Router();

// Only for routes mounted on this router
api.use((req, res, next) => {
  res.set("X-API", "v1");
  next();
});

api.get("/status", (req, res) => res.json({ api: "v1" }));

const app = express();
app.use("/api", api);
app.listen(3000);
// Router middleware scopes cross-cutting logic to a mount path

Practice Notes

Checklist for Router Middleware
- Practice: jwt protect
- Scenario: realtime chat
- Keep route handlers thin; push logic into controllers/services
- Always attach final 4-arg error middleware
- Validate input; load secrets from environment variables
- Export app separately from listen() for easier testing
