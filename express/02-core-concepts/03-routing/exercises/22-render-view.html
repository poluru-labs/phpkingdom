Express

// Express Routing — Exercise 22
// Focus: render view | Scenario: admin backend

const express = require("express");
const app = express();

app.get("/books", (req, res) => res.json([]));
app.get("/books/:isbn", (req, res) => res.json({ isbn: req.params.isbn }));
app.post("/books", (req, res) => res.status(201).json(req.body));
app.all("/secret", (req, res) => res.send("any method"));

app.listen(3000);
// Match method + path; first matching route wins

Practice Notes

Checklist for Express Routing
- Practice: render view
- Scenario: admin backend
- Keep route handlers thin; push logic into controllers/services
- Always attach final 4-arg error middleware
- Validate input; load secrets from environment variables
- Export app separately from listen() for easier testing
