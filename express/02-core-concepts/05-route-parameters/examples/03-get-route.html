Route Parameters

Section: Core Concepts

Focus: Get Route

Scenario: auth service

Study the Express route/middleware pattern and adapt it to your API.

Express

// Route Parameters — Example 03
// Focus: get route | Scenario: auth service

app.get("/users/:userId/posts/:postId", (req, res) => {
  const { userId, postId } = req.params;
  res.json({ userId, postId });
});

// Optional-ish pattern with regex
app.get("/order/:id(\\d+)", (req, res) => {
  res.json({ id: Number(req.params.id) });
});

app.param("userId", (req, res, next, id) => {
  req.userId = Number(id);
  next();
});

Practice Notes

Checklist for Route Parameters
- Practice: get route
- Scenario: auth service
- Keep route handlers thin; push logic into controllers/services
- Always attach final 4-arg error middleware
- Validate input; load secrets from environment variables
