Example 04

Route Methods

Section: Core Concepts

Focus: Post Route

Scenario: file service

Study the Express route/middleware pattern and adapt it to your API.

Express

// Route Methods — Example 04
// Focus: post route | Scenario: file service

app.get("/items", list);
app.post("/items", create);
app.put("/items/:id", replace);
app.patch("/items/:id", patch);
app.delete("/items/:id", remove);
app.head("/items", (req, res) => res.sendStatus(200));
app.options("/items", (req, res) => res.sendStatus(204));

function list(req, res) { res.json([]); }
function create(req, res) { res.status(201).json(req.body); }
function replace(req, res) { res.json({ id: req.params.id, ...req.body }); }
function patch(req, res) { res.json({ id: req.params.id, patched: req.body }); }
function remove(req, res) { res.status(204).end(); }

Practice Notes

Checklist for Route Methods
- Practice: post route
- Scenario: file service
- Keep route handlers thin; push logic into controllers/services
- Always attach final 4-arg error middleware
- Validate input; load secrets from environment variables
- Export app separately from listen() for easier testing
