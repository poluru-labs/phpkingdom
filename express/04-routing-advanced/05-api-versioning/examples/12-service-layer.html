Example 12

API Versioning

Section: Routing Advanced

Focus: Service Layer

Scenario: admin backend

Study the Express route/middleware pattern and adapt it to your API.

Express

// API Versioning — Example 12
// Focus: service layer | Scenario: admin backend

const express = require("express");
const v1 = express.Router();
const v2 = express.Router();

v1.get("/items", (req, res) => res.json({ version: 1, items: [] }));
v2.get("/items", (req, res) => res.json({ version: 2, data: { items: [] } }));

const app = express();
app.use("/api/v1", v1);
app.use("/api/v2", v2);
// Prefer URL versioning for public APIs; headers also work

Practice Notes

Checklist for API Versioning
- Practice: service layer
- Scenario: admin backend
- Keep route handlers thin; push logic into controllers/services
- Always attach final 4-arg error middleware
- Validate input; load secrets from environment variables
- Export app separately from listen() for easier testing
