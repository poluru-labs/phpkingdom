Express

// Express.js vs Node.js — Example 05
// Focus: route params | Scenario: blog API

// Node http (manual):
const http = require("http");
http.createServer((req, res) => {
  if (req.url === "/hi" && req.method === "GET") {
    res.writeHead(200, { "Content-Type": "application/json" });
    res.end(JSON.stringify({ hi: true }));
  } else {
    res.writeHead(404);
    res.end();
  }
}).listen(3000);

// Express (routing + middleware):
const express = require("express");
const app = express();
app.get("/hi", (req, res) => res.json({ hi: true }));
app.listen(3000);
// Express adds routing, middleware stack, and helpers on top of Node

Practice Notes

Checklist for Express.js vs Node.js
- Practice: route params
- Scenario: blog API
- Keep route handlers thin; push logic into controllers/services
- Always attach final 4-arg error middleware
- Validate input; load secrets from environment variables
- Export app separately from listen() for easier testing
