Express

// Express.js Setup — Exercise 21
// Focus: static mount | Scenario: REST API

// package.json scripts
// "start": "node server.js"
// "dev": "node --watch server.js"

const express = require("express");
const app = express();
const PORT = process.env.PORT || 3000;

app.get("/health", (req, res) => res.json({ ok: true }));

app.listen(PORT, () => {
  console.log(`Express ready on :${PORT}`);
});
// npm init -y && npm i express

Practice Notes

Checklist for Express.js Setup
- Practice: static mount
- Scenario: REST API
- Keep route handlers thin; push logic into controllers/services
- Always attach final 4-arg error middleware
- Validate input; load secrets from environment variables
- Export app separately from listen() for easier testing
