Express.js - Basics

Section: Basics

Scenario: auth service

Study the Express route/middleware pattern and adapt it to your API.

Express

// Express.js - Basics — Example 13
// Focus: body parser | Scenario: auth service

const express = require("express");
const app = express();

app.use(express.json());

app.get("/ping", (req, res) => res.json({ pong: true }));
app.post("/echo", (req, res) => res.json({ youSent: req.body }));

app.listen(3000);
// Basics: create app → middleware → routes → listen
