Example 09

CORS

Section: Security

Focus: Express Router

Scenario: microservice

Study the Express route/middleware pattern and adapt it to your API.

Express

// CORS — Example 09
// Focus: express router | Scenario: microservice

const cors = require("cors");

app.use(cors({
  origin: ["https://phpkingdom.com", "http://localhost:5173"],
  methods: ["GET", "POST", "PUT", "PATCH", "DELETE"],
  allowedHeaders: ["Content-Type", "Authorization"],
  credentials: true,
  maxAge: 600,
}));

app.get("/api/public", (req, res) => res.json({ ok: true }));
// Browser-only concern; servers calling you are unaffected

Practice Notes

Checklist for CORS
- Practice: express router
- Scenario: microservice
- Keep route handlers thin; push logic into controllers/services
- Always attach final 4-arg error middleware
- Validate input; load secrets from environment variables
- Export app separately from listen() for easier testing
