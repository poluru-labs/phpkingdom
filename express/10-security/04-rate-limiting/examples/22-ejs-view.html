Example 22

Rate Limiting

Section: Security

Focus: Ejs View

Scenario: admin backend

Study the Express route/middleware pattern and adapt it to your API.

Express

// Rate Limiting — Example 22
// Focus: ejs view | Scenario: admin backend

const rateLimit = require("express-rate-limit");

const apiLimiter = rateLimit({
  windowMs: 15 * 60 * 1000,
  max: 100,
  standardHeaders: true,
  legacyHeaders: false,
  message: { error: "Too many requests" },
});

const authLimiter = rateLimit({ windowMs: 60 * 1000, max: 5 });

app.use("/api", apiLimiter);
app.post("/auth/login", authLimiter, (req, res) => {
  res.json({ token: "…" });
});
// Tighten limits on auth and expensive endpoints

Checklist for Rate Limiting
