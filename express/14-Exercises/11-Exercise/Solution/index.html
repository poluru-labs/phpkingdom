Solution 11 — CRUD List Create

Implement GET /api/books and POST /api/books with an in-memory array.

Solution

const books = [];
app.get('/api/books', (req, res) => res.json(books));
app.post('/api/books', (req, res) => {
  const book = { id: Date.now(), ...req.body };
  books.push(book);
  res.status(201).json(book);
});
