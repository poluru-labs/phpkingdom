Study the Express route/middleware pattern and adapt it to your API.

Express

// EJS — Example 07
// Focus: middleware log | Scenario: realtime chat

app.set("view engine", "ejs");

app.get("/posts/:slug", (req, res) => {
  res.render("post", {
    title: req.params.slug,
    body: "Hello from EJS",
    site: "phpkingdom.com",
  });
});
// views/post.ejs → <h1><%= title %></h1><p><%= body %></p>

Practice Notes

Checklist for EJS
