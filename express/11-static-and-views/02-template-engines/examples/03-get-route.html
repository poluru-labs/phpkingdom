Example 03

Template Engines

Section: Static and Views

Focus: Get Route

Scenario: auth service

Study the Express route/middleware pattern and adapt it to your API.

Express

// Template Engines — Example 03
// Focus: get route | Scenario: auth service

app.set("views", path.join(__dirname, "views"));
app.set("view engine", "ejs"); // or pug / hbs

app.get("/", (req, res) => {
  res.render("home", { title: "phpkingdom.com", user: null });
});
// res.render(view, locals) — engine compiles templates to HTML

Practice Notes

Checklist for Template Engines
- Practice: get route
- Scenario: auth service
- Keep route handlers thin; push logic into controllers/services
- Always attach final 4-arg error middleware
- Validate input; load secrets from environment variables
- Export app separately from listen() for easier testing
