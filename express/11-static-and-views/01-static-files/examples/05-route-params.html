Example 05

Static Files

Section: Static and Views

Focus: Route Params

Scenario: blog API

Study the Express route/middleware pattern and adapt it to your API.

Express

// Static Files — Example 05
// Focus: route params | Scenario: blog API

const path = require("path");
const express = require("express");
const app = express();

app.use(express.static(path.join(__dirname, "public"), {
  maxAge: "1d",
  index: "index.html",
}));

app.get("*", (req, res) => {
  res.sendFile(path.join(__dirname, "public", "index.html"));
});
// Put CSS/JS/images in public/; API routes should be registered first
