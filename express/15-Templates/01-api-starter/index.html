express.json + health

Minimal JSON API with health route

Starter Server

const express = require("express");
const app = express();

app.use(express.json());

app.get("/health", (req, res) => {
  res.json({ ok: true, site: "phpkingdom.com" });
});

app.listen(process.env.PORT || 3000);

Run

npm install express
node server.js
curl http://localhost:3000/health
