Dockerfile

Containerize a production Express app

Starter Server

# Dockerfile
# FROM node:20-alpine
# WORKDIR /app
# COPY package*.json ./
# RUN npm ci --omit=dev
# COPY . .
# ENV NODE_ENV=production
# EXPOSE 3000
# CMD ["node", "server.js"]

const express = require("express");
const app = express();
app.get("/health", (req, res) => res.json({ ok: true }));
app.listen(process.env.PORT || 3000);

Run

npm install express
node server.js
curl http://localhost:3000/health
