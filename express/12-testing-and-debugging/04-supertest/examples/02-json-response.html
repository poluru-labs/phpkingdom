Study the Express route/middleware pattern and adapt it to your API.

Express

// Supertest — Example 02
// Focus: json response | Scenario: admin backend

const request = require("supertest");
const express = require("express");

const app = express();
app.get("/health", (req, res) => res.json({ ok: true }));

test("health json", async () => {
  await request(app)
    .get("/health")
    .expect("Content-Type", /json/)
    .expect(200, { ok: true });
});
// supertest drives the Express app in-process — no real port needed

Practice Notes

Checklist for Supertest
- Practice: json response
- Scenario: admin backend
- Keep route handlers thin; push logic into controllers/services
- Always attach final 4-arg error middleware
- Validate input; load secrets from environment variables
- Export app separately from listen() for easier testing
