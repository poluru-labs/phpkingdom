// Express Deployment — Example 21
// Focus: static public | Scenario: REST API

// Procfile / start: node server.js
// ENV: NODE_ENV=production PORT=… JWT_SECRET=… DATABASE_URL=…

const port = process.env.PORT || 3000;
app.listen(port, () => console.log(`listening ${port}`));

process.on("SIGTERM", () => {
  console.log("shutting down");
  process.exit(0);
});

Practice Notes

Checklist for Express Deployment
- Practice: static public
- Scenario: REST API
- Keep route handlers thin; push logic into controllers/services
- Always attach final 4-arg error middleware
- Validate input; load secrets from environment variables
- Export app separately from listen() for easier testing

Useful commands:
  npm init -y
  npm install express
  node --watch server.js
  curl http://localhost:3000/health
  npx jest   # or node --test / mocha + supertest
