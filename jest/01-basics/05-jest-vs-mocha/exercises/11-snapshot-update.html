Jest

// Jest vs Mocha — Exercise 11
// Focus: snapshot update | Scenario: utility library

// Jest = batteries included (assert + mock + snapshot + coverage)
// Mocha = runner only; pair with Chai + Sinon + nyc

// Mocha-style:
// const { expect } = require('chai');
// describe('sum', () => {
//   it('adds', () => expect(sum(1, 2)).to.equal(3));
// });

// Jest-style (built-in expect + jest.fn):
const api = { fetch: jest.fn().mockResolvedValue({ ok: true }) };

test("jest bundles mock + assert", async () => {
  await expect(api.fetch()).resolves.toEqual({ ok: true });
  expect(api.fetch).toHaveBeenCalledTimes(1);
});

Practice Notes

Checklist for Jest vs Mocha
- Practice: snapshot update
- Scenario: utility library
- Keep arrange / act / assert clear and deterministic
- Clear or restore mocks between tests (clearMocks / restoreMocks)
- Prefer async/await with resolves / rejects over done()
- Mock at boundaries; avoid over-mocking pure logic
- Review snapshot diffs before updating

Useful commands:
  npm install --save-dev jest
  npx jest
  npx jest --watch
  npx jest --coverage
  npx jest -u
