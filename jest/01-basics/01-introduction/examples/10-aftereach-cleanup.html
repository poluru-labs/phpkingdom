// Jest - Introduction — Example 10
// Focus: afterEach cleanup | Scenario: data layer

// Jest = zero-config JS test runner with matchers, mocks, snapshots, coverage
// Install: npm install --save-dev jest
// package.json: "scripts": { "test": "jest" }

function greet(name) {
  return `Hello, ${name}`;
}

test("greets phpkingdom.com visitors", () => {
  expect(greet("Ada")).toBe("Hello, Ada");
});
// Run: npx jest

Practice Notes

Checklist for Jest - Introduction
- Practice: afterEach cleanup
- Scenario: data layer
- Keep arrange / act / assert clear and deterministic
- Clear or restore mocks between tests (clearMocks / restoreMocks)
- Prefer async/await with resolves / rejects over done()
- Mock at boundaries; avoid over-mocking pure logic
- Review snapshot diffs before updating

Useful commands:
  npm install --save-dev jest
  npx jest
  npx jest --watch
  npx jest --coverage
  npx jest -u
