Jest

// Setup Files — Exercise 11
// Focus: snapshot update | Scenario: utility library

// jest.config.js
module.exports = {
  setupFiles: ["<rootDir>/jest.setup.env.js"],
  setupFilesAfterEnv: ["<rootDir>/jest.setup.after.js"],
};

// jest.setup.env.js — runs before the test framework is installed
process.env.TZ = "UTC";
process.env.API_URL = "http://localhost:4010";

// jest.setup.after.js — runs after Jest is installed (expect available)
require("@testing-library/jest-dom");
jest.setTimeout(15000);

Practice Notes

Checklist for Setup Files
- Practice: snapshot update
- Scenario: utility library
- Keep arrange / act / assert clear and deterministic
- Clear or restore mocks between tests (clearMocks / restoreMocks)
- Prefer async/await with resolves / rejects over done()
- Mock at boundaries; avoid over-mocking pure logic
- Review snapshot diffs before updating

Useful commands:
  npm install --save-dev jest
  npx jest
  npx jest --watch
  npx jest --coverage
  npx jest -u
