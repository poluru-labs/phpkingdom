// Test Environment — Example 20

// Node (default for many CLIs/APIs)
/** @type {import('jest').Config} */
const nodeConfig = {
  testEnvironment: "node",
};

// Browser-like DOM APIs (document, window)
const jsdomConfig = {
  testEnvironment: "jsdom",
};

// Per-file override at top of a test file:
/**
 * @jest-environment jsdom
 */
test("has document", () => {
  expect(typeof document).toBe("object");
});

Practice Notes

Checklist for Test Environment
- Practice: inline snapshot
- Scenario: data layer
- Keep arrange / act / assert clear and deterministic
- Clear or restore mocks between tests (clearMocks / restoreMocks)
- Prefer async/await with resolves / rejects over done()
- Mock at boundaries; avoid over-mocking pure logic
- Review snapshot diffs before updating

Useful commands:
  npm install --save-dev jest
  npx jest
  npx jest --watch
  npx jest --coverage
  npx jest -u
