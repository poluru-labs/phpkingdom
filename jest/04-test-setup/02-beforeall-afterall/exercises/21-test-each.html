Exercise 21

beforeAll and afterAll

Section: Test Setup

Focus: Test.Each

Scenario: utility library

Complete the task locally and verify with npx jest.

Jest

// beforeAll and afterAll — Exercise 21
// Focus: test.each | Scenario: utility library

let server;

beforeAll(async () => {
  server = { port: 3000, started: true };
});

afterAll(async () => {
  server.started = false;
  server = null;
});

test("server is up", () => {
  expect(server.started).toBe(true);
});

test("port is set", () => {
  expect(server.port).toBe(3000);
});
// Use beforeAll for expensive shared setup (DB container, HTTP server)

Practice Notes

Checklist for beforeAll and afterAll
- Practice: test.each
- Scenario: utility library
- Keep arrange / act / assert clear and deterministic
- Clear or restore mocks between tests (clearMocks / restoreMocks)
- Prefer async/await with resolves / rejects over done()
- Mock at boundaries; avoid over-mocking pure logic
- Review snapshot diffs before updating
