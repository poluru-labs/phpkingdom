beforeEach and afterEach

Section: Test Setup

Focus: Express Route

Scenario: Vue app

Study the Jest pattern and adapt matchers, mocks, or async flow to your project.

Jest

// beforeEach and afterEach — Example 23
// Focus: express route | Scenario: Vue app

let db;

beforeEach(() => {
  db = { users: [] };
});

afterEach(() => {
  db = null;
});

test("starts empty", () => {
  expect(db.users).toHaveLength(0);
});

test("can insert", () => {
  db.users.push({ id: 1 });
  expect(db.users).toHaveLength(1);
});
// beforeEach/afterEach run around every test in this file/describe

Practice Notes

Checklist for beforeEach and afterEach
- Practice: express route
- Scenario: Vue app
- Keep arrange / act / assert clear and deterministic
- Clear or restore mocks between tests (clearMocks / restoreMocks)
- Prefer async/await with resolves / rejects over done()
- Mock at boundaries; avoid over-mocking pure logic
- Review snapshot diffs before updating
