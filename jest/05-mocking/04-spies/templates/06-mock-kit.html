Jest

// Jest Spies — Template 06
// Focus: mock kit | Scenario: design system

const calculator = {
  multiply(a, b) {
    return a * b;
  },
  square(n) {
    return this.multiply(n, n);
  },
};

test("spyOn wraps a real method", () => {
  const spy = jest.spyOn(calculator, "multiply");
  expect(calculator.square(4)).toBe(16);
  expect(spy).toHaveBeenCalledWith(4, 4);
  spy.mockRestore();
});

test("spy can stub implementation", () => {
  const log = jest.spyOn(console, "log").mockImplementation(() => {});
  console.log("silent");
  expect(log).toHaveBeenCalledWith("silent");
  log.mockRestore();
});

Practice Notes

Checklist for Jest Spies
- Practice: mock kit
- Scenario: design system
- Keep arrange / act / assert clear and deterministic
- Clear or restore mocks between tests (clearMocks / restoreMocks)
- Prefer async/await with resolves / rejects over done()
- Mock at boundaries; avoid over-mocking pure logic
- Review snapshot diffs before updating

Useful commands:
  npm install --save-dev jest
  npx jest
  npx jest --watch
  npx jest --coverage
  npx jest -u
