Jest

// Mock Implementations — Example 03
// Focus: toBe matcher | Scenario: Vue app

test("mockImplementation replaces behavior", () => {
  const price = jest.fn().mockImplementation((sku) => {
    if (sku === "PRO") return 99;
    return 0;
  });
  expect(price("PRO")).toBe(99);
  expect(price("FREE")).toBe(0);
});

test("mockImplementationOnce chains", () => {
  const flip = jest
    .fn()
    .mockImplementationOnce(() => "heads")
    .mockImplementationOnce(() => "tails");
  expect(flip()).toBe("heads");
  expect(flip()).toBe("tails");
});

Practice Notes

Checklist for Mock Implementations
- Practice: toBe matcher
- Scenario: Vue app
- Keep arrange / act / assert clear and deterministic
- Clear or restore mocks between tests (clearMocks / restoreMocks)
- Prefer async/await with resolves / rejects over done()
- Mock at boundaries; avoid over-mocking pure logic
- Review snapshot diffs before updating

Useful commands:

  npx jest
  npx jest --watch
  npx jest --coverage
  npx jest -u
