Jest

// Auto Mocking — Exercise 24
// Focus: isolate modules | Scenario: Express API

// Automock every export as jest.fn()
jest.mock("./math", () => jest.createMockFromModule("./math"));

// Or enable globally:
// automock: true in jest.config.js (rarely recommended)

const math = require("./math");

test("automocked exports are mock functions", () => {
  math.add.mockReturnValue(10);
  expect(math.add(1, 2)).toBe(10);
  expect(jest.isMockFunction(math.add)).toBe(true);
});
// Prefer explicit jest.mock factories over blanket automock

Practice Notes

Checklist for Auto Mocking
- Practice: isolate modules
- Scenario: Express API
- Keep arrange / act / assert clear and deterministic
- Clear or restore mocks between tests (clearMocks / restoreMocks)
- Prefer async/await with resolves / rejects over done()
- Mock at boundaries; avoid over-mocking pure logic
- Review snapshot diffs before updating

Useful commands:
  npm install --save-dev jest
  npx jest
  npx jest --watch
  npx jest --coverage
  npx jest -u
