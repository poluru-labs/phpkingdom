Manual Mocks

Section: Module Mocks

Focus: Setup Hooks

Scenario: Express API

Complete the task locally and verify with npx jest.

Jest

// Manual Mocks — Exercise 04
// Focus: setup hooks | Scenario: Express API

// File layout:
// src/fsUtil.js
// src/__mocks__/fsUtil.js   ← manual mock

// __mocks__/fsUtil.js
module.exports = {
  readConfig: jest.fn(() => ({ site: "phpkingdom.com" })),
};

// fsUtil.test.js
jest.mock("./fsUtil"); // uses src/__mocks__/fsUtil.js
const fsUtil = require("./fsUtil");

test("manual mock supplies readConfig", () => {
  expect(fsUtil.readConfig()).toEqual({ site: "phpkingdom.com" });
});
// jest.requireActual('./fsUtil') restores the real module when needed

Practice Notes

Checklist for Manual Mocks
- Practice: setup hooks
- Scenario: Express API
- Keep arrange / act / assert clear and deterministic
- Clear or restore mocks between tests (clearMocks / restoreMocks)
- Prefer async/await with resolves / rejects over done()
- Mock at boundaries; avoid over-mocking pure logic
- Review snapshot diffs before updating

Useful commands:
  npm install --save-dev jest
  npx jest
  npx jest --watch
  npx jest --coverage
  npx jest -u
