Jest

// Mock Node Modules — Example 06
// Focus: number range | Scenario: design system

// Mock a third-party package
jest.mock("axios", () => ({
  get: jest.fn(),
  post: jest.fn(),
}));

const axios = require("axios");
const { fetchPosts } = require("./posts");

test("fetchPosts uses axios.get", async () => {
  axios.get.mockResolvedValue({ data: [{ id: 1 }] });
  await expect(fetchPosts()).resolves.toEqual([{ id: 1 }]);
  expect(axios.get).toHaveBeenCalledWith("/api/posts");
});
// Manual mock path: __mocks__/axios.js at project root next to node_modules

Practice Notes

Checklist for Mock Node Modules
- Practice: number range
- Scenario: design system
- Keep arrange / act / assert clear and deterministic
- Clear or restore mocks between tests (clearMocks / restoreMocks)
- Prefer async/await with resolves / rejects over done()
- Mock at boundaries; avoid over-mocking pure logic
- Review snapshot diffs before updating
