Jest

// Mock ES Modules — Example 06
// Focus: number range | Scenario: design system

// ESM mocking (experimental / node --experimental-vm-modules)
import { jest } from "@jest/globals";

jest.unstable_mockModule("./logger.js", () => ({
  log: jest.fn(),
}));

const { log } = await import("./logger.js");
const { run } = await import("./job.js");

test("esm module mock", async () => {
  run("deploy");
  expect(log).toHaveBeenCalledWith("deploy");
});
// Prefer CJS jest.mock when the codebase still uses require()

Practice Notes

Checklist for Mock ES Modules
- Practice: number range
- Scenario: design system
- Keep arrange / act / assert clear and deterministic
- Clear or restore mocks between tests (clearMocks / restoreMocks)
- Prefer async/await with resolves / rejects over done()
- Mock at boundaries; avoid over-mocking pure logic
- Review snapshot diffs before updating
