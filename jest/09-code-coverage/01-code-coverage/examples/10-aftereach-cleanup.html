// Code Coverage — Example 10
// Focus: afterEach cleanup | Scenario: data layer

// package.json
// "test:coverage": "jest --coverage"

function abs(n) {
  if (n < 0) return -n;
  return n;
}

test("covers both branches", () => {
  expect(abs(-3)).toBe(3);
  expect(abs(2)).toBe(2);
});
// Coverage marks uncovered lines/branches in the HTML report

Practice Notes

Checklist for Code Coverage
- Practice: afterEach cleanup
- Scenario: data layer
- Keep arrange / act / assert clear and deterministic
- Clear or restore mocks between tests (clearMocks / restoreMocks)
- Prefer async/await with resolves / rejects over done()
- Mock at boundaries; avoid over-mocking pure logic
- Review snapshot diffs before updating

Useful commands:
  npm install --save-dev jest
  npx jest
  npx jest --watch
  npx jest --coverage
  npx jest -u
