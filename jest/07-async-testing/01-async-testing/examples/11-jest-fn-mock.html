Jest

// Async Testing — Example 11
// Focus: jest.fn mock | Scenario: utility library

async function loadSettings() {
  return { theme: "light", site: "phpkingdom.com" };
}

test("async function with await", async () => {
  const settings = await loadSettings();
  expect(settings.theme).toBe("light");
});

test("async with resolves matcher", async () => {
  await expect(loadSettings()).resolves.toHaveProperty("site");
});
// Always return/await promises — do not leave floating promises

Practice Notes

Checklist for Async Testing
- Practice: jest.fn mock
- Scenario: utility library
- Keep arrange / act / assert clear and deterministic
- Clear or restore mocks between tests (clearMocks / restoreMocks)
- Prefer async/await with resolves / rejects over done()
- Mock at boundaries; avoid over-mocking pure logic
- Review snapshot diffs before updating

Useful commands:

  npx jest
  npx jest --watch
  npx jest --coverage
  npx jest -u
