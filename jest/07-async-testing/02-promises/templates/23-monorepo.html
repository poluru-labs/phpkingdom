// Testing Promises — Template 23
// Focus: monorepo | Scenario: Vue app

function fetchOk() {
  return Promise.resolve({ status: 200 });
}

function fetchFail() {
  return Promise.reject(new Error("network"));
}

test("resolves", () => {
  return expect(fetchOk()).resolves.toEqual({ status: 200 });
});

test("rejects", () => {
  return expect(fetchFail()).rejects.toThrow("network");
});
// Returning the assertion promise keeps Jest waiting

Practice Notes

Checklist for Testing Promises
- Practice: monorepo
- Scenario: Vue app
- Keep arrange / act / assert clear and deterministic
- Clear or restore mocks between tests (clearMocks / restoreMocks)
- Prefer async/await with resolves / rejects over done()
- Mock at boundaries; avoid over-mocking pure logic
- Review snapshot diffs before updating
