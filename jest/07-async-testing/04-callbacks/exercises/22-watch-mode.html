Testing Callbacks

Jest

// Testing Callbacks — Exercise 22
// Focus: watch mode | Scenario: React app

function fetchData(cb) {
  setTimeout(() => cb(null, { ok: true }), 10);
}

test("callback style with done", (done) => {
  fetchData((err, data) => {
    try {
      expect(err).toBeNull();
      expect(data).toEqual({ ok: true });
      done();
    } catch (e) {
      done(e);
    }
  });
});
// Prefer promisify + async/await when you control the API

Practice Notes

Checklist for Testing Callbacks
- Practice: watch mode
- Scenario: React app
- Keep arrange / act / assert clear and deterministic
- Clear or restore mocks between tests (clearMocks / restoreMocks)
- Prefer async/await with resolves / rejects over done()
- Mock at boundaries; avoid over-mocking pure logic
- Review snapshot diffs before updating
