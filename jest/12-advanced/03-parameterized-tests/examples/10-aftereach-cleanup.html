Parameterized Tests

Focus: Aftereach Cleanup

Study the Jest pattern and adapt matchers, mocks, or async flow to your project.

Jest

// Parameterized Tests — Example 10
// Focus: afterEach cleanup | Scenario: data layer

function add(a, b) {
  return a + b;
}

test.each([
  [1, 1, 2],
  [1, 2, 3],
  [2, 2, 4],
])("add(%i, %i) => %i", (a, b, expected) => {
  expect(add(a, b)).toBe(expected);
});

describe.each([
  { input: "a", len: 1 },
  { input: "ab", len: 2 },
])("string length", ({ input, len }) => {
  test(`${input} has length ${len}`, () => {
    expect(input).toHaveLength(len);
  });
});

Practice Notes

Checklist for Parameterized Tests
- Practice: afterEach cleanup
- Scenario: data layer
- Keep arrange / act / assert clear and deterministic
- Clear or restore mocks between tests (clearMocks / restoreMocks)
- Prefer async/await with resolves / rejects over done()
- Mock at boundaries; avoid over-mocking pure logic
- Review snapshot diffs before updating

  npx jest -u
