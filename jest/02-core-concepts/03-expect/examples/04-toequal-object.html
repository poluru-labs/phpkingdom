expect()

Section: Core Concepts

Focus: Toequal Object

Scenario: Express API

Study the Jest pattern and adapt matchers, mocks, or async flow to your project.

Jest

// expect() — Example 04
// Focus: toEqual object | Scenario: Express API

const user = { id: 1, name: "Ada", roles: ["admin"] };

test("expect wraps a value and chains matchers", () => {
  expect(user.name).toBe("Ada");
  expect(user).toEqual({ id: 1, name: "Ada", roles: ["admin"] });
  expect(user.roles).toContain("admin");
  expect(user.email).toBeUndefined();
});
// Soft assertions are not default — one failure stops the test

Practice Notes

Checklist for expect()
- Practice: toEqual object
- Scenario: Express API
- Keep arrange / act / assert clear and deterministic
- Clear or restore mocks between tests (clearMocks / restoreMocks)
- Prefer async/await with resolves / rejects over done()
- Mock at boundaries; avoid over-mocking pure logic
- Review snapshot diffs before updating

Useful commands:
  npm install --save-dev jest
  npx jest
  npx jest --watch
  npx jest --coverage
  npx jest -u
