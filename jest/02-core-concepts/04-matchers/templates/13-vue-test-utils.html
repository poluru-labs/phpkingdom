// Focus: vue test utils | Scenario: Vue app

test("matcher tour for a pricing object", () => {
  const price = { amount: 19.99, currency: "USD", tags: ["sale"] };

  expect(price.amount).toBeCloseTo(19.99);
  expect(price.currency).toMatch(/USD/);
  expect(price.tags).toEqual(expect.arrayContaining(["sale"]));
  expect(price).toEqual(
    expect.objectContaining({ currency: "USD" })
  );
});
// Prefer specific matchers over generic toBe(true)

Practice Notes

Checklist for Jest Matchers
- Practice: vue test utils
- Scenario: Vue app
- Keep arrange / act / assert clear and deterministic
- Clear or restore mocks between tests (clearMocks / restoreMocks)
- Prefer async/await with resolves / rejects over done()
- Mock at boundaries; avoid over-mocking pure logic
- Review snapshot diffs before updating

Useful commands:
  npm install --save-dev jest
  npx jest
  npx jest --watch
  npx jest --coverage
  npx jest -u
