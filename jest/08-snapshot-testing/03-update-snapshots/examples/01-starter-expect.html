Jest

// Update Snapshots — Example 01
// Focus: starter expect | Scenario: utility library

// Update all snapshots:
//   npx jest --updateSnapshot
//   npx jest -u
//
// Update interactive in watch mode: press u
//
// Snapshot files live next to tests:
//   __snapshots__/Header.test.js.snap

test("banner", () => {
  expect({ title: "Sale", tone: "pink" }).toMatchSnapshot();
});
// Commit snapshot files; treat them as reviewed expected output

Practice Notes

Checklist for Update Snapshots
- Practice: starter expect
- Scenario: utility library
- Keep arrange / act / assert clear and deterministic
- Clear or restore mocks between tests (clearMocks / restoreMocks)
- Prefer async/await with resolves / rejects over done()
- Mock at boundaries; avoid over-mocking pure logic
- Review snapshot diffs before updating

Useful commands:
  npm install --save-dev jest
  npx jest
  npx jest --watch
  npx jest --coverage
  npx jest -u

Notes
