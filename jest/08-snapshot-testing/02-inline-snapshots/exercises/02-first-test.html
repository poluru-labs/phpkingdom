Exercise 02

Inline Snapshots

Section: Snapshot Testing

Focus: First Test

Scenario: React app

Complete the task locally and verify with npx jest.

Jest

// Inline Snapshots — Exercise 02
// Focus: first test | Scenario: React app

test("inline snapshot keeps expected value in the test file", () => {
  expect({ ok: true, site: "phpkingdom.com" }).toMatchInlineSnapshot(`
    {
      "ok": true,
      "site": "phpkingdom.com",
    }
  `);
});

test("string inline snapshot", () => {
  expect("jest").toMatchInlineSnapshot(`"jest"`);
});
// npx jest -u updates inline snapshots in-place

Practice Notes

Checklist for Inline Snapshots
- Practice: first test
- Scenario: React app
- Keep arrange / act / assert clear and deterministic
- Clear or restore mocks between tests (clearMocks / restoreMocks)
- Prefer async/await with resolves / rejects over done()
- Mock at boundaries; avoid over-mocking pure logic
- Review snapshot diffs before updating

Useful commands:
  npm install --save-dev jest
  npx jest
  npx jest --watch
  npx jest --coverage
  npx jest -u
