// Snapshot Testing — Exercise 10
// Focus: timer advance | Scenario: data layer

function renderHeader(title) {
  return {
    type: "header",
    props: { title, site: "phpkingdom.com" },
  };
}

test("header snapshot", () => {
  expect(renderHeader("Home")).toMatchSnapshot();
});
// First run writes __snapshots__/file.test.js.snap
// Review diffs carefully before updating

Practice Notes

Checklist for Snapshot Testing
- Practice: timer advance
- Scenario: data layer
- Keep arrange / act / assert clear and deterministic
- Clear or restore mocks between tests (clearMocks / restoreMocks)
- Prefer async/await with resolves / rejects over done()
- Mock at boundaries; avoid over-mocking pure logic
- Review snapshot diffs before updating

Useful commands:
  npm install --save-dev jest
  npx jest
  npx jest --watch
  npx jest --coverage
  npx jest -u
