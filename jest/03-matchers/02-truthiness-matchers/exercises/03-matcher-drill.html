// Truthiness Matchers — Exercise 03
// Focus: matcher drill | Scenario: Vue app

test("truthiness matchers", () => {
  expect(null).toBeNull();
  expect(undefined).toBeUndefined();
  expect(true).toBeTruthy();
  expect(1).toBeTruthy();
  expect("").toBeFalsy();
  expect(0).toBeFalsy();
  expect(false).toBeFalsy();
  // Prefer toBeNull / toBeUndefined when you know the exact value
});

Practice Notes

Checklist for Truthiness Matchers
- Practice: matcher drill
- Scenario: Vue app
- Keep arrange / act / assert clear and deterministic
- Clear or restore mocks between tests (clearMocks / restoreMocks)
- Prefer async/await with resolves / rejects over done()
- Mock at boundaries; avoid over-mocking pure logic
- Review snapshot diffs before updating

Useful commands:
  npm install --save-dev jest
  npx jest
  npx jest --watch
  npx jest --coverage
  npx jest -u
