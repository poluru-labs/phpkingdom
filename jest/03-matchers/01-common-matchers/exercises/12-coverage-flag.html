// Common Matchers — Exercise 12
// Focus: coverage flag | Scenario: React app

test("common equality and identity matchers", () => {
  expect(2 + 2).toBe(4); // === for primitives
  expect({ a: 1 }).toEqual({ a: 1 }); // deep equality
  expect({ a: 1 }).not.toBe({ a: 1 }); // different references
  expect(Number.NaN).toBeNaN();
  expect(undefined).toBeUndefined();
  expect(null).toBeNull();
  expect("jest").toBeDefined();
});

Practice Notes

Checklist for Common Matchers
- Practice: coverage flag
- Scenario: React app
- Keep arrange / act / assert clear and deterministic
- Clear or restore mocks between tests (clearMocks / restoreMocks)
- Prefer async/await with resolves / rejects over done()
- Mock at boundaries; avoid over-mocking pure logic
- Review snapshot diffs before updating

Useful commands:
  npm install --save-dev jest
  npx jest
  npx jest --watch
  npx jest --coverage
  npx jest -u
