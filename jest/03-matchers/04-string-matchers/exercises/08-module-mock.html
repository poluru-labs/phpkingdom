Jest

// String Matchers — Exercise 08
// Focus: module mock | Scenario: cart module

test("string matchers", () => {
  expect("Welcome to phpkingdom.com").toMatch(/phpkingdom/i);
  expect("hello").toMatch(/^h/);
  expect("Ada Lovelace").toContain("Love");
  expect("abc").toHaveLength(3);
});

Practice Notes

Checklist for String Matchers
- Practice: module mock
- Scenario: cart module
- Keep arrange / act / assert clear and deterministic
- Clear or restore mocks between tests (clearMocks / restoreMocks)
- Prefer async/await with resolves / rejects over done()
- Mock at boundaries; avoid over-mocking pure logic
- Review snapshot diffs before updating
