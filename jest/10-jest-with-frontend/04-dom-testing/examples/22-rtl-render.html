Jest

// DOM Testing — Example 22
// Focus: rtl render | Scenario: React app

/**
 * @jest-environment jsdom
 */

test("create and query DOM nodes", () => {
  document.body.innerHTML = `<form>
    <label for="email">Email</label>
    <input id="email" value="ada@phpkingdom.com" />
  </form>`;

  const input = document.getElementById("email");
  expect(input.value).toBe("ada@phpkingdom.com");
  input.value = "grace@phpkingdom.com";
  expect(input.value).toContain("grace");
});

Practice Notes

Checklist for DOM Testing
- Practice: rtl render
- Scenario: React app
- Keep arrange / act / assert clear and deterministic
- Clear or restore mocks between tests (clearMocks / restoreMocks)
- Prefer async/await with resolves / rejects over done()
- Mock at boundaries; avoid over-mocking pure logic
- Review snapshot diffs before updating
