Jest

// Jest with React — Exercise 14
// Focus: rtl click | Scenario: Express API

/** @jsxImportSource react */
import React from "react";
import { render, screen } from "@testing-library/react";

function Hello({ name }) {
  return <h1>Hello {name}</h1>;
}

test("renders React component", () => {
  render(<Hello name="Ada" />);
  expect(screen.getByRole("heading", { name: /hello ada/i })).toBeTruthy();
});
// jest.config: testEnvironment: 'jsdom', transform for JSX

Practice Notes

Checklist for Jest with React
- Practice: rtl click
- Scenario: Express API
- Keep arrange / act / assert clear and deterministic
- Clear or restore mocks between tests (clearMocks / restoreMocks)
- Prefer async/await with resolves / rejects over done()
- Mock at boundaries; avoid over-mocking pure logic
- Review snapshot diffs before updating

Useful commands:
  npm install --save-dev jest
  npx jest
  npx jest --watch
  npx jest --coverage
  npx jest -u
