// jest-dom Matchers — Example 15
// Focus: manual mock | Scenario: Node CLI

// npm i -D @testing-library/jest-dom
// setupFilesAfterEnv: ['@testing-library/jest-dom']

import { render, screen } from "@testing-library/react";

function Login() {
  return (
    <main>
      <h1>Sign in</h1>
      <button type="submit" disabled>
        Continue
      </button>
    </main>
  );
}

test("jest-dom matchers read like English", () => {
  render(<Login />);
  expect(screen.getByRole("heading")).toHaveTextContent("Sign in");
  expect(screen.getByRole("button")).toBeDisabled();
  expect(screen.getByRole("main")).toBeVisible();
});

Practice Notes

Checklist for jest-dom Matchers
- Practice: manual mock
- Scenario: Node CLI
- Keep arrange / act / assert clear and deterministic
- Clear or restore mocks between tests (clearMocks / restoreMocks)
- Prefer async/await with resolves / rejects over done()
- Mock at boundaries; avoid over-mocking pure logic
- Review snapshot diffs before updating

Useful commands:
  npm install --save-dev jest
  npx jest
  npx jest --watch
  npx jest --coverage
  npx jest -u
