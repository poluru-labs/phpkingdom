// Jenkins — Template 18
// Focus: plugin pack | Scenario: TypeScript SDK

// Jenkinsfile sketch for Karma
pipeline {
  agent any
  environment { CI = "true" }
  stages {
    stage("Install") {
      steps { sh "npm ci" }
    }
    stage("Test") {
      steps {
        sh "npm test"
      }
      post {
        always {
          junit "reports/junit/*.xml"
          publishHTML(target: [
            reportDir: "coverage/html",
            reportFiles: "index.html",
            reportName: "Coverage",
          ])
        }
      }
    }
  }
}

Practice Notes

Checklist for Jenkins
- Practice: plugin pack
- Scenario: TypeScript SDK
- Prefer ChromeHeadless (+ CI flags) for automation
- Keep singleRun/autoWatch gated on process.env.CI
- Pair frameworks (Jasmine/Mocha) with explicit plugins[]
- Add junit + coverage reporters for CI gates
- Open /debug.html with headed Chrome when diagnosing flakes

Useful commands:
  npm i -D karma karma-jasmine jasmine-core karma-chrome-launcher
  npx karma init
  npx karma start --single-run
  npx karma start --browsers=Chrome
