// GitLab CI — Exercise 05
// Focus: launcher setup | Scenario: design system

# .gitlab-ci.yml
image: node:20-bookworm

variables:
  CI: "true"
  CHROME_BIN: "/usr/bin/chromium"

before_script:
  - apt-get update && apt-get install -y chromium
  - npm ci

test:
  script:
    - npm test
  artifacts:
    when: always
    reports:
      junit: reports/junit/karma-results.xml
    paths:
      - coverage/
# karma browsers: ChromeHeadlessCI with --no-sandbox

Practice Notes

Checklist for GitLab CI
- Practice: launcher setup
- Scenario: design system
- Prefer ChromeHeadless (+ CI flags) for automation
- Keep singleRun/autoWatch gated on process.env.CI
- Pair frameworks (Jasmine/Mocha) with explicit plugins[]
- Add junit + coverage reporters for CI gates
- Open /debug.html with headed Chrome when diagnosing flakes

Useful commands:
  npm i -D karma karma-jasmine jasmine-core karma-chrome-launcher
  npx karma init
  npx karma start --single-run
  npx karma start --browsers=Chrome
