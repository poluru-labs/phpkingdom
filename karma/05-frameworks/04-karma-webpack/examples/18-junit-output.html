Karma

// Karma with Webpack — Example 18
// Focus: junit output | Scenario: TypeScript SDK

// karma-webpack bundles ES modules / TS for the browser
// npm i -D karma-webpack webpack karma-sourcemap-loader

module.exports = function (config) {
  config.set({
    frameworks: ["jasmine"],
    files: ["src/test.js"],
    preprocessors: { "src/test.js": ["webpack", "sourcemap"] },
    webpack: {
      mode: "development",
      module: {
        rules: [{ test: /\.js$/, use: "babel-loader", exclude: /node_modules/ }],
      },
      devtool: "inline-source-map",
    },
    webpackMiddleware: { stats: "errors-only" },
    browsers: ["ChromeHeadless"],
    singleRun: true,
  });
};

Practice Notes

Checklist for Karma with Webpack
- Practice: junit output
- Scenario: TypeScript SDK
- Prefer ChromeHeadless (+ CI flags) for automation
- Keep singleRun/autoWatch gated on process.env.CI
- Pair frameworks (Jasmine/Mocha) with explicit plugins[]
- Add junit + coverage reporters for CI gates
- Open /debug.html with headed Chrome when diagnosing flakes

Useful commands:
  npm i -D karma karma-jasmine jasmine-core karma-chrome-launcher
  npx karma init
  npx karma start --single-run
  npx karma start --browsers=Chrome
