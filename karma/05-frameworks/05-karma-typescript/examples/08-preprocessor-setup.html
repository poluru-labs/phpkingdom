Karma

// Karma with TypeScript — Example 08
// Focus: preprocessor setup | Scenario: TypeScript SDK

// karma-typescript compiles .ts specs without a separate webpack config
// npm i -D karma-typescript typescript

module.exports = function (config) {
  config.set({
    frameworks: ["jasmine", "karma-typescript"],
    files: [{ pattern: "src/**/*.ts" }],
    preprocessors: { "src/**/*.ts": ["karma-typescript"] },
    reporters: ["progress", "karma-typescript"],
    karmaTypescriptConfig: {
      tsconfig: "./tsconfig.spec.json",
      reports: { html: "coverage", "text-summary": "" },
    },
    browsers: ["ChromeHeadless"],
    singleRun: true,
  });
};

Practice Notes

Checklist for Karma with TypeScript
- Practice: preprocessor setup
- Scenario: TypeScript SDK
- Prefer ChromeHeadless (+ CI flags) for automation
- Keep singleRun/autoWatch gated on process.env.CI
- Pair frameworks (Jasmine/Mocha) with explicit plugins[]
- Add junit + coverage reporters for CI gates
- Open /debug.html with headed Chrome when diagnosing flakes

Useful commands:
  npm i -D karma karma-jasmine jasmine-core karma-chrome-launcher
  npx karma init
  npx karma start --single-run
  npx karma start --browsers=Chrome
