Solution 13 — Mocha + Chai

Switch frameworks to mocha and require chai in a sample assertion.

Solution

frameworks: ['mocha', 'chai'],
// npm i -D karma-mocha mocha karma-chai chai

describe('math', function () {
  it('adds', function () {
    expect(2 + 2).to.equal(4);
  });
});
