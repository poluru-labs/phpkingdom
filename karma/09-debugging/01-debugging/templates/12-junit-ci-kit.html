Karma

// Karma Debugging — Template 12
// Focus: junit ci kit | Scenario: legacy SPA

// Debug Karma runs locally with headed Chrome + debug.html
module.exports = function (config) {
  config.set({
    frameworks: ["jasmine"],
    files: ["src/**/*.js", "src/**/*.spec.js"],
    browsers: ["Chrome"],
    singleRun: false,
    autoWatch: true,
    client: { clearContext: false },
    logLevel: config.LOG_DEBUG,
  });
};
// 1) karma start
// 2) open http://localhost:9876/debug.html
// 3) DevTools → Sources → set breakpoints in specs

Practice Notes

Checklist for Karma Debugging
- Practice: junit ci kit
- Scenario: legacy SPA
- Prefer ChromeHeadless (+ CI flags) for automation
- Keep singleRun/autoWatch gated on process.env.CI
- Pair frameworks (Jasmine/Mocha) with explicit plugins[]
- Add junit + coverage reporters for CI gates
- Open /debug.html with headed Chrome when diagnosing flakes

Useful commands:
  npm i -D karma karma-jasmine jasmine-core karma-chrome-launcher
  npx karma init
  npx karma start --single-run
  npx karma start --browsers=Chrome
