// Progress Reporter — Example 24
// Focus: service spec | Scenario: admin dashboard

// Built-in progress reporter — compact dots / OK counts
module.exports = function (config) {
  config.set({
    frameworks: ["jasmine"],
    files: ["src/**/*.spec.js"],
    reporters: ["progress"],
    browsers: ["ChromeHeadless"],
    singleRun: true,
    colors: true,
  });
};
// Output looks like: ChromeHeadless ... SUCCESS
// Pair with spec reporter when you need per-test names locally

Practice Notes

Checklist for Progress Reporter
- Practice: service spec
- Scenario: admin dashboard
- Prefer ChromeHeadless (+ CI flags) for automation
- Keep singleRun/autoWatch gated on process.env.CI
- Pair frameworks (Jasmine/Mocha) with explicit plugins[]
- Add junit + coverage reporters for CI gates
- Open /debug.html with headed Chrome when diagnosing flakes

Useful commands:
  npm i -D karma karma-jasmine jasmine-core karma-chrome-launcher
  npx karma init
  npx karma start --single-run
