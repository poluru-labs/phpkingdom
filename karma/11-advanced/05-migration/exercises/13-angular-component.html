// Karma Migration — Exercise 13
// Focus: angular component | Scenario: component library

// Migrating legacy Karma configs
// 1) Replace PhantomJS → ChromeHeadless (+ CI flags)
// 2) Explicit plugins[] list; drop deprecated preprocessors
// 3) singleRun/autoWatch gated on process.env.CI
// 4) Add junit + coverage thresholds for gates
// 5) Prefer Angular builder / Vitest/Jest when leaving browser-runner era

module.exports = function (config) {
  config.set({
    frameworks: ["jasmine"],
    // browsers: ["PhantomJS"], // REMOVED
    browsers: ["ChromeHeadless"],
    customLaunchers: {
      ChromeHeadlessCI: {
        base: "ChromeHeadless",
        flags: ["--no-sandbox", "--disable-gpu"],
      },
    },
    singleRun: true,
    autoWatch: false,
  });
};

Practice Notes

Checklist for Karma Migration
- Practice: angular component
- Scenario: component library
- Prefer ChromeHeadless (+ CI flags) for automation
- Keep singleRun/autoWatch gated on process.env.CI
- Pair frameworks (Jasmine/Mocha) with explicit plugins[]
- Add junit + coverage reporters for CI gates
- Open /debug.html with headed Chrome when diagnosing flakes

Useful commands:
  npm i -D karma karma-jasmine jasmine-core karma-chrome-launcher
  npx karma init
  npx karma start --single-run
  npx karma start --browsers=Chrome
