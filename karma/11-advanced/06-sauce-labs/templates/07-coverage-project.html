Karma

// Sauce Labs / BrowserStack — Template 07
// Focus: coverage project | Scenario: monorepo package

// Sauce Labs / BrowserStack via karma-sauce-launcher
// npm i -D karma-sauce-launcher

module.exports = function (config) {
  config.set({
    frameworks: ["jasmine"],
    files: ["src/**/*.spec.js"],
    reporters: ["progress", "saucelabs"],
    sauceLabs: {
      testName: "Karma cross-browser",
      region: "us",
      startConnect: true,
    },
    customLaunchers: {
      sl_chrome: {
        base: "SauceLabs",
        browserName: "chrome",
        platform: "Windows 11",
        version: "latest",
      },
      sl_safari: {
        base: "SauceLabs",
        browserName: "safari",
        platform: "macOS 13",
        version: "latest",
      },
    },
    browsers: ["sl_chrome", "sl_safari"],
    singleRun: true,
    // SAUCE_USERNAME / SAUCE_ACCESS_KEY required
  });
};

Practice Notes

Checklist for Sauce Labs / BrowserStack
- Practice: coverage project
- Scenario: monorepo package
- Prefer ChromeHeadless (+ CI flags) for automation
- Keep singleRun/autoWatch gated on process.env.CI
- Pair frameworks (Jasmine/Mocha) with explicit plugins[]
- Add junit + coverage reporters for CI gates
- Open /debug.html with headed Chrome when diagnosing flakes

Useful commands:
  npm i -D karma karma-jasmine jasmine-core karma-chrome-launcher
  npx karma init
  npx karma start --single-run
  npx karma start --browsers=Chrome

Notes
