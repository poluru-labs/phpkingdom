// Parallel browser runs — capture multiple launchers at once
module.exports = function (config) {
  config.set({
    frameworks: ["jasmine"],
    files: ["src/**/*.spec.js"],
    browsers: ["ChromeHeadless", "FirefoxHeadless"],
    concurrency: 2,
    reporters: ["progress"],
    singleRun: true,
    browserDisconnectTolerance: 2,
  });
};
// Watch CPU: each headed browser is expensive; prefer headless in CI

Practice Notes

Checklist for Parallel Browser Runs
- Practice: plugin enable
- Scenario: TypeScript SDK
- Prefer ChromeHeadless (+ CI flags) for automation
- Keep singleRun/autoWatch gated on process.env.CI
- Pair frameworks (Jasmine/Mocha) with explicit plugins[]
- Add junit + coverage reporters for CI gates
- Open /debug.html with headed Chrome when diagnosing flakes

Useful commands:
  npm i -D karma karma-jasmine jasmine-core karma-chrome-launcher
  npx karma init
  npx karma start --single-run
  npx karma start --browsers=Chrome
