// Puppeteer Launcher — Exercise 08
// Focus: plugin enable | Scenario: TypeScript SDK

// Drive Chrome via Puppeteer's bundled Chromium
// npm i -D puppeteer karma-chrome-launcher

process.env.CHROME_BIN = require("puppeteer").executablePath();

module.exports = function (config) {
  config.set({
    frameworks: ["jasmine"],
    files: ["src/**/*.spec.js"],
    browsers: ["ChromeHeadless"],
    customLaunchers: {
      PuppeteerHeadless: {
        base: "ChromeHeadless",
        flags: ["--no-sandbox", "--disable-gpu"],
      },
    },
    singleRun: true,
  });
};
// Useful in CI images that do not install system Chrome

Practice Notes

Checklist for Puppeteer Launcher
- Practice: plugin enable
- Scenario: TypeScript SDK
- Prefer ChromeHeadless (+ CI flags) for automation
- Keep singleRun/autoWatch gated on process.env.CI
- Pair frameworks (Jasmine/Mocha) with explicit plugins[]
- Add junit + coverage reporters for CI gates
- Open /debug.html with headed Chrome when diagnosing flakes

Useful commands:
  npm i -D karma karma-jasmine jasmine-core karma-chrome-launcher
  npx karma init
  npx karma start --single-run
  npx karma start --browsers=Chrome
