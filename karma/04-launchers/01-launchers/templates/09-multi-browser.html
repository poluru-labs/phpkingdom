// Karma Launchers — Template 09
// Focus: multi browser | Scenario: Webpack app

// Launchers map browser names → npm packages
// karma-chrome-launcher → Chrome, ChromeHeadless, Chromium
// karma-firefox-launcher → Firefox, FirefoxHeadless

module.exports = function (config) {
  config.set({
    frameworks: ["jasmine"],
    files: ["src/**/*.spec.js"],
    browsers: ["ChromeHeadless", "FirefoxHeadless"],
    plugins: [
      "karma-jasmine",
      "karma-chrome-launcher",
      "karma-firefox-launcher",
    ],
    singleRun: true,
  });
};

Practice Notes

Checklist for Karma Launchers
- Practice: multi browser
- Scenario: Webpack app
- Prefer ChromeHeadless (+ CI flags) for automation
- Keep singleRun/autoWatch gated on process.env.CI
- Pair frameworks (Jasmine/Mocha) with explicit plugins[]
- Add junit + coverage reporters for CI gates
- Open /debug.html with headed Chrome when diagnosing flakes

Useful commands:
  npm i -D karma karma-jasmine jasmine-core karma-chrome-launcher
  npx karma init
  npx karma start --single-run
  npx karma start --browsers=Chrome
