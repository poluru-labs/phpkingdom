Solution 07 — v-for List

Render a list with a stable :key.

Solution

<script setup>
const items = [
  { id: 1, label: "Vue" },
  { id: 2, label: "Pinia" },
];
</script>

<template>
  <ul>
    <li v-for="item in items" :key="item.id">{{ item.label }}</li>
  </ul>
</template>
