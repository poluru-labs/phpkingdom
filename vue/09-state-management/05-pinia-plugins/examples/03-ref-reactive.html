Vue.js

// Pinia Plugins — Example 03
// Focus: ref reactive | Scenario: todo app

// pinia persisted-state style plugin sketch
pinia.use(({ store }) => {
  const key = `pinia:${store.$id}`;
  const raw = localStorage.getItem(key);
  if (raw) store.$patch(JSON.parse(raw));
  store.$subscribe((_, state) => {
    localStorage.setItem(key, JSON.stringify(state));
  });
});

Practice Notes

Checklist for Pinia Plugins
- Practice: ref reactive
- Scenario: todo app
- Prefer <script setup> + Composition API for Vue 3
- Use ref for primitives, reactive for objects; computed for derived state
- Key lists with stable ids; v-if for costly trees, v-show for toggles
- Props down / emits up; Pinia or provide/inject for shared state
- Route with vue-router; guard auth; fetch with composables + loading/error
