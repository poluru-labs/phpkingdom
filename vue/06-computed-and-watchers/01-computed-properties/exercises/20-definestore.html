Computed Properties

Section: Computed and Watchers

Focus: Definestore

Scenario: B2B portal

Implement the focus in a Vite + Vue project and verify reactivity in the browser.

Vue.js

// Computed Properties — Exercise 20
// Focus: defineStore | Scenario: B2B portal

<script setup>
import { ref, computed } from "vue";
const first = ref("Ada");
const last = ref("Lovelace");
const fullName = computed(() => `${first.value} ${last.value}`);
</script>

<template>
  <p>{{ fullName }}</p>
</template>

Practice Notes

Checklist for Computed Properties
- Practice: defineStore
- Scenario: B2B portal
- Prefer <script setup> + Composition API for Vue 3
- Use ref for primitives, reactive for objects; computed for derived state
- Key lists with stable ids; v-if for costly trees, v-show for toggles
- Props down / emits up; Pinia or provide/inject for shared state
- Route with vue-router; guard auth; fetch with composables + loading/error
