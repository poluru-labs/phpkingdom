Exercise 24

v-model Modifiers

Section: Forms

Focus: Typed Props

Scenario: e-commerce store

Implement the focus in a Vite + Vue project and verify reactivity in the browser.

Vue.js

// v-model Modifiers — Exercise 24
// Focus: typed props | Scenario: e-commerce store

<script setup>
import { ref } from "vue";
const age = ref(0);
const search = ref("");
</script>

<template>
  <input v-model.number="age" type="number" />
  <input v-model.lazy.trim="search" />
</template>

Practice Notes

Checklist for v-model Modifiers
- Practice: typed props
- Scenario: e-commerce store
- Prefer <script setup> + Composition API for Vue 3
- Use ref for primitives, reactive for objects; computed for derived state
- Key lists with stable ids; v-if for costly trees, v-show for toggles
- Props down / emits up; Pinia or provide/inject for shared state
- Route with vue-router; guard auth; fetch with composables + loading/error

Useful commands:

  npm install
  npm run dev
  npm run build
  npm run type-check   # vue-tsc when TypeScript enabled
