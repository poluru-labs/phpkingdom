## Layout

- `01-Basics` … `07-Styling` — topic examples (typically 5+ HTML files per topic)
- `08-Misc-Examples` — ~100 standalone demos
- `09-Exercises` — 25 Problem → Solution drills
- `10-Table-Examples` — classic table patterns
- `11-Form-Examples` — classic form patterns
- `12-Page-Templates` — 25 full page templates

Every new HTML file includes the metadata comment block (`sitename`, author, email, `autor website`).

## Upgrade / regenerate indexes

```bash
python3 upgrade_html.py
```

The script **adds** missing lessons and templates; it does not overwrite existing lesson HTML.

Last upgrade touched ~0 new files; course topics (01–07) now include **158** HTML examples.
