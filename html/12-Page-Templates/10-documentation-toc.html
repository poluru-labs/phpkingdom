2. Page landmarks

Use semantic wrappers so assistive technology and search engines understand page regions.

ElementTypical use
headerSite branding, top navigation
navPrimary link groups
mainUnique content for this URL
asideRelated sidebar content
footerCopyright, contact, secondary nav

3. Headings

One h1 per page. Do not skip levels for styling convenience — use CSS instead.

<h1>Page title</h1>
<section>
  <h2>Section</h2>
  <h3>Subsection</h3>
</section>

4. Lists

  • ul — unordered bullet lists
  • ol — ordered numbered lists
  • dl — terms and definitions (great for FAQ pages)

5. Tables

Reserve tables for tabular data: pricing, schedules, product specs. Use thead, tbody, and th scope for clarity.

6. Forms

Every input needs a label. Group related fields with fieldset and legend. See contact template and login template for examples.
