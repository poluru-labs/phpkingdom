HTML SEO — Robots Meta Tag

Control indexing and link following with meta name=robots.

View Source on this file to see the robots directive in <head>:

<meta name="robots" content="index, follow">
DirectiveMeaning
indexAllow this page in search results (default for public pages).
noindexAsk crawlers not to list this page.
followFollow links on this page.
nofollowDo not pass ranking credit via links (use sparingly).

Common pairs: index, follow for public content; noindex, nofollow for staging or private pages.
