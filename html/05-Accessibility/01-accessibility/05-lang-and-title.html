HTML Accessibility — Lang & Title

Set lang on html and write a descriptive document title.

The lang attribute helps screen readers pronounce text correctly. The <title> is the first thing many assistive technologies announce.

This document uses <html lang="en">. For a French paragraph inside an English page:

Bonjour, bienvenue sur phpkingdom.

Title best practices

  • Describe the page purpose, not just the site name.
  • Keep titles unique within your site.
  • Put the specific topic before the brand when space is tight.
<title>Heading Order Tutorial | phpkingdom</title>
