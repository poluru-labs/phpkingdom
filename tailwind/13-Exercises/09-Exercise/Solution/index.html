Solution 09 — Focus Ring Input

Style an input with border, rounded-md, and a teal focus ring (focus:ring-2 focus:ring-teal-500).

<input type="text" placeholder="Your name" class="w-full max-w-sm border border-slate-300 rounded-md px-3 py-2 focus:outline-none focus:ring-2 focus:ring-teal-500">
