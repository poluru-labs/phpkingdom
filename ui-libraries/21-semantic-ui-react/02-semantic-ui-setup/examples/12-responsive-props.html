UI Patterns

// Semantic UI React Setup — Example 12
// Focus: responsive props | Scenario: admin dashboard

import { Button, Container, Header } from "semantic-ui-react";
import "semantic-ui-css/semantic.min.css";

export function App() {
  return (
    <Container style={{ marginTop: "2em" }}>
      <Header as="h1">Dashboard</Header>
      <Button primary>Save</Button>
    </Container>
  );
}

Practice Notes

Checklist for Semantic UI React Setup
- Practice: responsive props
- Scenario: admin dashboard
- Prefer tree-shakeable imports / component wrappers for your design system
- Keep accessibility: keyboard, focus, labels, contrast
- Theme via tokens (color/spacing/type) instead of one-off overrides
- Measure bundle size before adopting heavy enterprise kits

Useful commands:
  npm install <ui-library>
  npx shadcn@latest add button
  npx storybook@latest init
  npm run build && npx bundlesize  # or source-map-explorer
