// Theme Providers — Example 09
// Focus: toast alert | Scenario: form-heavy CRM

:root {
  --color-bg: #ffffff;
  --color-fg: #111827;
  --color-primary: #6b21a8;
  --space-2: 0.5rem;
  --space-4: 1rem;
  --radius-md: 0.5rem;
}
[data-theme="dark"] {
  --color-bg: #0b1220;
  --color-fg: #e5e7eb;
  --color-primary: #c084fc;
}
body { background: var(--color-bg); color: var(--color-fg); }
.btn-primary {
  background: var(--color-primary);
  color: #fff;
  padding: var(--space-2) var(--space-4);
  border-radius: var(--radius-md);
}

Practice Notes

Checklist for Theme Providers
- Practice: toast alert
- Scenario: form-heavy CRM
- Prefer tree-shakeable imports / component wrappers for your design system
- Keep accessibility: keyboard, focus, labels, contrast
- Theme via tokens (color/spacing/type) instead of one-off overrides
- Measure bundle size before adopting heavy enterprise kits
