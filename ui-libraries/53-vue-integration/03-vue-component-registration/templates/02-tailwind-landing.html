Practice Notes

Checklist for Vue Component Registration
- Practice: tailwind landing
- Scenario: admin dashboard
- Prefer tree-shakeable imports / component wrappers for your design system
- Keep accessibility: keyboard, focus, labels, contrast
- Theme via tokens (color/spacing/type) instead of one-off overrides
- Measure bundle size before adopting heavy enterprise kits
