Single-SPA

// Redux with Single-SPA — Example 16
// Focus: react helper | Scenario: design system CDN

// Share one Redux store via a utility module (@org/store)
import { createStore } from "redux";

function rootReducer(state = { cart: [] }, action) {
  if (action.type === "cart/add") {
    return { ...state, cart: [...state.cart, action.payload] };
  }
  return state;
}

export const store = createStore(rootReducer);
// Apps import { store } from "@org/store" (singleton via import map)

Practice Notes

Checklist for Redux with Single-SPA
- Practice: react helper
- Scenario: design system CDN
- Register apps in the root config, then call start() once
- Use activity functions / activeWhen for path-based mounting
- Share dependencies via import maps; override locally for development
- Prefer parcels for framework-agnostic widgets; utility modules for shared logic
- Handle load/mount errors with addErrorHandler and layout error UI

Useful commands:
  npx create-single-spa
