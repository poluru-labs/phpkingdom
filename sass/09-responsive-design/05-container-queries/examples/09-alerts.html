Example 09

Container Queries with Sass

Section: Responsive Design

Focus: Alerts

Scenario: documentation site

Study how the SCSS snippet is structured and how the pattern can scale in a project.

SCSS Snippet

// Container Queries with Sass — Example 09
// Focus: alerts | Scenario: documentation site

// Pair Sass tokens with native container queries
.card-grid {
  container-type: inline-size;
  container-name: cards;
}

@mixin container-up($name, $min) {
  @container #{$name} (min-width: #{$min}) {
    @content;
  }
}

.card {
  padding: 1rem;
  @include container-up(cards, 40rem) {
    display: grid;
    grid-template-columns: 1fr 1fr;
  }
}
