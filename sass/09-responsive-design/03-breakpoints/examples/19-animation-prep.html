Sass Breakpoints

Section: Responsive Design

Focus: Animation Prep

Scenario: documentation site

Study how the SCSS snippet is structured and how the pattern can scale in a project.

SCSS Snippet

// Sass Breakpoints — Example 19
// Focus: animation prep | Scenario: documentation site

@use "sass:map";

$breakpoints: (
  sm: 576px,
  md: 768px,
  lg: 992px,
  xl: 1200px,
);

@function bp($name) {
  @return map.get($breakpoints, $name);
}

@media (min-width: bp(lg)) {
  .container { max-width: 960px; }
}

HTML Markup

<section class="block-breakpoints">
  <h2>Sass Breakpoints</h2>
  <p>Animation Prep for a documentation site.</p>
</section>

Notes

This example focuses on Sass Breakpoints in a documentation site context.

Prefer @use/@forward, keep tokens in abstracts, and compile with Dart Sass.
