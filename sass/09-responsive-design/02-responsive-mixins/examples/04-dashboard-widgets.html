Example 04

Responsive Mixins

Section: Responsive Design

Focus: Dashboard Widgets

Scenario: storefront

Study how the SCSS snippet is structured and how the pattern can scale in a project.

SCSS Snippet

// Responsive Mixins — Example 04
// Focus: dashboard widgets | Scenario: storefront

@use "sass:map";
$bp: (sm: 576px, md: 768px, lg: 992px);

@mixin respond-to($name) {
  @media (min-width: map.get($bp, $name)) {
    @content;
  }
}

.grid {
  display: grid;
  gap: 1rem;
  grid-template-columns: 1fr;
  @include respond-to(md) { grid-template-columns: repeat(3, 1fr); }
}

This example focuses on Responsive Mixins in a storefront context.

Prefer @use/@forward, keep tokens in abstracts, and compile with Dart Sass.
