Sass Mixins

Study how the SCSS snippet is structured and how the pattern can scale in a project.

SCSS Snippet

// Sass Mixins — Example 17
// Focus: landing page | Scenario: booking app

@mixin center-flex {
  display: flex;
  align-items: center;
  justify-content: center;
}

@mixin truncate($lines: 1) {
  @if $lines == 1 {
    overflow: hidden;
    text-overflow: ellipsis;
    white-space: nowrap;
  } @else {
    display: -webkit-box;
    -webkit-line-clamp: $lines;
    -webkit-box-orient: vertical;
    overflow: hidden;
  }
}

.hero { @include center-flex; }
.title { @include truncate(2); }
