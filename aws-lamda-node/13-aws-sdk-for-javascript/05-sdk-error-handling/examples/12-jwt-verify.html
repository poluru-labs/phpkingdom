Node.js Lambda

// AWS SDK Error Handling — Example 12
// Focus: jwt verify | Scenario: file pipeline

// AWS Lambda (Node.js) topic: AWS SDK Error Handling
export const handler = async (event, context) => {
  console.log(JSON.stringify({
    topic: "sdk-error-handling",
    requestId: context.awsRequestId,
    remainingMs: context.getRemainingTimeInMillis(),
  }));

  const body = typeof event?.body === "string"
    ? JSON.parse(event.body || "{}")
    : (event?.body || event || {});

  // Focus area: sdk-error-handling
  const result = { ok: true, topic: "sdk-error-handling", label: "AWS SDK Error Handling", input: body };

  return {
    statusCode: 200,
    headers: {
      "content-type": "application/json",
      "access-control-allow-origin": "*",
    },
    body: JSON.stringify(result),
  };
};

export const TOPIC_SDK_ERROR_HANDLING = "sdk-error-handling";

Practice Notes

Checklist for AWS SDK Error Handling
- Practice: jwt verify

- Keep handlers thin; put business logic in modules
- Reuse SDK clients outside the handler when possible
- Log requestId; avoid logging secrets
- Set memory/timeout for your workload; test cold starts
