Node.js Lambda

// AWS Lambda - Introduction — Example 09
// Focus: sqs consume | Scenario: webhook receiver

export const handler = async (event, context) => {
  console.log(JSON.stringify({
    requestId: context.awsRequestId,
    remainingMs: context.getRemainingTimeInMillis(),
  }));
  return {
    statusCode: 200,
    headers: { "content-type": "application/json" },
    body: JSON.stringify({ message: "hello from Lambda", eventType: typeof event }),
  };
};

export const TOPIC_ID = "introduction";

Practice Notes

Checklist for AWS Lambda - Introduction
- Practice: sqs consume
- Scenario: webhook receiver
- Keep handlers thin; put business logic in modules
- Reuse SDK clients outside the handler when possible
- Log requestId; avoid logging secrets
- Set memory/timeout for your workload; test cold starts

Useful commands:
