Lambda Response Streaming

Section: Advanced

Focus: Sdk V3 Client

Scenario: REST microservice

Implement the handler locally, then invoke with SAM/CLI and verify logs.

Node.js Lambda

// Lambda Response Streaming — Exercise 11
// Focus: sdk v3 client | Scenario: REST microservice

import { awslambda } from "@aws-sdk/client-lambda"; // runtime provides awslambda globally in Node 18+

export const handler = awslambda.streamifyResponse(async (event, responseStream) => {
  responseStream.setContentType("text/plain");
  responseStream.write("hello ");
  responseStream.write("from streaming Lambda");
  responseStream.end();
});

export const TOPIC_ID = "response-streaming";

Practice Notes

Checklist for Lambda Response Streaming
- Practice: sdk v3 client
- Scenario: REST microservice
- Keep handlers thin; put business logic in modules
- Reuse SDK clients outside the handler when possible
- Log requestId; avoid logging secrets
- Set memory/timeout for your workload; test cold starts

Useful commands:
  aws lambda invoke --function-name demo out.json
  sam local invoke -e events/event.json
  npm test
  npx esbuild index.js --bundle --platform=node --target=node20 --outfile=dist/index.js

Notes
