Amazon S3 with Lambda

Section: Amazon S3

Focus: Context Inspect

Scenario: queue worker

Study the Node.js Lambda pattern and adapt it to your AWS project.

Node.js Lambda

// Amazon S3 with Lambda — Example 03
// Focus: context inspect | Scenario: queue worker

import { S3Client, PutObjectCommand, GetObjectCommand } from "@aws-sdk/client-s3";
import { getSignedUrl } from "@aws-sdk/s3-request-presigner";

const s3 = new S3Client({});

export const handler = async (event) => {
  const key = `uploads/${Date.now()}.bin`;
  const url = await getSignedUrl(
    s3,
    new PutObjectCommand({ Bucket: process.env.BUCKET, Key: key }),
    { expiresIn: 900 }
  );
  return { statusCode: 200, body: JSON.stringify({ url, key }) };
};

export const TOPIC_ID = "s3";
