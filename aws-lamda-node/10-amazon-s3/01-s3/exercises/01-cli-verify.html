Exercise 01

Amazon S3 with Lambda

Section: Amazon S3

Focus: Cli Verify

Scenario: REST microservice

Implement the handler locally, then invoke with SAM/CLI and verify logs.

Node.js Lambda

// Amazon S3 with Lambda — Exercise 01
// Focus: cli verify | Scenario: REST microservice

import { S3Client, PutObjectCommand, GetObjectCommand } from "@aws-sdk/client-s3";
import { getSignedUrl } from "@aws-sdk/s3-request-presigner";

const s3 = new S3Client({});

export const handler = async (event) => {
  const key = `uploads/${Date.now()}.bin`;
  const url = await getSignedUrl(
    s3,
    new PutObjectCommand({ Bucket: process.env.BUCKET, Key: key }),
    { expiresIn: 900 }
  );
  return { statusCode: 200, body: JSON.stringify({ url, key }) };
};

export const TOPIC_ID = "s3";

Practice Notes

Checklist for Amazon S3 with Lambda
- Practice: cli verify
- Scenario: REST microservice
- Keep handlers thin; put business logic in modules
- Reuse SDK clients outside the handler when possible
- Log requestId; avoid logging secrets
- Set memory/timeout for your workload; test cold starts

Useful commands:
  aws lambda invoke --function-name demo out.json
  sam local invoke -e events/event.json
  npm test
