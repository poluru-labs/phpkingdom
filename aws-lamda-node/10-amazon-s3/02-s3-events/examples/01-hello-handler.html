Example 01

S3 Event Triggers

Section: Amazon S3

Focus: Hello Handler

Scenario: REST microservice

Study the Node.js Lambda pattern and adapt it to your AWS project.

Node.js Lambda

// S3 Event Triggers — Example 01
// Focus: hello handler | Scenario: REST microservice

import { S3Client, PutObjectCommand, GetObjectCommand } from "@aws-sdk/client-s3";
import { getSignedUrl } from "@aws-sdk/s3-request-presigner";

const s3 = new S3Client({});

export const handler = async (event) => {
  const key = `uploads/${Date.now()}.bin`;
  const url = await getSignedUrl(
    s3,
    new PutObjectCommand({ Bucket: process.env.BUCKET, Key: key }),
    { expiresIn: 900 }
  );
  return { statusCode: 200, body: JSON.stringify({ url, key }) };
};

export const TOPIC_ID = "s3-events";

Practice Notes

Checklist for S3 Event Triggers
- Practice: hello handler
- Scenario: REST microservice
- Keep handlers thin; put business logic in modules
- Reuse SDK clients outside the handler when possible
- Log requestId; avoid logging secrets
- Set memory/timeout for your workload; test cold starts
