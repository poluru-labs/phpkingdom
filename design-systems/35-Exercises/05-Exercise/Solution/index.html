Solution 05 — Button Variants

Style primary and secondary buttons with tokens.

Solution

.ds-button { background: var(--color-action); color: var(--color-action-fg); }
.ds-button[data-variant='secondary'] {
  background: transparent;
  color: var(--color-action);
  box-shadow: inset 0 0 0 1px var(--color-action);
}
