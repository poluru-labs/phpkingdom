Practice Notes

Checklist for Semantic Versioning
- Practice: icon set
- Scenario: marketing site
- Separate primitive → semantic → component tokens
- Document usage, do/don't, and accessibility in Storybook
- Version with semver; deprecate before breaking
- Measure adoption and bundle impact

Useful commands:
  npm init -y && npm pkg set name=@phpkingdom/ds
  npx storybook@latest init
  npm run build && npm publish --access public
  npx chromatic --project-token=$CHROMATIC_PROJECT_TOKEN
