Spec Sample

// Playwright Best Practices — Exercise 03
// Focus: locator cleanup | Scenario: checkout flow

import { test, expect } from '@playwright/test';

test('best-practice smoke', async ({ page }) => {
  await page.goto('/');
  // 1) Role/label locators  2) web-first expect  3) no fixed sleeps
  await expect(page.getByRole('heading', { name: /welcome/i })).toBeVisible();
  await page.getByRole('link', { name: 'Docs' }).click();
  await expect(page).toHaveURL(/docs/);
});
// Also: storageState for auth, fixtures for setup, traces on retry.

Notes

This exercise shows one way to apply Playwright Best Practices in a checkout flow context.

Prefer role/label/test-id locators and rely on Playwright auto-waiting over fixed sleeps.
