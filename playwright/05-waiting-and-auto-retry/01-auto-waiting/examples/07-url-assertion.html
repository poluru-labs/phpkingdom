Auto Waiting

Section: Waiting and Auto Retry

Focus: Url Assertion

Scenario: API-backed SPA

Study the Playwright spec and config notes, then adapt them to your app.

Spec Sample

// Auto Waiting — Example 07
// Focus: url assertion | Scenario: API-backed SPA

import { test, expect } from '@playwright/test';

test('rely on auto-waiting instead of sleep', async ({ page }) => {
  await page.goto('/dashboard');
  // Bad: await page.waitForTimeout(5000);
  await expect(page.getByText('Loaded')).toBeVisible();
  await page.getByRole('button', { name: 'Refresh' }).click();
  await expect(page.getByTestId('spinner')).toBeHidden();
});

Config Notes

// playwright.config.ts — notes for Auto Waiting
import { defineConfig, devices } from '@playwright/test';

export default defineConfig({
  testDir: './tests',
  fullyParallel: true,
  forbidOnly: !!process.env.CI,
  retries: process.env.CI ? 2 : 0,
  workers: process.env.CI ? 2 : undefined,
  reporter: [['html'], ['list']],
  use: {
    baseURL: 'http://localhost:3000',
    trace: 'on-first-retry',
    screenshot: 'only-on-failure',
    video: 'retain-on-failure',
  },
  projects: [
    { name: 'chromium', use: { ...devices['Desktop Chrome'] } },
    { name: 'firefox', use: { ...devices['Desktop Firefox'] } },
    { name: 'webkit', use: { ...devices['Desktop Safari'] } },
  ],
  // Focus: url assertion for API-backed SPA (auto-waiting)
});

Notes

This example shows one way to apply Auto Waiting in a api-backed spa context.

Prefer role/label/test-id locators and rely on Playwright auto-waiting over fixed sleeps.
