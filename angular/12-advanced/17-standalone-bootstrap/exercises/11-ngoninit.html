Standalone Bootstrap

Section: Advanced

Implement the focus with Angular CLI and verify in the browser.

Angular

// Standalone Bootstrap — Exercise 11
// Focus: ngOnInit | Scenario: enterprise admin

import { bootstrapApplication } from "@angular/platform-browser";
import { provideRouter } from "@angular/router";
import { AppComponent } from "./app.component";
import { routes } from "./app.routes";

bootstrapApplication(AppComponent, {
  providers: [provideRouter(routes)],
}).catch((err) => console.error(err));

export const TOPIC_ID = "standalone-bootstrap";

Practice Notes

Checklist for Standalone Bootstrap
- Practice: ngOnInit
- Scenario: enterprise admin
- Prefer standalone components + inject() for new Angular apps
- Use signals for local UI state; RxJS for async streams and HttpClient
- Reactive forms for complex validation; template-driven for simple forms
- Route with provideRouter; guard auth routes; lazy-load feature areas
- Prefer OnPush + async pipe / signals to reduce change detection work

Useful commands:
  npm i -g @angular/cli
  ng new my-app --standalone
  ng generate component features/counter --standalone
  ng serve
  ng test
  ng build
