Solution 24 — ngOnDestroy Cleanup

Unsubscribe or destroyRef on destroy.

Solution

private readonly destroyRef = inject(DestroyRef);

ngOnInit() {
  this.users.list$()
    .pipe(takeUntilDestroyed(this.destroyRef))
    .subscribe((users) => (this.usersList = users));
}
