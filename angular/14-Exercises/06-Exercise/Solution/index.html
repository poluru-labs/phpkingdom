Solution 06 — *ngFor List

Render a list with *ngFor and trackBy.

Solution

items = [
  { id: 1, label: 'Angular' },
  { id: 2, label: 'RxJS' },
];

trackById = (_: number, item: { id: number }) => item.id;

// <li *ngFor="let item of items; trackBy: trackById">{{ item.label }}</li>
