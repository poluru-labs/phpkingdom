Practice Notes

Checklist for Angular Templates
- Practice: ngOnInit
- Scenario: enterprise admin
- Prefer standalone components + inject() for new Angular apps
- Use signals for local UI state; RxJS for async streams and HttpClient
- Reactive forms for complex validation; template-driven for simple forms
- Route with provideRouter; guard auth routes; lazy-load feature areas
- Prefer OnPush + async pipe / signals to reduce change detection work

Useful commands:
  npm i -g @angular/cli
  ng new my-app --standalone
  ng generate component features/counter --standalone
  ng serve
  ng test
  ng build
