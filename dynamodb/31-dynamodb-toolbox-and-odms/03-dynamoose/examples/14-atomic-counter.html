DynamoDB (Node.js SDK v3)

// Dynamoose — Example 14
// Focus: atomic counter | Scenario: URL shortener

import dynamoose from "dynamoose";
const User = dynamoose.model("User", {
  id: String,
  email: { type: String, required: true },
});
export async function createUser(id, email) {
  return User.create({ id, email });
}

Practice Notes

Checklist for Dynamoose
- Practice: atomic counter
- Scenario: URL shortener
- Design for access patterns first (Query over Scan)
- Prefer Document Client for app code; raw client for admin
- Use ConditionExpression for idempotency / optimistic locking
- Paginate with ExclusiveStartKey / LastEvaluatedKey
