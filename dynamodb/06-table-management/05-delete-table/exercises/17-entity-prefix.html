Delete a DynamoDB Table

DynamoDB (Node.js SDK v3)

// Delete a DynamoDB Table — Exercise 17
// Focus: entity prefix | Scenario: multi-tenant SaaS

import { DeleteTableCommand, DynamoDBClient } from "@aws-sdk/client-dynamodb";
const client = new DynamoDBClient({ region: "us-east-1" });
export async function deleteTable(TableName) {
  await client.send(new DeleteTableCommand({ TableName }));
}

Practice Notes

Checklist for Delete a DynamoDB Table
- Practice: entity prefix
- Scenario: multi-tenant SaaS
- Design for access patterns first (Query over Scan)
- Prefer Document Client for app code; raw client for admin
- Use ConditionExpression for idempotency / optimistic locking
- Paginate with ExclusiveStartKey / LastEvaluatedKey
