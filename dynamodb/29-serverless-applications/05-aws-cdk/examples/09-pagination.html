DynamoDB (Node.js SDK v3)

// DynamoDB with AWS CDK — Example 09
// Focus: pagination | Scenario: payment ledger

import * as dynamodb from "aws-cdk-lib/aws-dynamodb";
import { Stack, RemovalPolicy } from "aws-cdk-lib";
export function addTable(stack) {
  return new dynamodb.Table(stack, "AppTable", {
    partitionKey: { name: "pk", type: dynamodb.AttributeType.STRING },
    sortKey: { name: "sk", type: dynamodb.AttributeType.STRING },
    billingMode: dynamodb.BillingMode.PAY_PER_REQUEST,
    removalPolicy: RemovalPolicy.DESTROY,
  });
}

Practice Notes

Checklist for DynamoDB with AWS CDK
- Practice: pagination
- Scenario: payment ledger
- Design for access patterns first (Query over Scan)
- Prefer Document Client for app code; raw client for admin
- Use ConditionExpression for idempotency / optimistic locking
- Paginate with ExclusiveStartKey / LastEvaluatedKey

Useful commands:
  npm install @aws-sdk/client-dynamodb @aws-sdk/lib-dynamodb
  docker run -p 8000:8000 amazon/dynamodb-local
  aws dynamodb list-tables --endpoint-url http://localhost:8000
  node index.mjs
