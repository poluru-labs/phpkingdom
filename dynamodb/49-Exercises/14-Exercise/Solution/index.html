Solution 14 — Transact Write

Create order and decrement inventory in one transaction.

Solution

await doc.send(new TransactWriteCommand({
  TransactItems: [
    { Put: { TableName, Item: { pk: "ORDER#1", sk: "META", total: 10 } } },
    { Update: { TableName, Key: { pk: "SKU#A", sk: "STOCK" }, UpdateExpression: "SET qty = qty - :n", ConditionExpression: "qty >= :n", ExpressionAttributeValues: { ":n": 1 } } },
  ],
}));
