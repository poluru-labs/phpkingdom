Solution 05 — Put Item

Put a user profile with ConditionExpression.

Solution

await doc.send(new PutCommand({
  TableName: "AppTable",
  Item: { pk: "USER#1", sk: "PROFILE", email: "a@b.com", version: 1 },
  ConditionExpression: "attribute_not_exists(pk)",
}));
