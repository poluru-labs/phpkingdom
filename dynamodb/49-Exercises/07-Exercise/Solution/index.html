Solution 07 — Update Email

Update email and bump version.

Solution

await doc.send(new UpdateCommand({
  TableName: "AppTable",
  Key: { pk: "USER#1", sk: "PROFILE" },
  UpdateExpression: "SET email = :e, version = version + :one",
  ExpressionAttributeValues: { ":e": "new@b.com", ":one": 1 },
}));
