Solution 12 — Batch Write

Batch put two items.

Solution

await doc.send(new BatchWriteCommand({
  RequestItems: {
    AppTable: [
      { PutRequest: { Item: { pk: "USER#1", sk: "PROFILE" } } },
      { PutRequest: { Item: { pk: "USER#2", sk: "PROFILE" } } },
    ],
  },
}));
