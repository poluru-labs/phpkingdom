DynamoDB (Node.js SDK v3)

// Entity Prefixes — Example 03
// Focus: get item | Scenario: chat messages

export const prefixes = {
  user: "USER#",
  order: "ORDER#",
  product: "PRODUCT#",
  tenant: "TENANT#",
};
export function pk(type, id) {
  return `${prefixes[type]}${id}`;
}

Practice Notes

Checklist for Entity Prefixes
- Practice: get item
- Scenario: chat messages
- Design for access patterns first (Query over Scan)
- Prefer Document Client for app code; raw client for admin
- Use ConditionExpression for idempotency / optimistic locking
- Paginate with ExclusiveStartKey / LastEvaluatedKey
