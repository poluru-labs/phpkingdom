DynamoDB (Node.js SDK v3)

// SDK Client Error Handling — Exercise 01
// Focus: sdk install | Scenario: user profile API

import { DynamoDBClient } from "@aws-sdk/client-dynamodb";
import { GetCommand, DynamoDBDocumentClient } from "@aws-sdk/lib-dynamodb";
const doc = DynamoDBDocumentClient.from(new DynamoDBClient({ region: "us-east-1" }));
export async function safeGet(Key) {
  try {
    return await doc.send(new GetCommand({ TableName: "AppTable", Key }));
  } catch (err) {
    if (err.name === "ResourceNotFoundException") return null;
    if (err.name === "ProvisionedThroughputExceededException") throw err; // let SDK retry / bubble
    throw err;
  }
}

Practice Notes

Checklist for SDK Client Error Handling
- Practice: sdk install
- Scenario: user profile API
- Design for access patterns first (Query over Scan)
- Prefer Document Client for app code; raw client for admin
- Use ConditionExpression for idempotency / optimistic locking
- Paginate with ExclusiveStartKey / LastEvaluatedKey

Useful commands:
  npm install @aws-sdk/client-dynamodb @aws-sdk/lib-dynamodb
  docker run -p 8000:8000 amazon/dynamodb-local
  aws dynamodb list-tables --endpoint-url http://localhost:8000
  node index.mjs
