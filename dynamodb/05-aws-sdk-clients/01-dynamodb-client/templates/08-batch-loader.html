DynamoDB (Node.js SDK v3)

// DynamoDB Client — Template 08
// Focus: batch loader | Scenario: activity feed

import { DynamoDBClient, ListTablesCommand } from "@aws-sdk/client-dynamodb";
const client = new DynamoDBClient({ region: "us-east-1" });
// Low-level client: AttributeValue shapes { S, N, M, ... }
export async function listTables() {
  return client.send(new ListTablesCommand({}));
}

Practice Notes

Checklist for DynamoDB Client
- Practice: batch loader
- Scenario: activity feed
- Design for access patterns first (Query over Scan)
- Prefer Document Client for app code; raw client for admin
- Use ConditionExpression for idempotency / optimistic locking
- Paginate with ExclusiveStartKey / LastEvaluatedKey

Useful commands:
  npm install @aws-sdk/client-dynamodb @aws-sdk/lib-dynamodb
  docker run -p 8000:8000 amazon/dynamodb-local
  aws dynamodb list-tables --endpoint-url http://localhost:8000
  node index.mjs
