DynamoDB (Node.js SDK v3)

// Contributor Insights — Template 08
// Focus: batch loader | Scenario: activity feed

import { UpdateContributorInsightsCommand, DynamoDBClient } from "@aws-sdk/client-dynamodb";
const client = new DynamoDBClient({ region: "us-east-1" });
// Surfaces hottest keys / most accessed items
export async function enableContributorInsights(TableName = "AppTable") {
  await client.send(new UpdateContributorInsightsCommand({
    TableName,
    ContributorInsightsAction: "ENABLE",
  }));
}

Practice Notes

Checklist for Contributor Insights
- Practice: batch loader
- Scenario: activity feed
- Design for access patterns first (Query over Scan)
- Prefer Document Client for app code; raw client for admin
- Use ConditionExpression for idempotency / optimistic locking
- Paginate with ExclusiveStartKey / LastEvaluatedKey
