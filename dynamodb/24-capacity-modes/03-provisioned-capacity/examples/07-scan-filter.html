Provisioned Capacity

Section: Capacity Modes

Focus: Scan Filter

Scenario: multi-tenant SaaS

Study the DynamoDB Document Client pattern and adapt it to your access patterns.

DynamoDB (Node.js SDK v3)

// Provisioned Capacity — Example 07
// Focus: scan filter | Scenario: multi-tenant SaaS

import { UpdateTableCommand, DynamoDBClient } from "@aws-sdk/client-dynamodb";
const client = new DynamoDBClient({ region: "us-east-1" });
export async function setProvisioned(TableName, ReadCapacityUnits, WriteCapacityUnits) {
  await client.send(new UpdateTableCommand({
    TableName,
    BillingMode: "PROVISIONED",
    ProvisionedThroughput: { ReadCapacityUnits, WriteCapacityUnits },
  }));
}
