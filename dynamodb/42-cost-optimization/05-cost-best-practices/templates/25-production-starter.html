Practice Notes

Checklist for Cost Optimization Practices
- Practice: production starter
- Scenario: session store
- Design for access patterns first (Query over Scan)
- Prefer Document Client for app code; raw client for admin
- Use ConditionExpression for idempotency / optimistic locking
- Paginate with ExclusiveStartKey / LastEvaluatedKey

Useful commands:
  npm install @aws-sdk/client-dynamodb @aws-sdk/lib-dynamodb
  docker run -p 8000:8000 amazon/dynamodb-local
  aws dynamodb list-tables --endpoint-url http://localhost:8000
  node index.mjs

Notes

This template shows one way to apply Cost Optimization Practices in a session store context.
