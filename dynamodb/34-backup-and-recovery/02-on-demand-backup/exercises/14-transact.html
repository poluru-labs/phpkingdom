On-Demand Backups

Section: Backup and Recovery

Focus: Transact

Scenario: URL shortener

Run against DynamoDB Local or AWS, then verify with GetItem/Query and CloudWatch metrics.

DynamoDB (Node.js SDK v3)

// On-Demand Backups — Exercise 14
// Focus: transact | Scenario: URL shortener

import { CreateBackupCommand, DynamoDBClient } from "@aws-sdk/client-dynamodb";
const client = new DynamoDBClient({ region: "us-east-1" });
export async function onDemandBackup(TableName = "AppTable") {
  return client.send(new CreateBackupCommand({
    TableName,
    BackupName: `AppTable-${Date.now()}`,
  }));
}

Practice Notes

Checklist for On-Demand Backups
- Practice: transact
- Scenario: URL shortener
- Design for access patterns first (Query over Scan)
- Prefer Document Client for app code; raw client for admin
- Use ConditionExpression for idempotency / optimistic locking
- Paginate with ExclusiveStartKey / LastEvaluatedKey

Useful commands:
