Template 06

On-Demand Backups

Section: Backup and Recovery

Focus: Single Table App

Scenario: inventory ledger

Use this scaffold as a starting point for a DynamoDB-backed Node.js service.

DynamoDB (Node.js SDK v3)

// On-Demand Backups — Template 06
// Focus: single table app | Scenario: inventory ledger

import { CreateBackupCommand, DynamoDBClient } from "@aws-sdk/client-dynamodb";
const client = new DynamoDBClient({ region: "us-east-1" });
export async function onDemandBackup(TableName = "AppTable") {
  return client.send(new CreateBackupCommand({
    TableName,
    BackupName: `AppTable-${Date.now()}`,
  }));
}

Practice Notes

Checklist for On-Demand Backups
- Practice: single table app
- Scenario: inventory ledger
- Design for access patterns first (Query over Scan)
- Prefer Document Client for app code; raw client for admin
- Use ConditionExpression for idempotency / optimistic locking
- Paginate with ExclusiveStartKey / LastEvaluatedKey

Useful commands:
  npm install @aws-sdk/client-dynamodb @aws-sdk/lib-dynamodb
  docker run -p 8000:8000 amazon/dynamodb-local
  aws dynamodb list-tables --endpoint-url http://localhost:8000
  node index.mjs

Notes

This template shows one way to apply On-Demand Backups in a inventory ledger context.
