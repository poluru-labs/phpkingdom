DynamoDB (Node.js SDK v3)

// Point-in-Time Recovery — Exercise 14
// Focus: transact | Scenario: URL shortener

import { UpdateContinuousBackupsCommand, DynamoDBClient } from "@aws-sdk/client-dynamodb";
const client = new DynamoDBClient({ region: "us-east-1" });
export async function enablePitr(TableName = "AppTable") {
  await client.send(new UpdateContinuousBackupsCommand({
    TableName,
    PointInTimeRecoverySpecification: { PointInTimeRecoveryEnabled: true },
  }));
}

Practice Notes

Checklist for Point-in-Time Recovery
- Practice: transact
- Scenario: URL shortener
- Design for access patterns first (Query over Scan)
- Prefer Document Client for app code; raw client for admin
- Use ConditionExpression for idempotency / optimistic locking
- Paginate with ExclusiveStartKey / LastEvaluatedKey
