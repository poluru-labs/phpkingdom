DynamoDB (Node.js SDK v3)

// Mock the DynamoDB Client — Example 24
// Focus: retry throttle | Scenario: URL shortener

import { mockClient } from "aws-sdk-client-mock";
import { DynamoDBDocumentClient, PutCommand } from "@aws-sdk/lib-dynamodb";
export const ddbMock = mockClient(DynamoDBDocumentClient);
ddbMock.on(PutCommand).resolves({});

Practice Notes

Checklist for Mock the DynamoDB Client
- Practice: retry throttle
- Scenario: URL shortener
- Design for access patterns first (Query over Scan)
- Prefer Document Client for app code; raw client for admin
- Use ConditionExpression for idempotency / optimistic locking
- Paginate with ExclusiveStartKey / LastEvaluatedKey

Useful commands:
  npm install @aws-sdk/client-dynamodb @aws-sdk/lib-dynamodb
  docker run -p 8000:8000 amazon/dynamodb-local
  aws dynamodb list-tables --endpoint-url http://localhost:8000
  node index.mjs
