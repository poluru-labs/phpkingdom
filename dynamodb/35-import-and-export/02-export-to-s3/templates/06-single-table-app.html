Template 06

Export DynamoDB to S3

Section: Import and Export

Focus: Single Table App

Scenario: inventory ledger

Use this scaffold as a starting point for a DynamoDB-backed Node.js service.

DynamoDB (Node.js SDK v3)

// Export DynamoDB to S3 — Template 06
// Focus: single table app | Scenario: inventory ledger

import { ExportTableCommand, DynamoDBClient } from "@aws-sdk/client-dynamodb";
const client = new DynamoDBClient({ region: "us-east-1" });
export async function exportToS3(tableArn, bucket) {
  await client.send(new ExportTableCommand({
    TableArn: tableArn,
    S3Bucket: bucket,
    ExportFormat: "DYNAMODB_JSON",
  }));
}

Practice Notes

Checklist for Export DynamoDB to S3
- Practice: single table app
- Scenario: inventory ledger
- Design for access patterns first (Query over Scan)
- Prefer Document Client for app code; raw client for admin
- Use ConditionExpression for idempotency / optimistic locking
- Paginate with ExclusiveStartKey / LastEvaluatedKey
