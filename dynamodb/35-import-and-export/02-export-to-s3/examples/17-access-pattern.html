Example 17

Export DynamoDB to S3

Section: Import and Export

Focus: Access Pattern

Scenario: multi-tenant SaaS

Study the DynamoDB Document Client pattern and adapt it to your access patterns.

DynamoDB (Node.js SDK v3)

// Export DynamoDB to S3 — Example 17
// Focus: access pattern | Scenario: multi-tenant SaaS

import { ExportTableCommand, DynamoDBClient } from "@aws-sdk/client-dynamodb";
const client = new DynamoDBClient({ region: "us-east-1" });
export async function exportToS3(tableArn, bucket) {
  await client.send(new ExportTableCommand({
    TableArn: tableArn,
    S3Bucket: bucket,
    ExportFormat: "DYNAMODB_JSON",
  }));
}
