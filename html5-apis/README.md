## Layout

- `01-Basics` … `11-Advanced` — topic examples (typically 5+ HTML files per topic)
- `12-Misc-Examples` — standalone demos
- `13-Exercises` — Problem → Solution drills

Every HTML file includes the metadata comment block (`sitename`, author, email, `autor website`).
