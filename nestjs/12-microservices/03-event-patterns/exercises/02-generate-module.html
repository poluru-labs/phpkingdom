Exercise 02

Event Patterns

Section: Microservices

Focus: Generate Module

Scenario: SaaS platform

Generate the feature with Nest CLI, implement the focus, and verify with HTTP requests.

NestJS

// Event Patterns — Exercise 02
// Focus: generate module | Scenario: SaaS platform

import { Controller } from "@nestjs/common";
import { EventPattern, Payload } from "@nestjs/microservices";

@Controller()
export class NotificationsController {
  @EventPattern("user.created")
  handleUserCreated(@Payload() data: { email: string }) {
    console.log("send welcome email to", data.email);
    // fire-and-forget: no response expected
  }
}
// Client: client.emit("user.created", { email: "ada@example.com" })

Practice Notes

Checklist for Event Patterns
- Practice: generate module
- Scenario: SaaS platform
- Structure by feature modules: module + controller + service + DTOs
- Prefer constructor injection; keep providers @Injectable()
- Validate input with class-validator + ValidationPipe (whitelist)
- Use guards for auth/roles, pipes for transform/validate, filters for errors
- Test with TestingModule; e2e with supertest against NestFactory
