NestJS

// Dependency Injection — Example 15
// Focus: config module | Scenario: auth service

import { Injectable, Module } from "@nestjs/common";

@Injectable()
export class UsersRepository {
  findAll() {
    return [{ id: 1, name: "Ada" }];
  }
}

@Injectable()
export class UsersService {
  constructor(private readonly repo: UsersRepository) {}

  list() {
    return this.repo.findAll();
  }
}

@Module({
  providers: [UsersRepository, UsersService],
  exports: [UsersService],
})
export class UsersModule {}
// Nest resolves constructor deps from the DI container

Practice Notes

Checklist for Dependency Injection
- Practice: config module
- Scenario: auth service
- Structure by feature modules: module + controller + service + DTOs
- Prefer constructor injection; keep providers @Injectable()
- Validate input with class-validator + ValidationPipe (whitelist)
- Use guards for auth/roles, pipes for transform/validate, filters for errors
- Test with TestingModule; e2e with supertest against NestFactory

Useful commands:
  npm i -g @nestjs/cli
  nest new my-api
  nest g resource users
  nest start --watch
  npm run test
  npm run test:e2e
