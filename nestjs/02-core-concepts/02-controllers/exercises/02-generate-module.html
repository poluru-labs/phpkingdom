NestJS

// NestJS Controllers — Exercise 02
// Focus: generate module | Scenario: SaaS platform

import {
  Controller,
  Get,
  Post,
  Body,
  Param,
  ParseIntPipe,
  HttpCode,
  HttpStatus,
} from "@nestjs/common";

@Controller("users")
export class UsersController {
  @Get()
  findAll() {
    return [{ id: 1, name: "Ada" }];
  }

  @Get(":id")
  findOne(@Param("id", ParseIntPipe) id: number) {
    return { id, name: "Ada" };
  }

  @Post()
  @HttpCode(HttpStatus.CREATED)
  create(@Body() body: { name: string }) {
    return { id: 2, ...body };
  }
}

Practice Notes

Checklist for NestJS Controllers
- Practice: generate module
- Scenario: SaaS platform
- Structure by feature modules: module + controller + service + DTOs
- Prefer constructor injection; keep providers @Injectable()
- Validate input with class-validator + ValidationPipe (whitelist)
- Use guards for auth/roles, pipes for transform/validate, filters for errors
- Test with TestingModule; e2e with supertest against NestFactory

Useful commands:
  npm i -g @nestjs/cli
  nest new my-api
  nest g resource users
  nest start --watch
  npm run test
  npm run test:e2e

Notes
