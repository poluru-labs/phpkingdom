Validation Schema

Study the NestJS module/controller/service pattern and adapt it to your API.

NestJS

// Validation Schema — Example 22
// Focus: microservice pattern | Scenario: SaaS platform

import { Module } from "@nestjs/common";
import { ConfigModule } from "@nestjs/config";
import * as Joi from "joi";
// or: import { z } from "zod";

@Module({
  imports: [
    ConfigModule.forRoot({
      isGlobal: true,
      validationSchema: Joi.object({
        NODE_ENV: Joi.string()
          .valid("development", "production", "test")
          .default("development"),
        PORT: Joi.number().default(3000),
        DATABASE_URL: Joi.string().uri().required(),
        JWT_SECRET: Joi.string().min(16).required(),
      }),
      validationOptions: { abortEarly: false },
    }),
  ],
})
export class AppModule {}
// App fails fast on boot if env fails schema validation

Practice Notes

Checklist for Validation Schema
- Practice: microservice pattern
- Scenario: SaaS platform
- Structure by feature modules: module + controller + service + DTOs
- Prefer constructor injection; keep providers @Injectable()
- Validate input with class-validator + ValidationPipe (whitelist)
- Use guards for auth/roles, pipes for transform/validate, filters for errors
- Test with TestingModule; e2e with supertest against NestFactory
