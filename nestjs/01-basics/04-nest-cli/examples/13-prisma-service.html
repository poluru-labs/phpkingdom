NestJS

// Nest CLI — Example 13
// Focus: prisma service | Scenario: e-commerce API

# Nest CLI — scaffolding & build
nest new my-api
nest g module users
nest g controller users
nest g service users
nest g resource products --no-spec

# nest-cli.json controls sourceRoot, compilerOptions
# nest build   → compiles to dist/
# nest start --watch
# nest info    → environment report

Practice Notes

Checklist for Nest CLI
- Practice: prisma service
- Scenario: e-commerce API
- Structure by feature modules: module + controller + service + DTOs
- Prefer constructor injection; keep providers @Injectable()
- Validate input with class-validator + ValidationPipe (whitelist)
- Use guards for auth/roles, pipes for transform/validate, filters for errors
- Test with TestingModule; e2e with supertest against NestFactory

Useful commands:
  npm i -g @nestjs/cli
  nest new my-api
  nest g resource users
  nest start --watch
  npm run test
  npm run test:e2e

Notes

This example shows one way to apply Nest CLI in a e-commerce api context.
