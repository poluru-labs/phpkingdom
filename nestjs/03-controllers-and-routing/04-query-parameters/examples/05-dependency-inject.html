Example 05

Query Parameters

Section: Controllers and Routing

Focus: Dependency Inject

Scenario: auth service

Study the NestJS module/controller/service pattern and adapt it to your API.

NestJS

// Query Parameters — Example 05
// Focus: dependency inject | Scenario: auth service

import { Controller, Get, Query, DefaultValuePipe, ParseIntPipe } from "@nestjs/common";

@Controller("users")
export class UsersController {
  @Get()
  findAll(
    @Query("page", new DefaultValuePipe(1), ParseIntPipe) page: number,
    @Query("limit", new DefaultValuePipe(10), ParseIntPipe) limit: number,
    @Query("q") q?: string,
  ) {
    return { page, limit, q: q ?? null, items: [] };
  }
}
// GET /users?page=2&limit=20&q=ada

Practice Notes

Checklist for Query Parameters
- Practice: dependency inject
- Scenario: auth service
- Structure by feature modules: module + controller + service + DTOs
- Prefer constructor injection; keep providers @Injectable()
- Validate input with class-validator + ValidationPipe (whitelist)
- Use guards for auth/roles, pipes for transform/validate, filters for errors
- Test with TestingModule; e2e with supertest against NestFactory
