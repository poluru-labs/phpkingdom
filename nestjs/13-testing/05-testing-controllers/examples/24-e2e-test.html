Testing Controllers

Section: Testing

Focus: E2E Test

Scenario: admin service

Study the NestJS module/controller/service pattern and adapt it to your API.

NestJS

// Testing Controllers — Example 24
// Focus: e2e test | Scenario: admin service

import { Test } from "@nestjs/testing";
import { UsersController } from "./users.controller";
import { UsersService } from "./users.service";

describe("UsersController", () => {
  let controller: UsersController;
  const usersService = {
    findAll: jest.fn().mockReturnValue([{ id: 1, name: "Ada" }]),
  };

  beforeEach(async () => {
    const module = await Test.createTestingModule({
      controllers: [UsersController],
      providers: [{ provide: UsersService, useValue: usersService }],
    }).compile();
    controller = module.get(UsersController);
  });

  it("findAll", () => {
    expect(controller.findAll()).toEqual([{ id: 1, name: "Ada" }]);
  });
});

Practice Notes

Checklist for Testing Controllers
- Practice: e2e test
- Scenario: admin service
- Structure by feature modules: module + controller + service + DTOs
- Prefer constructor injection; keep providers @Injectable()
- Validate input with class-validator + ValidationPipe (whitelist)
- Use guards for auth/roles, pipes for transform/validate, filters for errors
- Test with TestingModule; e2e with supertest against NestFactory
