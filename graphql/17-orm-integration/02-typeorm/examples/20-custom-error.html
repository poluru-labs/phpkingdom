GraphQL (Node.js)

// GraphQL with TypeORM — Example 20
// Focus: custom error | Scenario: analytics API

import { AppDataSource } from "./data-source";
import { User } from "./entity/User";
const repo = () => AppDataSource.getRepository(User);
const resolvers = {
  Query: { users: () => repo().find() },
  Mutation: { createUser: (_p, { input }) => repo().save(repo().create(input)) },
};

Practice Notes

Checklist for GraphQL with TypeORM
- Practice: custom error
- Scenario: analytics API
- Keep resolvers thin; push logic into services
- Use DataLoader to avoid N+1 nested queries
- Put authz checks in context / field resolvers / directives
- Prefer non-null carefully; return typed GraphQLError codes
- Limit depth/complexity; deprecate before breaking changes
