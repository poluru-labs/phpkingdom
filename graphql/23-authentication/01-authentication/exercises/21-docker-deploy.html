// GraphQL Authentication — Exercise 21
// Focus: docker deploy | Scenario: blog API

await startStandaloneServer(server, {
  context: async ({ req }) => {
    const token = req.headers.authorization?.replace("Bearer ", "");
    const user = token ? await verifyToken(token) : null;
    return { user };
  },
});

Practice Notes

Checklist for GraphQL Authentication
- Practice: docker deploy
- Scenario: blog API
- Keep resolvers thin; push logic into services
- Use DataLoader to avoid N+1 nested queries
- Put authz checks in context / field resolvers / directives
- Prefer non-null carefully; return typed GraphQLError codes
- Limit depth/complexity; deprecate before breaking changes
