// GraphQL Request Logging — Example 07
// Focus: input type | Scenario: federated platform

const plugin = {
  async requestDidStart() {
    const start = Date.now();
    return {
      async willSendResponse(rc) {
        console.log(JSON.stringify({ op: rc.operationName, ms: Date.now() - start }));
      },
    };
  },
};

Practice Notes

Checklist for GraphQL Request Logging
- Practice: input type
- Scenario: federated platform
- Keep resolvers thin; push logic into services
- Use DataLoader to avoid N+1 nested queries
- Put authz checks in context / field resolvers / directives
- Prefer non-null carefully; return typed GraphQLError codes
- Limit depth/complexity; deprecate before breaking changes
