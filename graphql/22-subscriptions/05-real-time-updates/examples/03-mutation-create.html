Real-Time Updates

Section: Subscriptions

Focus: Mutation Create

Scenario: social feed

Study the GraphQL schema/resolver pattern and adapt it to your API.

GraphQL (Node.js)

// Real-Time Updates — Example 03
// Focus: mutation create | Scenario: social feed

const resolvers = {
  Mutation: {
    postMessage: async (_p, { roomId, body }, { pubsub, user }) => {
      const message = { id: crypto.randomUUID(), roomId, body, userId: user.id };
      await pubsub.publish(`MESSAGE_ADDED_${roomId}`, { messageAdded: message });
      return message;
    },
  },
};

Practice Notes

Checklist for Real-Time Updates
- Practice: mutation create
- Scenario: social feed
- Keep resolvers thin; push logic into services
- Use DataLoader to avoid N+1 nested queries
- Put authz checks in context / field resolvers / directives
- Prefer non-null carefully; return typed GraphQLError codes
- Limit depth/complexity; deprecate before breaking changes
