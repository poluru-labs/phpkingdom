// GraphQL Validation — Template 03
// Focus: ecommerce api | Scenario: social feed

import { GraphQLError } from "graphql";
function assertEmail(email) {
  if (!/^[^\s@]+@[^\s@]+\.[^\s@]+$/.test(email)) {
    throw new GraphQLError("Invalid email", { extensions: { code: "BAD_USER_INPUT", field: "email" } });
  }
}

Practice Notes

Checklist for GraphQL Validation
- Practice: ecommerce api
- Scenario: social feed
- Keep resolvers thin; push logic into services
- Use DataLoader to avoid N+1 nested queries
- Put authz checks in context / field resolvers / directives
- Prefer non-null carefully; return typed GraphQLError codes
- Limit depth/complexity; deprecate before breaking changes
