GraphQL (Node.js)

// GraphQL Types — Example 24
// Focus: federation entity | Scenario: chat service

const typeDefs = `#graphql
  scalar DateTime
  enum Role { USER ADMIN }
  type User { id: ID! role: Role! joinedAt: DateTime! }
  input UserFilter { role: Role }
  type Query { users(filter: UserFilter): [User!]! }
`;

Practice Notes

Checklist for GraphQL Types
- Practice: federation entity
- Scenario: chat service
- Keep resolvers thin; push logic into services
- Use DataLoader to avoid N+1 nested queries
- Put authz checks in context / field resolvers / directives
- Prefer non-null carefully; return typed GraphQLError codes
- Limit depth/complexity; deprecate before breaking changes
