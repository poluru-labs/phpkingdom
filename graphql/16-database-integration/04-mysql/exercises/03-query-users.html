GraphQL (Node.js)

// GraphQL with MySQL — Exercise 03
// Focus: query users | Scenario: social feed

import mysql from "mysql2/promise";
const pool = mysql.createPool(process.env.MYSQL_URL);
const resolvers = {
  Query: {
    product: async (_p, { id }) => {
      const [rows] = await pool.query("SELECT * FROM products WHERE id = ?", [id]);
      return rows[0] || null;
    },
  },
};

Practice Notes

Checklist for GraphQL with MySQL
- Practice: query users
- Scenario: social feed
- Keep resolvers thin; push logic into services
- Use DataLoader to avoid N+1 nested queries
- Put authz checks in context / field resolvers / directives
- Prefer non-null carefully; return typed GraphQLError codes
- Limit depth/complexity; deprecate before breaking changes
