GraphQL (Node.js)

// GraphQL with PostgreSQL — Template 12
// Focus: file upload | Scenario: e-commerce catalog

import pg from "pg";
const pool = new pg.Pool({ connectionString: process.env.DATABASE_URL });
const resolvers = {
  Query: {
    users: async () => (await pool.query("SELECT id, email FROM users")).rows,
  },
};

Practice Notes

Checklist for GraphQL with PostgreSQL
- Practice: file upload
- Scenario: e-commerce catalog
- Keep resolvers thin; push logic into services
- Use DataLoader to avoid N+1 nested queries
- Put authz checks in context / field resolvers / directives
- Prefer non-null carefully; return typed GraphQLError codes
- Limit depth/complexity; deprecate before breaking changes
