GraphQL (Node.js)

// GraphQL with DynamoDB — Template 11
// Focus: filter input | Scenario: blog API

import { DynamoDBClient, GetItemCommand } from "@aws-sdk/client-dynamodb";
const ddb = new DynamoDBClient({});
const resolvers = {
  Query: {
    user: async (_p, { id }) => {
      const out = await ddb.send(new GetItemCommand({ TableName: "Users", Key: { id: { S: id } } }));
      return out.Item ? { id: out.Item.id.S, email: out.Item.email.S } : null;
    },
  },
};

Practice Notes

Checklist for GraphQL with DynamoDB
- Practice: filter input
- Scenario: blog API
- Keep resolvers thin; push logic into services
- Use DataLoader to avoid N+1 nested queries
- Put authz checks in context / field resolvers / directives
- Prefer non-null carefully; return typed GraphQLError codes
- Limit depth/complexity; deprecate before breaking changes
