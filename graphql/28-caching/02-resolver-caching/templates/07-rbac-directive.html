GraphQL (Node.js)

// Resolver Caching — Template 07
// Focus: rbac directive | Scenario: federated platform

const cache = new Map();
const resolvers = {
  Query: {
    expensive: async (_p, { id }) => {
      if (cache.has(id)) return cache.get(id);
      const value = await compute(id);
      cache.set(id, value);
      return value;
    },
  },
};

Practice Notes

Checklist for Resolver Caching

- Use DataLoader to avoid N+1 nested queries
- Put authz checks in context / field resolvers / directives

- Limit depth/complexity; deprecate before breaking changes
