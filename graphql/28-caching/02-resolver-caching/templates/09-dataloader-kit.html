GraphQL (Node.js)

// Resolver Caching — Template 09
// Focus: dataloader kit | Scenario: content CMS

const cache = new Map();
const resolvers = {
  Query: {
    expensive: async (_p, { id }) => {
      if (cache.has(id)) return cache.get(id);
      const value = await compute(id);
      cache.set(id, value);
      return value;
    },
  },
};

Practice Notes

Checklist for Resolver Caching
- Practice: dataloader kit
- Scenario: content CMS
- Keep resolvers thin; push logic into services
- Use DataLoader to avoid N+1 nested queries
- Put authz checks in context / field resolvers / directives
- Prefer non-null carefully; return typed GraphQLError codes
- Limit depth/complexity; deprecate before breaking changes
