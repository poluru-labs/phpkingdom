GraphQL (Node.js)

// GraphQL with Redis — Example 08
// Focus: enum status | Scenario: SaaS multi-tenant

import Redis from "ioredis";
const redis = new Redis(process.env.REDIS_URL);
const resolvers = {
  Query: {
    product: async (_p, { id }) => {
      const hit = await redis.get(`product:${id}`);
      if (hit) return JSON.parse(hit);
      const row = await db.products.findById(id);
      await redis.set(`product:${id}`, JSON.stringify(row), "EX", 60);
      return row;
    },
  },
};

Practice Notes

Checklist for GraphQL with Redis
- Practice: enum status
- Scenario: SaaS multi-tenant
- Keep resolvers thin; push logic into services
- Use DataLoader to avoid N+1 nested queries
- Put authz checks in context / field resolvers / directives
- Prefer non-null carefully; return typed GraphQLError codes
- Limit depth/complexity; deprecate before breaking changes
