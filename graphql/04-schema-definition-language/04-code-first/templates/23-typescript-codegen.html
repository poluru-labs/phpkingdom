GraphQL (Node.js)

// Code-First Development — Template 23
// Focus: typescript codegen | Scenario: social feed

import { GraphQLObjectType, GraphQLString, GraphQLSchema } from "graphql";
const Query = new GraphQLObjectType({
  name: "Query",
  fields: { hello: { type: GraphQLString, resolve: () => "code-first" } },
});
export const schema = new GraphQLSchema({ query: Query });

Practice Notes

Checklist for Code-First Development
- Practice: typescript codegen
- Scenario: social feed
- Keep resolvers thin; push logic into services
- Use DataLoader to avoid N+1 nested queries
- Put authz checks in context / field resolvers / directives
- Prefer non-null carefully; return typed GraphQLError codes
- Limit depth/complexity; deprecate before breaking changes

  node server.mjs
