GraphQL (Node.js)

// GraphQL Yoga — Template 04
// Focus: social graph | Scenario: chat service

import { createSchema, createYoga } from "graphql-yoga";
import { createServer } from "node:http";
const yoga = createYoga({
  schema: createSchema({
    typeDefs: `type Query { hello: String! }`,
    resolvers: { Query: { hello: () => "Yoga" } },
  }),
});
createServer(yoga).listen(4000);

Practice Notes

Checklist for GraphQL Yoga
- Practice: social graph
- Scenario: chat service
- Keep resolvers thin; push logic into services
- Use DataLoader to avoid N+1 nested queries
- Put authz checks in context / field resolvers / directives
- Prefer non-null carefully; return typed GraphQLError codes
- Limit depth/complexity; deprecate before breaking changes
