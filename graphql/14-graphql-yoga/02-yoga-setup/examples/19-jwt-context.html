Practice Notes

Checklist for GraphQL Yoga Setup
- Practice: jwt context
- Scenario: content CMS
- Keep resolvers thin; push logic into services
- Use DataLoader to avoid N+1 nested queries
- Put authz checks in context / field resolvers / directives
- Prefer non-null carefully; return typed GraphQLError codes
- Limit depth/complexity; deprecate before breaking changes
