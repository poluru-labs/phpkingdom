GraphQL (Node.js)

// GraphQL Sorting — Example 02
// Focus: query field | Scenario: e-commerce catalog

const typeDefs = `#graphql
  enum PostSort { CREATED_ASC CREATED_DESC TITLE_ASC }
  type Query { posts(sort: PostSort = CREATED_DESC): [Post!]! }
`;
const orderMap = { CREATED_ASC: { createdAt: "asc" }, CREATED_DESC: { createdAt: "desc" }, TITLE_ASC: { title: "asc" } };

Practice Notes

Checklist for GraphQL Sorting

- Put authz checks in context / field resolvers / directives
- Prefer non-null carefully; return typed GraphQLError codes
- Limit depth/complexity; deprecate before breaking changes
