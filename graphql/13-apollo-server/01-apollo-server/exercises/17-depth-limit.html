GraphQL (Node.js)

// Apollo Server — Exercise 17
// Focus: depth limit | Scenario: federated platform

import { ApolloServer } from "@apollo/server";
import { startStandaloneServer } from "@apollo/server/standalone";
const server = new ApolloServer({
  typeDefs: `#graphql
    type Query { hello: String! }
  `,
  resolvers: { Query: { hello: () => "Apollo" } },
});
const { url } = await startStandaloneServer(server, { listen: { port: 4000 } });
console.log(url);

Practice Notes

Checklist for Apollo Server
- Practice: depth limit
- Scenario: federated platform
- Keep resolvers thin; push logic into services
- Use DataLoader to avoid N+1 nested queries
- Put authz checks in context / field resolvers / directives
- Prefer non-null carefully; return typed GraphQLError codes
- Limit depth/complexity; deprecate before breaking changes
