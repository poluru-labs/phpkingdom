// Apollo Server Plugins — Exercise 18
// Focus: jest resolver | Scenario: SaaS multi-tenant

const loggingPlugin = {
  async requestDidStart() {
    return {
      async willSendResponse(rc) {
        console.log(rc.operationName, rc.response.http?.status);
      },
    };
  },
};
const server = new ApolloServer({ typeDefs, resolvers, plugins: [loggingPlugin] });

Practice Notes

Checklist for Apollo Server Plugins
- Practice: jest resolver
- Scenario: SaaS multi-tenant
- Keep resolvers thin; push logic into services
- Use DataLoader to avoid N+1 nested queries
- Put authz checks in context / field resolvers / directives
- Prefer non-null carefully; return typed GraphQLError codes
- Limit depth/complexity; deprecate before breaking changes

Useful commands:

  npm install graphql-yoga  # alternative
  node server.mjs
