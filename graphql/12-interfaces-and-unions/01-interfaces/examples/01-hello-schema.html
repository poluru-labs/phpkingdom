// GraphQL Interfaces — Example 01
// Focus: hello schema | Scenario: blog API

const typeDefs = `#graphql
  interface Node { id: ID! }
  type User implements Node { id: ID! email: String! }
  type Post implements Node { id: ID! title: String! }
  type Query { node(id: ID!): Node }
`;

Practice Notes

Checklist for GraphQL Interfaces
- Practice: hello schema
- Scenario: blog API
- Keep resolvers thin; push logic into services
- Use DataLoader to avoid N+1 nested queries
- Put authz checks in context / field resolvers / directives
- Prefer non-null carefully; return typed GraphQLError codes
- Limit depth/complexity; deprecate before breaking changes
