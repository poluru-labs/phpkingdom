Module Federation

// Redux with Module Federation — Template 05
// Focus: vue host remote | Scenario: profile remote

// Shared Redux store across host + remotes

// packages/store — singleton shared module
import { configureStore, createSlice } from "@reduxjs/toolkit";

const cart = createSlice({
  name: "cart",
  initialState: { items: [] },
  reducers: {
    add(state, action) { state.items.push(action.payload); },
  },
});

export const { add } = cart.actions;
export const store = configureStore({ reducer: { cart: cart.reducer } });

// shared: {
//   "@acme/store": { singleton: true },
//   react: { singleton: true },
//   "react-redux": { singleton: true },
// }
// Host wraps <Provider store={store}>; remotes use useDispatch/useSelector

Practice Notes

Checklist for Redux with Module Federation
- Practice: vue host remote
- Scenario: profile remote
- Share framework runtimes as singletons with requiredVersion
- Load remotes lazily; wrap with error boundaries / fallbacks
- Deploy remotes independently; version remoteEntry URLs carefully
- Align CORS and CSP for cross-origin remoteEntry.js

Useful commands:
  npm install -D webpack webpack-cli webpack-dev-server
  # run host + remote on different ports
  npx webpack serve --config webpack.host.js --port 3000
  npx webpack serve --config webpack.remote.js --port 3002
