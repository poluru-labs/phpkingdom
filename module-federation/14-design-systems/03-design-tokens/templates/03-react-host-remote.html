// Share design tokens (CSS variables / JS theme) across remotes

// tokens.css exposed or injected by shell
:root {
  --color-brand: #9a3412;
  --space-md: 16px;
  --font-sans: "Source Sans 3", system-ui, sans-serif;
}

// shell index.html loads tokens once
// remotes use var(--color-brand) — no duplicate theme bundles

// JS tokens module (singleton shared):
export const tokens = { colorBrand: "#9a3412", spaceMd: 16 };
// shared: { "@acme/tokens": { singleton: true } }

Practice Notes

Checklist for Shared Design Tokens
- Practice: react host remote
- Scenario: SaaS dashboard
- Share framework runtimes as singletons with requiredVersion
- Load remotes lazily; wrap with error boundaries / fallbacks
- Deploy remotes independently; version remoteEntry URLs carefully
- Align CORS and CSP for cross-origin remoteEntry.js

Useful commands:
  npm install -D webpack webpack-cli webpack-dev-server
  # run host + remote on different ports
  npx webpack serve --config webpack.host.js --port 3000
  npx webpack serve --config webpack.remote.js --port 3002

Notes
