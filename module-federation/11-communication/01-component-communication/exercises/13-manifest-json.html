// 2) Custom events (framework-agnostic)
window.dispatchEvent(new CustomEvent("catalog:select", { detail: { id: "sku-1" } }));
window.addEventListener("catalog:select", (e) => console.log(e.detail));

// 3) Shared event bus module (singleton shared package)
import { bus } from "@acme/bus";
bus.emit("cart:add", { id: "sku-1" });

Practice Notes

Checklist for Component Communication
- Practice: manifest json
- Scenario: SaaS dashboard
- Share framework runtimes as singletons with requiredVersion
- Load remotes lazily; wrap with error boundaries / fallbacks
- Deploy remotes independently; version remoteEntry URLs carefully
- Align CORS and CSP for cross-origin remoteEntry.js

Useful commands:
  npm install -D webpack webpack-cli webpack-dev-server
  # run host + remote on different ports
  npx webpack serve --config webpack.host.js --port 3000
