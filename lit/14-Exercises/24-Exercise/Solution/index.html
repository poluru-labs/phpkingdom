Solution 24 — Testing Fixture Sketch

Sketch an open-wc fixture test for a Lit element.

Solution

import { fixture, html, expect } from '@open-wc/testing';

it('renders', async () => {
  const el = await fixture(html`<hello-lit></hello-lit>`);
  expect(el.shadowRoot.textContent).to.include('Hello');
});
