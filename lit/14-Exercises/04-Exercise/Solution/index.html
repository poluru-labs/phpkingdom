Solution 04 — State Toggle

Use a state:true property open to toggle panel visibility.

Solution

static properties = {
  open: { type: Boolean, state: true },
};

render() {
  return html`
    <button @click=${() => (this.open = !this.open)}>Toggle</button>
    ${this.open ? html`<div>Panel</div>` : null}
  `;
}
