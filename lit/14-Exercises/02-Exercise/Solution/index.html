Solution 02 — First LitElement

Create a LitElement that renders Hello phpkingdom.com.

Solution

import { LitElement, html } from 'lit';

class HelloLit extends LitElement {
  render() {
    return html`<p>Hello phpkingdom.com</p>`;
  }
}
customElements.define('hello-lit', HelloLit);
