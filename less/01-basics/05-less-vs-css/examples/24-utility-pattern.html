LESS vs CSS

Section: Basics

Focus: Utility Pattern

Scenario: storefront

Study how the LESS snippet is structured and how the pattern can scale in a project.

LESS Snippet

// LESS vs CSS — Example 24
// Focus: utility pattern | Scenario: storefront

/* Plain CSS */
/* .btn { background: #0d6efd; } */
/* .btn:hover { background: #0b5ed7; } */

/* Same idea in LESS — tokens + nesting */
@brand: #0d6efd;

.btn {
  background: @brand;
  &:hover { background: darken(@brand, 8%); }
}

/* LESS also adds mixins, guards, extend, and compile-time math */
