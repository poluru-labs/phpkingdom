Solution 09 — Parent Selector

Use & to add .card--featured and &:hover modifiers.

Solution LESS

.card {
  padding: 1rem;
  border: 1px solid #dee2e6;

  &--featured {
    border-color: #0d6efd;
  }

  &:hover {
    box-shadow: 0 8px 24px rgba(13, 110, 253, 0.12);
  }
}
