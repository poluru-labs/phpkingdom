Solution 13 — Default Function

Use when (default()) as a fallback mixin branch.

Solution LESS

.theme(@name) when (@name = dark) {
  background: #212529;
  color: #f8f9fa;
}
.theme(@name) when (default()) {
  background: #fff;
  color: #212529;
}

.card {
  .theme(light);
  padding: 1rem;
}
