Solution 04 — Parametric Mixin

Create .button(@bg; @color: #fff) and use it for primary and dark buttons.

Solution LESS

.button(@bg; @color: #fff) {
  background: @bg;
  color: @color;
  padding: 0.5rem 1rem;
  border: 0;
  border-radius: 6px;
}

.btn-primary { .button(#0d6efd); }
.btn-dark { .button(#212529); }
