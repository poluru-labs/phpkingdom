Solution 22 — BEM with LESS

Nest BEM elements and modifiers under .card using &__ and &--.

Solution LESS

.card {
  padding: 1rem;
  background: #fff;

  &__title {
    font-size: 1.25rem;
    font-weight: 700;
  }

  &--featured {
    border: 2px solid #0d6efd;
  }
}
