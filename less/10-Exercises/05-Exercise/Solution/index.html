Solution 05 — Mixin Guards

Add a guarded mixin that sets dark text when @bg is light.

Solution LESS

.contrast(@bg) when (lightness(@bg) >= 50%) {
  color: #111;
}
.contrast(@bg) when (lightness(@bg) < 50%) {
  color: #fff;
}

.panel {
  background: #e7f1ff;
  .contrast(#e7f1ff);
  padding: 1rem;
}
