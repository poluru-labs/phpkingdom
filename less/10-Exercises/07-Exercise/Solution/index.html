Solution 07 — Color Functions

Use lighten(), darken(), and fade() on @brand for button states.

Solution LESS

@brand: #0d6efd;

.btn {
  background: @brand;
  color: #fff;
  border: 1px solid fade(@brand, 40%);

  &:hover { background: lighten(@brand, 8%); }
  &:active { background: darken(@brand, 8%); }
}
