Solution 21 — Design Tokens

Create a small token set (@space-*, @color-*) and use it on .card.

Solution LESS

@color-brand: #0d6efd;
@color-ink: #212529;
@space-2: 0.5rem;
@space-3: 1rem;
@radius: 12px;

.card {
  color: @color-ink;
  padding: @space-3;
  border-radius: @radius;
  border: 1px solid fade(@color-brand, 25%);
}
