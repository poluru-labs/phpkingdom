Solution 19 — Responsive Mixin

Write .respond-to(@bp; @rules) wrapping a media query.

Solution LESS

.respond-to(@bp; @rules) {
  @media (min-width: @bp) {
    @rules();
  }
}

.grid {
  display: block;
  .respond-to(768px; {
    display: grid;
    grid-template-columns: 1fr 1fr;
    gap: 1rem;
  });
}
