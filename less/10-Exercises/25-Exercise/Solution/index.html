Solution 25 — Performance Tip

Prefer shallow nesting and reusable mixins over duplicated rules.

Solution LESS

// Prefer:
.card { }
.card__title { }
.card__body { }

// Reuse:
.panel() {
  padding: 1rem;
  border-radius: 8px;
}

// Avoid 5+ level nesting and copy-pasted property blocks.
