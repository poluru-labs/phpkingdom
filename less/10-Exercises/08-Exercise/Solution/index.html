Solution 08 — Extend

Create a shared .message class and :extend() it into .alert-success.

Solution LESS

.message {
  padding: 0.75rem 1rem;
  border-radius: 8px;
  border-left: 4px solid;
}

.alert-success {
  &:extend(.message);
  background: #d1e7dd;
  border-color: #198754;
  color: #0f5132;
}
