LESS Guards

Section: Control and Conditions

Focus: Component Styling

Study how the LESS snippet is structured and how the pattern can scale in a project.

LESS Snippet

// LESS Guards — Example 03
// Focus: component styling | Scenario: blog redesign

.button(@bg) when (iscolor(@bg)) {
  background: @bg;
  color: #fff;
}
.button(@bg) when (isstring(@bg)) {
  background: transparent;
  color: #0d6efd;
  border: 1px solid #0d6efd;
}

.primary { .button(#0d6efd); }
.outline { .button("ghost"); }
