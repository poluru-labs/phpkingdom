LESS Loops

Section: Control and Conditions

Focus: Real-World Layout

Scenario: marketing site

Study how the LESS snippet is structured and how the pattern can scale in a project.

LESS Snippet

// LESS Loops — Example 02
// Focus: real-world layout | Scenario: marketing site

.spacer(@i) when (@i <= 5) {
  .p-@{i} {
    padding: (@i * 0.25rem);
  }
  .spacer(@i + 1);
}
.spacer(1);

@colors: blue, green, red;
.tint-loop(@i: 1) when (@i <= length(@colors)) {
  @c: extract(@colors, @i);
  .tint-@{c} { background: @c; }
  .tint-loop(@i + 1);
}
.tint-loop();
