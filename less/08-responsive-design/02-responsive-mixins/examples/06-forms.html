Responsive Mixins

Section: Responsive Design

Focus: Forms

Scenario: admin panel

Study how the LESS snippet is structured and how the pattern can scale in a project.

LESS Snippet

// Responsive Mixins — Example 06
// Focus: forms | Scenario: admin panel

.respond-to(@bp; @rules) {
  @media (min-width: @bp) {
    @rules();
  }
}

.grid {
  display: block;

  .respond-to(768px; {
    display: grid;
    grid-template-columns: 1fr 1fr;
    gap: 1rem;
  });

  .respond-to(992px; {
    grid-template-columns: repeat(3, 1fr);
  });
}
