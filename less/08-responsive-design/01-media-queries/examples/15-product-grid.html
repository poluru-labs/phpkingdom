Example 15

LESS Media Queries

Section: Responsive Design

Focus: Product Grid

Scenario: portfolio

Study how the LESS snippet is structured and how the pattern can scale in a project.

LESS Snippet

// LESS Media Queries — Example 15
// Focus: product grid | Scenario: portfolio

@bp-md: 768px;
@bp-lg: 992px;

.container {
  width: 100%;
  padding: 0 1rem;

  @media (min-width: @bp-md) {
    max-width: 720px;
    margin: 0 auto;
  }

  @media (min-width: @bp-lg) {
    max-width: 960px;
  }
}

HTML Markup

<section class="panel-media-queries">
  <h2>LESS Media Queries</h2>
  <p>Product Grid for a portfolio.</p>
</section>

Notes

This example shows one way to apply LESS Media Queries in a portfolio context.

Adapt selectors, token names, and mixins to match your project naming rules.
