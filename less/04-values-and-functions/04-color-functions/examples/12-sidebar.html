Color Functions

Section: Values and Functions

Focus: Sidebar

Scenario: marketing site

Study how the LESS snippet is structured and how the pattern can scale in a project.

LESS Snippet

// Color Functions — Example 12
// Focus: sidebar | Scenario: marketing site

@brand: #0d6efd;

.btn {
  background: @brand;
  color: #fff;
  border: 1px solid fade(@brand, 40%);

  &:hover { background: lighten(@brand, 8%); }
  &:active { background: darken(@brand, 8%); }
  &:focus { outline: 2px solid spin(@brand, 20); }
}

.tint { background: tint(@brand, 80%); }
.shade { background: shade(@brand, 20%); }
