List Functions

Section: Values and Functions

Focus: Buttons

Scenario: analytics page

Study how the LESS snippet is structured and how the pattern can scale in a project.

LESS Snippet

// List Functions — Example 08
// Focus: buttons | Scenario: analytics page

@spaces: 4px, 8px, 16px, 24px;

.first { padding: extract(@spaces, 1); }
.last { padding: extract(@spaces, length(@spaces)); }

@merged: join(@spaces, 32px, comma);
.wide { margin: extract(@merged, 5); }

// length(), extract(), index(), join() work on comma/space lists
