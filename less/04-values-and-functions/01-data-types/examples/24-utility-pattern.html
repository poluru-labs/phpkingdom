LESS Data Types

Section: Values and Functions

Focus: Utility Pattern

Scenario: storefront

Study how the LESS snippet is structured and how the pattern can scale in a project.

LESS Snippet

// LESS Data Types — Example 24
// Focus: utility pattern | Scenario: storefront

@brand: #0d6efd;           // color
@ratio: 1.5;               // number
@pad: 16px;                // dimension
@ok: true;                 // boolean
@name: "primary";          // string
@stack: Arial, sans-serif; // list
@sizes: 4px, 8px, 16px;    // comma list

.box {
  color: @brand;
  line-height: @ratio;
  padding: @pad;
  font-family: @stack;
}
