LESS with Bootstrap

Section: Advanced

Focus: Dashboard Widgets

Scenario: storefront

Study how the LESS snippet is structured and how the pattern can scale in a project.

LESS Snippet

// LESS with Bootstrap — Example 04
// Focus: dashboard widgets | Scenario: storefront

// Override Bootstrap LESS variables before importing
@brand-primary: #0d6efd;
@border-radius-base: 8px;
@font-size-base: 16px;

@import "bootstrap/less/bootstrap";

// Custom layer on top
.btn-brand {
  .button-variant(@brand-primary; @brand-primary);
}

HTML Markup

<section class="panel-less-with-bootstrap">
  <h2>LESS with Bootstrap</h2>

</section>
