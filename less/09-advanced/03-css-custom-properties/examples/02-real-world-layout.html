CSS Custom Properties

Section: Advanced

Focus: Real-World Layout

Scenario: marketing site

Study how the LESS snippet is structured and how the pattern can scale in a project.

LESS Snippet

// CSS Custom Properties — Example 02
// Focus: real-world layout | Scenario: marketing site

@brand: #0d6efd;
@ink: #212529;
@radius: 12px;

:root {
  --brand: @brand;
  --ink: @ink;
  --radius: @radius;
}

.btn {
  background: var(--brand);
  color: #fff;
  border-radius: var(--radius);
}

// Compile-time LESS tokens → runtime CSS variables for theming
