Example 15

Lazy Loading Variables

Section: Advanced

Focus: Product Grid

Scenario: portfolio

Study how the LESS snippet is structured and how the pattern can scale in a project.

LESS Snippet

// Lazy Loading Variables — Example 15
// Focus: product grid | Scenario: portfolio

.box {
  color: @brand; // uses the *last* @brand in scope (lazy evaluation)
}

@brand: #0d6efd;
@brand: #6610f2; // wins at use time

// Unlike CSS custom properties, LESS vars resolve at compile time
// but still "lazy" within the file/scope

HTML Markup

<section class="panel-lazy-loading">
  <h2>Lazy Loading Variables</h2>
  <p>Product Grid for a portfolio.</p>
</section>

Notes

This example shows one way to apply Lazy Loading Variables in a portfolio context.

Adapt selectors, token names, and mixins to match your project naming rules.
