Recursive Mixins

Section: Mixins

Study how the LESS snippet is structured and how the pattern can scale in a project.

LESS Snippet

// Recursive Mixins — Example 17
// Focus: landing page | Scenario: booking app

.cols(@i) when (@i <= 4) {
  .col-@{i} {
    width: percentage(@i / 12);
  }
  .cols(@i + 1);
}
.cols(1);

// Generates .col-1 … .col-4 at compile time
