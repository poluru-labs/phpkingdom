Recursive Mixins

Section: Mixins

Focus: Hero Section

Scenario: SaaS dashboard

Study how the LESS snippet is structured and how the pattern can scale in a project.

LESS Snippet

// Recursive Mixins — Example 11
// Focus: hero section | Scenario: SaaS dashboard

.cols(@i) when (@i <= 4) {
  .col-@{i} {
    width: percentage(@i / 12);
  }
  .cols(@i + 1);
}
.cols(1);

// Generates .col-1 … .col-4 at compile time
