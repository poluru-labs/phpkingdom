Node.js Streams

Section: Events and Streams

Focus: Express Route

Scenario: webhook receiver

Study the Node.js pattern and adapt it to your service or script.

Node.js

// Node.js Streams — Example 06
// Focus: express route | Scenario: webhook receiver

import { createReadStream, createWriteStream } from "node:fs";
import { pipeline } from "node:stream/promises";
import { createGzip } from "node:zlib";

await pipeline(
  createReadStream("input.txt"),
  createGzip(),
  createWriteStream("input.txt.gz"),
);
console.log("compressed");
// Always use pipeline / pump — handles errors + cleanup
