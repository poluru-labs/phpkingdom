EventEmitter

Section: Events and Streams

Focus: Cli Script

Scenario: REST microservice

Use this scaffold as a starting point for a Node.js project.

Node.js

// EventEmitter — Template 01
// Focus: cli script | Scenario: REST microservice

import { EventEmitter } from "node:events";

const bus = new EventEmitter();
bus.on("job", (id) => console.log("job", id));
bus.once("ready", () => console.log("ready once"));
bus.emit("ready");
bus.emit("job", 42);
bus.emit("job", 43);
// Always handle 'error' events or the process may crash
