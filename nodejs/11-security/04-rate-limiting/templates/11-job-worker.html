Rate Limiting

Section: Security

Focus: Job Worker

Scenario: REST microservice

Use this scaffold as a starting point for a Node.js project.

Node.js

// Rate Limiting — Template 11
// Focus: job worker | Scenario: REST microservice

import express from "express";
import rateLimit from "express-rate-limit";

const app = express();
const limiter = rateLimit({
  windowMs: 60_000,
  max: 100,
  standardHeaders: true,
  legacyHeaders: false,
});

app.use("/api", limiter);
app.get("/api/data", (_req, res) => res.json({ ok: true }));
app.listen(3000);
