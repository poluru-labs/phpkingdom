API Routing

Section: REST APIs

Focus: Cluster App

Scenario: batch job

Use this scaffold as a starting point for a Node.js project.

Node.js

// API Routing — Template 17
// Focus: cluster app | Scenario: batch job

import express from "express";

const app = express();
app.use(express.json());

const api = express.Router();
api.get("/items", (_req, res) => res.json([]));
api.get("/items/:id", (req, res) => res.json({ id: req.params.id }));
api.post("/items", (req, res) => res.status(201).json(req.body));

app.use("/api", api);
app.listen(3000);

Practice Notes

Checklist for API Routing
- Practice: cluster app
- Scenario: batch job
- Prefer promises / async-await over nested callbacks
- Always handle errors; never leave streams without error listeners
- Use environment variables for secrets and config
- Validate inputs at API boundaries
